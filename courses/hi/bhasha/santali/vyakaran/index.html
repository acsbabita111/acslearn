  • ᱞᱟᱜᱤᱛ (लागित) = के लिए, -ᱛᱮ (-ते) = को / से (ᱤᱥᱠᱩᱞᱚᱛᱮ (इस्कूलते) = स्कूल को)।

✍️ उदाहरण (कोर्स के असली वाक्य)

📘 नियम

  • विशेषण संज्ञा से पहले: ᱢᱟᱨᱟᱸᱜ ᱳᱲᱟᱜ (मारांग ओड़ाक़) = बड़ा घर; ᱵᱮᱥ (बेस) = अच्छा।
  • ᱢᱤᱫ (मित़), ᱵᱟᱨ (बार), ᱯᱮ (पे) = एक, दो, तीन।

📘 नियम

  • ᱡᱳᱦᱟᱨ (जोहार) = नमस्कार (हर समय), ᱥᱟᱨᱚᱦᱟᱣ (सारहाव) = धन्यवाद, ᱟᱯᱮ (आपे) = आप (आदर)।
  • माँगते समय क्रिया के बाद ᱢᱮ (मे) / ᱯᱮ (पे): ᱮᱢ ᱢᱮ (एम मे) = दीजिए।
