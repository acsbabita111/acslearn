इस पाठ के बाद तुम कर पाओगे: (1) जाल और काग़ज़ का फ़र्क़ समझना, (2) orientation-margin-size Excel-ढंग से साधना, (3) Fit-सिकुड़न सोच-समझकर बरतना, (4) Print Area व Print Titles लगाना, (5) 2.13 की Ctrl+P रस्म Excel पर चलाना।

जाल अनंत है, काग़ज़ नहीं

Word का पन्ना पहले से A4 था — जो दिखा, वही छपा। Excel का जाल अनंत है — हज़ारों पंक्तियाँ, सैकड़ों स्तंभ — और काग़ज़ उतना ही छोटा। इसीलिए Excel-छपाई की सबसे आम शिकायत: "आधी सारणी अगले पन्ने पर चली गई" या "दाएँ के दो स्तंभ कटकर पन्ना-2 पर छपे।" जड़ एक ही है — जाल को काग़ज़ की सीमा बतानी पड़ती है, और यह पाठ वही बताना सिखाता है। राहत की बात: खंड-2 के सारे हथियार (पाठ 2.06 का Layout, पाठ 2.13 की Ctrl+P रस्म) यहाँ चलते हैं — बस Excel के तीन अपने औज़ार जुड़ते हैं।

Layout — orientation, margin, size (2.06 की याद)

Page Layout-पट्टी वही तिकड़ी देती है: Orientation — सारणियाँ अक्सर चौड़ी होती हैं (नाम-काम-शुल्क-तारीख़-टिप्पणी…), इसलिए Excel में landscape (लेटा) Word से कहीं ज़्यादा काम आता है — स्तंभ ज़्यादा, कटाव कम; Margins — Normal से शुरू; Size — A4 जाँचना यहाँ भी अनिवार्य (पाठ 2.06 की Letter-फाँस Excel में भी वैसी ही बैठी है)। क्रम भी वही पुराना — नींव पहले: data भरने के बाद छपाई के दिन सब बदलने से बेहतर है कि छपने वाली sheet का रुख़ पहले सोच लो। फ़ोन-ईमानदारी: Excel-app/Sheets फ़ोन पर ये setting सीमित देते हैं — अ-18 इसीलिए partial दर्ज है; पूरा अभ्यास desktop/Sheets-web पर होगा।

Excel की अपनी तिकड़ी — Fit, Print Area, Print Titles

(1) Fit — सिकुड़न: Ctrl+P की settings में सबसे नीचे No Scaling बदलकर Fit All Columns on One Page — दाएँ कटते स्तंभ सिकुड़कर एक पन्ने की चौड़ाई में आ जाते हैं। सावधानी पुरानी समझ से: सिकुड़न = छोटा font — दो-चार स्तंभ कटते हों तो Fit ठीक; बीस स्तंभ ठूँसोगे तो छपा पन्ना सुई-जैसे अक्षरों वाला होगा (पढ़ने लायक़ नहीं = छपा ही क्यों?)। तब बेहतर रास्ता landscape या ग़ैर-ज़रूरी स्तंभ छिपाना। (2) Print Area — छपाई-घेरा: पूरी sheet नहीं, सिर्फ़ चुना हिस्सा छापना हो (जैसे ऊपर की सारांश-सारणी) — हिस्सा चुनो → Page Layout → Print Area → Set Print Area; अब Ctrl+P उसी घेरे को छापेगा। हटाना वहीं Clear से। (3) Print Titles — हर पन्ने पर header: लंबी सूची तीन पन्नों में छपे तो पन्ना-2/3 पर स्तंभ-नाम ग़ायब — वही 2.09 वाली बीमारी। इलाज Excel में: Page Layout → Print Titles → "Rows to repeat at top" में पंक्ति-1 चुनो — अब हर छपे पन्ने पर header दोहराएगा (Freeze screen का था, यह काग़ज़ का)। और एक बारीक़ी: जाल की धूसर रेखाएँ छपतीं नहीं — छपाई में डिब्बे चाहिए तो पाठ 3.02 वाला All Borders लगाओ, या Page Layout में Gridlines → Print ✓।

रस्म वही — झलक, settings, तब Print

पाठ 2.13 की तीन-कदम रस्म अक्षरशः: Ctrl+P → झलक में हर पन्ना देखो (यहीं दिखेगा कौन स्तंभ कट रहा है — झलक के नीचे पन्ना-गिनती "1 of 3" पढ़ो) → settings मिलाओ (printer, Pages, copies, orientation, Fit) → तब Print। और PDF-रास्ता भी वही: Save As → PDF — हिसाब किसी को भेजना हो तो PDF ही भेजो (पाठ 2.13 का सूत्र: काम चालू = xlsx, काम पूरा/बाहर भेजना = PDF) — PDF में जाल वैसा ही दिखेगा जैसा तुमने झलक में जमाया।

पाँच पन्नों में बिखरा हिसाब (काल्पनिक उदाहरण)

मनोज (काल्पनिक नाम) को समिति की बैठक में महीने का हिसाब छापकर ले जाना था। सीधे Print दबाया — पाँच पन्ने निकले: दाएँ के दो स्तंभ अलग पन्नों पर, पन्ना-3 से header ग़ायब, और नीचे का आधा जाल ख़ाली पंक्तियों समेत छपा हुआ। काग़ज़ बर्बाद, बैठक में शर्मिंदगी। उस्ताद ने अगली बार रस्म से करवाया: पहले landscape, फिर झलक — अब भी एक स्तंभ कटा तो Fit All Columns; हिसाब वाला हिस्सा चुनकर Set Print Area (नीचे का कच्चा-चिट्ठा घेरे से बाहर); Print Titles में पंक्ति-1 — और झलक में "1 of 2" साफ़-सुथरे पन्ने। मनोज की copy में तीन पंक्तियाँ जुड़ीं: "Excel में सीधा Print = जुआ। पहले रुख़, फिर घेरा, फिर झलक।" बैठक के लिए उसने PDF भी बनाई — WhatsApp पर भेजी तो सबके फ़ोन पर वही दो सुथरे पन्ने।

अभ्यास — अ-18 (NIOS Practical 18 पर आधारित) — partial: setup-हिस्सा desktop/Sheets-web पर

काम: 3.03 वाली नवंबर-sheet (20+ पंक्तियाँ, 6+ स्तंभ बनाओ) पर — (1) सीधा Ctrl+P झलक: गिनो कितने पन्ने व क्या कट रहा है (screenshot/लिखो), (2) landscape + A4 + Normal margin, (3) Fit All Columns on One Page, (4) ऊपर की 10-पंक्ति सारणी पर Set Print Area → झलक-प्रमाण → Clear, (5) Print Titles से पंक्ति-1 हर पन्ने पर, (6) अंतिम झलक बनाम पहली झलक की तुलना दो वाक्यों में, (7) Save As → PDF। अपेक्षित output: सुथरी छपाई-झलक + PDF; पहले-बाद की तुलना। रूब्रिक R-a-18 (10 अंक): पहली झलक-पड़ताल = 2 · orientation/A4/margin = 2 · Fit सही मौक़े पर = 2 · Print Area set-clear = 2 · Print Titles + PDF = 2। पास = 6।

छोटा टेस्ट — 5 प्रश्न

प्र-1. Excel-छपाई Word से ज़्यादा फाँस-भरी क्यों? (क) जाल अनंत, काग़ज़ सीमित — सीमा बतानी पड़ती है (ख) काग़ज़ Excel के लिए महँगा है (ग) Excel में Print होता ही नहीं (घ) Excel ही Word से ज़्यादा ख़राब है उत्तर: (क)। कारण: वरना स्तंभ कटकर पन्नों में बिखरते — जाल को नाप Fit/Area/रुख़ से देना पड़ता है। बाक़ी क्यों ग़लत: (घ) औज़ार पूरे हैं — बरतना आना चाहिए; (ग) Ctrl+P वहीं है; (ख) बात नाप की है, दाम की नहीं।

प्र-2. चौड़ी सारणी (8 स्तंभ) का पहला इलाज? (क) font घटाकर 6 अंक कर दो (ख) orientation = landscape — लेटा पन्ना (ग) सारणी को तोड़कर दो फ़ाइलों में बाँट दो (घ) आधे स्तंभ delete कर मिटा दो उत्तर: (ख)। कारण: चौड़ाई का सीधा जवाब चौड़ा पन्ना — Excel में लेटा रुख़ ज़्यादा काम आता है; फिर भी कटे तो Fit। बाक़ी क्यों ग़लत: (क) सुई-अक्षर = अपठनीय छपाई; (घ) data मिटाना छपाई का इलाज नहीं — छिपाना/Print Area है; (ग) एक सारणी तोड़ने से पढ़ना और कठिन।

प्र-3. Fit All Columns on One Page की क़ीमत क्या है? (क) छिपा हुआ data हमेशा के लिए मिट जाता है (ख) छपाई के सारे रंग उड़ जाते हैं (ग) सब स्तंभ सिकुड़ते = font छोटा — ठूँसो तो अपठनीय (घ) कोई क़ीमत नहीं — आँख मूँदकर हमेशा लगाओ उत्तर: (ग)। कारण: सिकुड़न मुफ़्त नहीं — दो-चार कटते स्तंभों तक ठीक, बीस ठूँसे तो अपठनीय; विकल्प landscape/स्तंभ-छँटाई। बाक़ी क्यों ग़लत: (घ) "हमेशा" वाली सोच ही सुई-अक्षर छपवाती है; (क) data सुरक्षित — छपाई-नाप भर बदलता; (ख) रंगों से लेना-देना नहीं।

प्र-4. पूरी sheet में से सिर्फ़ ऊपर की सारांश-सारणी छापनी है — औज़ार? (क) हिस्सा नई फ़ाइल में copy करो (ख) हिस्सा चुनकर Page Layout → Print Area → Set (ग) sheet का हिस्सा छप ही नहीं सकता (घ) छपाई के लिए बाक़ी का सारा data ही मिटा डालो उत्तर: (ख)। कारण: छपाई-घेरा — Ctrl+P सिर्फ़ घेरा छापेगा, जाल अछूता; काम होने पर Clear। बाक़ी क्यों ग़लत: (घ) छपाई के लिए data की बलि — कभी नहीं; (ग) औज़ार इसी काम का है; (क) चलेगा, पर दो-फ़ाइल-कबाड़ बेवजह।

प्र-5. तीन पन्नों की छपाई में पन्ना-2/3 पर स्तंभ-नाम भी चाहिए — Excel-इलाज? (क) Print Titles → Rows to repeat = पंक्ति-1 (ख) View का Freeze Top Row लगा दो — वही काम करेगा (ग) छपे पन्ना-2 पर हाथ से लिख दो (घ) Excel में ऐसा हो नहीं सकता उत्तर: (क)। कारण: Page Layout की Print Titles = काग़ज़ पर दोहराती header — 2.09 के Repeat Header का Excel-भाई। बाक़ी क्यों ग़लत: (ग) छपे पन्ने पर क़लम = कच्चा काम; (ख) Freeze screen का औज़ार है — छपाई पर उसका असर नहीं (यही आम उलझन है); (घ) औज़ार मौजूद है — जगह याद रखो।
