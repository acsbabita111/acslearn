इस पाठ के बाद तुम बता पाओगे: (1) input और output का फ़र्क़, (2) CPU क्या करता है, (3) RAM और storage का अंतर, (4) फ़ोन में ये सब कहाँ हैं, (5) डिजिटल मित्र को यह जानना क्यों ज़रूरी है।

शरीर की उपमा — सबसे आसान रास्ता

कंप्यूटर को एक मेहनती शरीर समझो। आँख-कान = input (इनपुट) उपकरण — जिनसे बात भीतर जाती है। दिमाग़ = CPU — जो सोचता-गिनता है। हाथ की तुरंत वाली याद = RAM (रैम) — चालू काम जितनी देर हाथ में है। बक्से वाली पक्की याद = storage (स्टोरेज) — जहाँ चीज़ें बरसों रखी रहती हैं। मुँह-हाव-भाव = output (आउटपुट) उपकरण — जिनसे जवाब बाहर आता है।

input — भीतर भेजने वाले दरवाज़े

keyboard (कीबोर्ड) से अक्षर, mouse (माउस) से इशारा, touchscreen (टचस्क्रीन) से उँगली, microphone (माइक्रोफ़ोन) से आवाज़, camera/scanner से तस्वीर — ये सब input हैं। डिजिटल मित्र का सबसे बड़ा input-औज़ार keyboard है; इसीलिए पाठ 1.06 पूरा typing पर है।

CPU — गिनने-सोचने वाला दिमाग़

CPU (सीपीयू — Central Processing Unit) हर आदेश को पूरा करता है: तुमने "क" दबाया, CPU ने उसे पहचाना, screen तक पहुँचाया। वह बहुत तेज़ है पर आज्ञाकारी — जो कहा जाए वही करता है, अच्छा-बुरा नहीं परखता। इसीलिए ग़लत आदेश (जैसे ग़लत फ़ाइल delete) भी वह उतनी ही तेज़ी से मान लेता है — सोचने का काम तुम्हारा है।

RAM बनाम storage — सबसे ज़रूरी फ़र्क़

RAM = चालू काम की मेज़। जो document अभी खुला है, वह RAM पर है। मेज़ छोटी हो और दस काम फैला दो, तो काम अटकने-धीमा होने लगता है। बिजली गई या कंप्यूटर बंद = मेज़ साफ़ — बिना सहेजा काम उड़ जाता है। storage = अलमारी। hard disk (हार्ड डिस्क), SSD, फ़ोन की भीतरी जगह, pen drive (पेन ड्राइव), memory card — यहाँ सहेजी फ़ाइल बिजली जाने पर भी रखी रहती है। पाठ 2.01 का "Save करो" मंत्र असल में यही है: मेज़ (RAM) से अलमारी (storage) में रखना।

output — बाहर दिखाने वाले दरवाज़े

monitor/screen पर दिखना, speaker (स्पीकर) से सुनाई देना, printer से छपना — ये output हैं। एक मज़ेदार जोड़ी याद रखो: touchscreen एक साथ input भी है (उँगली) और output भी (दिखाना)।

फ़ोन में यही सब कहाँ?

तुम्हारा फ़ोन भी पूरा कंप्यूटर है: touchscreen = input+output · भीतर का chip (चिप) = CPU · फ़ोन की RAM = वही मेज़ · भीतरी जगह और memory card = अलमारी। "फ़ोन हैंग (अटक) हो गया" की आम जड़ अक्सर यही है — छोटी मेज़ पर बहुत सारे app एक साथ फैले हैं।

दुकान पर काम आने वाली समझ (काल्पनिक उदाहरण)

अनिल (काल्पनिक नाम) के केंद्र पर ग्राहक बोला — "मेरा type किया पत्र ग़ायब हो गया, कंप्यूटर ख़राब है!" अनिल ने शांति से पूछा: "Save किया था?" जवाब — "नहीं, बिजली चली गई थी।" अनिल ने समझाया: पत्र RAM की मेज़ पर था, अलमारी (storage) तक पहुँचा ही नहीं — कंप्यूटर ख़राब नहीं, Save छूटा था। पाँच मिनट में पत्र दोबारा बना, इस बार हर दो मिनट पर Save — ग्राहक समझ भी गया, भरोसा भी बढ़ा। अंग-ज्ञान का असली फल यही है: दिक़्क़त की जड़ पहचानना।

करके देखो (छोटा काम)

अपने फ़ोन या घर के किसी उपकरण को देखकर काग़ज़ पर तीन सूचियाँ बनाओ — input अंग, output अंग, और "दोनों" वाले। कम-से-कम छह चीज़ें लिखो।

लेबल पढ़ना सीखो — ख़रीद-सलाह की नींव

दुकान पर कंप्यूटर/फ़ोन के साथ लिखा मिलता है — "8GB RAM, 256GB storage"। अब तुम इसे पढ़ सकते हो: 8GB RAM = काम की मेज़ का आकार (जितनी बड़ी, उतने app एक साथ आराम से); 256GB storage = अलमारी की जगह (जितनी ज़्यादा, उतनी फ़ाइलें-app समाएँगे)। GB (जीबी) जगह की इकाई है — जैसे अनाज के लिए किलो। ग्राहक जब पूछे "कौन-सा फ़ोन लूँ?", तो डिजिटल मित्र brand के नाम नहीं, काम की ज़रूरत से जवाब देता है: सिर्फ़ form-typing का काम है तो साधारण मेज़ चलेगी; भारी app चलाने हैं तो बड़ी मेज़ चाहिए। (किसी एक brand की सिफ़ारिश इस कोर्स का काम नहीं — ज़रूरत पढ़ना सिखाना काम है।)

देखभाल की चार आदतें — अंग लंबे चलें

(1) धूल दुश्मन है — कंप्यूटर-keyboard ढककर रखो, हवा के रास्ते (vents) बंद मत करो। (2) खाना-पीना keyboard से दूर — एक गिलास पानी पूरा keyboard ले डूबता है। (3) बिजली के झटकों से बचाव — जहाँ बिजली आती-जाती हो, वहाँ UPS/अच्छा extension काम की फ़ाइलों का बीमा है (जड़ तुम जानते हो: RAM की मेज़ बिजली जाते ही साफ़)। (4) storage कभी ठसाठस मत भरो — अलमारी ठसाठस हो तो नई चीज़ रखने-निकालने में पूरा घर धीमा हो जाता है; काम की फ़ाइलें क़ायदे के folder में, बेकार की सफ़ाई समय-समय पर। ये चार आदतें केंद्र के उपकरणों की उम्र सालों बढ़ाती हैं — और ग्राहक के सामने "मशीन अटक गई" वाली शर्मिंदगी घटाती हैं।

एक जोड़-बात — MB और GB का नाता: जगह की छोटी इकाई MB (एमबी) है; लगभग 1000 MB = 1 GB। एक photo अक्सर कुछ MB की होती है, type किया document उससे भी बहुत छोटा — इसीलिए 256GB की अलमारी में हज़ारों document आराम से समाते हैं, पर video-फ़ाइलें (जो GB में होती हैं) उसे जल्दी भरती हैं। ग्राहक का "फ़ोन भर गया" रोना अक्सर video-भंडार का ही रोना होता है।

छोटा टेस्ट — 5 प्रश्न

प्र-1. keyboard, mouse और scanner किस परिवार के अंग हैं? (क) input (ख) output (ग) storage (घ) बिजली उत्तर: (क)। कारण: तीनों से जानकारी कंप्यूटर के भीतर जाती है। बाक़ी क्यों ग़लत: (ख) output बाहर दिखाता है — उल्टी दिशा; (ग) storage रखने की जगह है, दरवाज़ा नहीं; (घ) बिजली ऊर्जा है, अंग-परिवार नहीं।

प्र-2. CPU के बारे में कौन-सी बात सही है? (क) वह हर आदेश को पहले अच्छा-बुरा परखता है, तब मानता है (ख) वह screen पर सिर्फ़ चित्र और रंग दिखाने का काम करता है (ग) वह सहेजी हुई फ़ाइलें बरसों तक सँभालकर रखता है (घ) वह हर आदेश तेज़ी से पूरा करता है — परखना इंसान का काम है उत्तर: (घ)। कारण: CPU आज्ञाकारी गिनने वाला दिमाग़ है, विवेक तुम्हारा। बाक़ी क्यों ग़लत: (क) परखने की समझ उसमें नहीं; (ख) दिखाना screen/output का काम; (ग) बरसों सँभालना storage का काम।

प्र-3. बिजली जाते ही सामान साफ़ — यह किसकी पहचान है? (क) RAM (रैम) की — यह चालू काम की मेज़ है (ख) hard disk (हार्ड डिस्क) की — यह बड़ी अलमारी है (ग) pen drive (पेन ड्राइव) की — यह जेबी अलमारी है (घ) memory card (मेमोरी कार्ड) की — यह छोटी अलमारी है उत्तर: (क)। कारण: RAM चालू काम की मेज़ है — बिजली गई, मेज़ साफ़। बाक़ी क्यों ग़लत: (ख), (ग), (घ) तीनों storage-अलमारी हैं — सहेजा सामान वहाँ बिजली बिना भी रखा रहता है।

प्र-4. "Save करना" का अंग-भाषा में मतलब? (क) storage से RAM में लाना (ख) printer से छापना (ग) RAM से storage में रखना (घ) screen बंद करना उत्तर: (ग)। कारण: मेज़ का चालू काम अलमारी में पक्का रखना = Save। बाक़ी क्यों ग़लत: (क) यह उल्टा काम है — फ़ाइल "खोलना"; (ख) छापना output है, सहेजना नहीं; (घ) screen बंद करने से काम न बचता है न जाता है।

प्र-5. "फ़ोन हैंग हो रहा है" की सबसे आम जड़ (इस पाठ के हिसाब से)? (क) फ़ोन के भीतर घुसा कोई भूत-प्रेत या बुरी नज़र (ख) धूप का तेज़ उजाला screen पर पड़ते रहना (ग) फ़ोन पर कसकर चढ़ा हुआ नया मोटा cover (घ) छोटी RAM-मेज़ पर बहुत सारे app एक साथ उत्तर: (घ)। कारण: चालू कामों की मेज़ भर जाए तो सब धीमा। बाक़ी क्यों ग़लत: (क) अंधविश्वास — मशीन की दिक़्क़त की जड़ हमेशा भौतिक/तकनीकी; (ख) उजाले से गति का नाता नहीं; (ग) cover बाहरी ख़ोल है, भीतर की मेज़ नहीं।
