इस पाठ के बाद तुम कर पाओगे: (1) खंड-2 की चार सबसे आम दिक़्क़तों को लक्षण→जड़→इलाज क्रम में सुलझाना, (2) Google Docs में document बनाना, (3) cloud-save की अपने-आप बचत समझना, (4) Docs से docx/PDF निकालना, (5) "कौन-सा औज़ार कब" का समझ-भरा चुनाव।

मिस्त्री वाला आधा हुनर — बिगड़े को सुधारना

खंड-2 के पंद्रह पाठों में बनाना सीखा; डिजिटल मित्र की दुकान पर उतना ही काम बिगड़े का आता है — "फ़ाइल खुल नहीं रही", "सब टेढ़ा हो गया"। मिस्त्री का तरीक़ा याद करो (पाठ 1.04 की आत्मा): घबराओ नहीं — लक्षण पढ़ो → जड़ सोचो → इलाज आज़माओ। चार सबसे आम मरीज़:

दिक़्क़त-1: फ़ाइल खुल ही नहीं रही। जड़ें क्रम से: (क) ग़लत जगह ढूँढी — नाम से खोजो, Downloads/अपना folder (पाठ 1.04 की अलमारी-समझ); (ख) फ़ाइल-प्रकार औज़ार से बेमेल — docx के लिए Word/Docs चाहिए; (ग) भेजने-लाने में अधूरी आई — दोबारा मँगाओ; (घ) सब विफल = प्रति सचमुच बिगड़ी (corrupt) — अब backup-प्रति/भेजी PDF ही सहारा; यही दिन Save As-आदत का ब्याज देता है।

दिक़्क़त-2: formatting बिखर गई — दूसरी मशीन पर सब टेढ़ा। जड़: docx का रूप खोलने वाली मशीन के Word-संस्करण और font-भंडार पर टिका है; तुम्हारा font वहाँ न हो तो मशीन बदलकर दिखाती है। इलाज दो-तरफ़ा: बाहर भेजने के लिए PDF (पाठ 2.13 का सूत्र — काम पूरा = PDF), और भीतर के काम में आम-प्रचलित font (पाठ 2.03)।

दिक़्क़त-3: लिखा हुआ ग़ायब/अधूरा। जड़ें: बिना-save बंद किया (Ctrl+S स्वभाव है — पाठ 2.01), या पुरानी प्रति खोल ली — नाम-तारीख़ पढ़ो, "अंतिम-v2" नामकरण-आदत यहीं बचाती है; Word का AutoRecover कभी-कभी बिना-save काम लौटा देता है — पर वह क़िस्मत है, बीमा नहीं।

दिक़्क़त-4: "document बिगड़ गया — सब धुँधला/अजीब!" जड़ अक्सर बिगाड़ नहीं, दृश्य है: header-footer के भीतर खड़े हो (पाठ 2.10), या view बदल गया है। इलाज: Esc, फिर View-मेन्यू से Print Layout पर लौटो। सूत्र याद रखो: बिगड़ने और अलग दिखने में फ़र्क़ है — पहले दृश्य जाँचो, तब घबराओ।

Google Docs — वही काम, मुफ़्त और cloud में

अब दूसरी छतरी। हर मशीन पर Word नहीं होता — और ज़रूरी भी नहीं: Google Docs (गूगल डॉक्स) browser/फ़ोन-app में चलने वाला मुफ़्त document-औज़ार है; चाहिए सिर्फ़ Google-खाता और internet। खोलो docs.google.com (या Docs-app) → + (नया) → वही जानी-पहचानी दुनिया: typing, B/I/U, alignment, bullets, table, चित्र — खंड-2 का लगभग पूरा हुनर वैसे का वैसा चलता है; बटन की जगह थोड़ी इधर-उधर है, सोच वही। जो सीखा वह Word का नहीं, document-काम का हुनर था — यही इस खंड की असली कमाई है।

cloud-save — बचत की चिंता से छुट्टी, समझ के साथ

Docs का सबसे बड़ा फ़र्क़: Save-बटन है ही नहीं — हर बदलाव अपने-आप Google की cloud (क्लाउड — internet-अलमारी) में सहेजता चलता है; बिजली जाए, browser गिरे — काम बचा रहता है, और वही document दूसरे फ़ोन/कंप्यूटर पर खाता खोलते ही हाज़िर। पर दो समझ साथ बाँधो: (1) यह जादू internet-पर टिका है — network के बिना ताज़ा बदलाव ऊपर नहीं चढ़ते; (2) cloud-फ़ाइल खाते की अमानत है — खाते का password ही अब फ़ाइलों का ताला है (खंड-6 में यह बात गहरी होगी)। और जब दफ़्तर docx/PDF माँगे: Docs में File → Download → Microsoft Word (.docx) या PDF — cloud-प्रति से उतरी हुई फ़ाइल तुम्हारे फ़ोन/कंप्यूटर में आ जाती है; cloud वाली मूल अपनी जगह बनी रहती है (वही "दो फ़ाइलें, दो काम" वाली 2.13 की समझ)।

चुनाव का सूत्र

Word (desktop): भारी-लंबा काम, mail merge (2.14), बिना-internet काम। Docs: मुफ़्त शुरुआत, फ़ोन-से-कंप्यूटर आना-जाना, अपने-आप बचत, साथ-काम। पुल: docx दोनों ओर खुलता-उतरता है। डिजिटल मित्र दोनों जेब में रखता है — वफ़ादारी औज़ार से नहीं, काम से।

दो मशीनों की एक दुकान (काल्पनिक उदाहरण)

मंजू (काल्पनिक नाम) की दुकान पर एक ही desktop था। उसने छोटे काम फ़ोन के Docs पर उठा लिए — typing वही, सोच वही; cloud-save ने बिजली-कटौती वाले इलाक़े की "लिखा गया!" शिकायत ही ख़त्म कर दी। बड़ा काम (merge की 60 चिट्ठियाँ) आया तो वही document desktop पर docx उतारकर Word में पूरा किया। एक दिन ग्राहक की docx खुली ही नहीं — मंजू ने मिस्त्री-क्रम चलाया: जगह ✓, प्रकार ✓, तो तीसरी जड़ — भेजने में अधूरी आई होगी; दोबारा मँगाई, खुल गई। ग्राहक ने पूछा, "कैसे पता था?" मंजू: "रटा नहीं था — क्रम पता था।"

अभ्यास — अ-13 व अ-36 (NIOS Practical 13 व 36 पर आधारित)

अ-13 (दिक़्क़त-सुलझाव): जोड़ी बनाकर खेल — साथी तुम्हारी अभ्यास-फ़ाइल में चारों में से कोई एक दिक़्क़त की नक़ल रचे (जैसे: पट्टी-भीतर छोड़ दे, फ़ाइल दूसरे folder में सरका दे, पुरानी-प्रति खोलकर दे)। तुम बोल-बोलकर लक्षण→जड़→इलाज चलाओ और सुलझाने का क्रम लिखो। फिर भूमिका बदलो। रूब्रिक R-a-13 (10 अंक): लक्षण सही पढ़ा = 2 · जड़ें क्रम से जाँचीं (छलाँग नहीं) = 4 · इलाज सही = 2 · घबराहट-मुक्त बोल-जाँच = 2। पास = 6। अ-36 (Docs): फ़ोन/browser के Docs में वही पाठ 2.03 वाली काल्पनिक सूचना बनाओ — शीर्षक-सजावट, bullet-सूची, एक table; फिर File → Download से docx और PDF दोनों उतारो और folder में दिखाओ; अंत में internet बंद करके एक पंक्ति जोड़ो और देखो Docs क्या कहता है (cloud-सीमा अपनी आँख से)। रूब्रिक R-a-36 (10 अंक): Docs में document = 3 · सजावट-सूची-table = 3 · docx+PDF download = 2 · cloud-सीमा की लिखी समझ = 2। पास = 6।

छोटा टेस्ट — 5 प्रश्न

प्र-1. किसी भी दिक़्क़त पर मिस्त्री-क्रम क्या है? (क) लक्षण पढ़ो → जड़ें क्रम से जाँचो → इलाज (ख) दुकान बंद करके घर चले जाओ (ग) बस restart → restart → restart करते चले जाओ (घ) तुरंत नई फ़ाइल बनाकर शुरू करो उत्तर: (क)। कारण: क्रम ही रटे बिना सुलझाने की ताक़त — मंजू-कथा का सार। बाक़ी क्यों ग़लत: (ग) बिना-जड़ restart तीर है, तरीक़ा नहीं; (घ) नई फ़ाइल मेहनत नहीं लौटाती; (ख) भागना हुनर नहीं।

प्र-2. तुम्हारी docx दफ़्तर की मशीन पर टेढ़ी-बिखरी खुली — पक्का बचाव आगे के लिए? (क) दफ़्तर की मशीन ही बदलवा दो (ख) document में और भी ज़्यादा गहरे-चटक रंग भर दो (ग) बाहर भेजने के लिए PDF — रूप हर जगह एक-सा (घ) पूरी फ़ाइल दोबारा type करो उत्तर: (ग)। कारण: docx का रूप मशीन के font/संस्करण पर टिका; PDF छपी-तस्वीर (पाठ 2.13)। बाक़ी क्यों ग़लत: (क) हर मशीन नहीं बदलवा सकते; (घ) दोबारा-typing जड़ नहीं छूती; (ख) रंग बिखराव को रंगीन बिखराव ही बनाता।

प्र-3. Google Docs में Save-बटन क्यों नहीं है? (क) Docs में save हो ही नहीं सकता (ख) Save सिर्फ़ paid-खाते में मिलता है (ग) बनाने वाले भूल गए (घ) हर बदलाव अपने-आप cloud में सहेजता चलता है उत्तर: (घ)। कारण: cloud-save चलता-फिरता Ctrl+S — यही Docs का बड़ा फ़र्क़। बाक़ी क्यों ग़लत: (ग) यह design है, भूल नहीं; (क) सहेजना तो लगातार हो रहा है; (ख) मुफ़्त खाते में भी यही है।

प्र-4. दफ़्तर ने Docs में बने document की Word-फ़ाइल माँगी — रास्ता? (क) File → Download → Microsoft Word (.docx) (ख) दफ़्तर वालों से Docs खुलवाओ (ग) हो ही नहीं सकता — Docs से Word कभी नहीं बनता (घ) screen की फ़ोटो खींचकर भेज दो उत्तर: (क)। कारण: Docs docx/PDF दोनों उतारता है — cloud-मूल बची रहती है। बाक़ी क्यों ग़लत: (ग) पुल बना हुआ है — "हो नहीं सकता" ग़लत; (घ) फ़ोटो न सँपादित, न क़ायदे की जमा; (ख) माँग पूरी करना ही सेवा है।

प्र-5. cloud-save के बारे में समझ-भरा सच? (क) cloud सिर्फ़ कंप्यूटर पर ही चलता है (ख) बचत अपने-आप, पर internet पर टिकी; password ही ताला (ग) cloud = जादू, कभी कुछ नहीं बिगड़ता (घ) cloud की फ़ाइल दुनिया में सबको दिखती है उत्तर: (ख)। कारण: सुविधा की दो शर्तें — network और खाता-सुरक्षा — जानना ही पक्की समझ। बाक़ी क्यों ग़लत: (ग) "जादू"-भरोसा network-कटे दिन टूटता है; (घ) फ़ाइल खाते की अमानत है, सार्वजनिक नहीं; (क) cloud की ख़ूबी ही हर-device पहुँच है।

खंड-2 पूरा। अगला → खंड-3: Excel — अंकों की दुनिया (पाठ 3.01 से)।
