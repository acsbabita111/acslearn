पाठ परिचय

दहलीज़-पर्ची निकालिए — तीन सवाल, तीन दाँव। सवाल-1: "रंग-आकार का हुक्म html में ही लिखा जाएगा, या उसकी अलग भाषा होगी?" — जवाब आज, और वह है: अलग भाषा। उसका नाम है CSS, और उसका काम एक ही है — पन्ने की शक्ल: रंग, अक्षरों का आकार, जगह, किनारे, सजावट।

इस अलगाव को समझने का सबसे सीधा रूपक आपके अपने घर में है: शरीर और कपड़े। शरीर वही रहता है — पर शादी में एक कपड़े, खेत में दूसरे, स्कूल में तीसरे। कपड़े बदलने के लिए शरीर का कुछ नहीं बदलना पड़ता! html पन्ने का शरीर है — उसका ढाँचा, उसका मतलब: यह शीर्षक है, यह अनुच्छेद, यह सूची, यह तालिका (अध्याय 9 से 12 की पूरी कमाई!)। CSS उस शरीर के कपड़े हैं — वही शीर्षक कभी हरा, कभी नीला; वही अनुच्छेद कभी बड़े अक्षरों में, कभी छोटे — और शरीर अछूता।

आज code कम, समझ ज़्यादा: CSS नाम का मतलब, उसके एक नियम की चीर-फाड़ (चार अंग — वही पाठ-64 वाली tag-चीर-फाड़ की तरह), और यह सवाल कि दुनिया ने शरीर और कपड़े को अलग क्यों रखा। पिछले मेले की ग़लतफ़हमी ने आधा जवाब दे दिया था; आज पूरा। चलिए — दर्ज़ी की दुकान खुलती है।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. HTML बनाम CSS एक वाक्य में बोल पाएँगे — "html बताता है चीज़ क्या है; CSS बताता है वह कैसी दिखे"।

2. एक CSS-नियम के चार अंग पहचान पाएँगे — चुनने वाला (selector), गुण (property), मूल्य (value), घोषणा (declaration)।

3. मतलब और रूप अलग रखने के तीन फल गिना पाएँगे — और दहलीज़ के तीनों दाँव मिला लेंगे।

नाम का मतलब — और एक नियम की चीर-फाड़

नाम पहले: CSS = Cascading Style Sheets (कैस्केडिंग स्टाइल शीट्स)। तीन शब्द, तीन मतलब — Style (स्टाइल) = रूप-ढंग, शक्ल; Sheets (शीट्स) = पत्रे, यानी नियमों के पन्ने; और Cascading (कैस्केडिंग) = झरने की तरह बहना — नियम ऊपर से नीचे बहते हैं, और जब दो नियम एक ही चीज़ पर टकराएँ, तो एक तय रीत से तय होता है कि कौन जीतेगा (यह "झरने की रीत" इसी अध्याय में धीरे-धीरे खुलेगी — पाठ-105 में पहली टक्कर देखेंगे!)। पूरा नाम एक वाक्य में: "रूप-ढंग के नियमों के पत्रे, जो झरने की तरह बहते हैं"।

अब एक नियम — चीर-फाड़ से पहले अंदाज़ा: नीचे CSS का एक पूरा नियम है। 🔮 अंदाज़ा लगाइए — बिना किसी के बताए — यह नियम किस चीज़ पर, क्या असर डालेगा? (संकेत: आप h1 को पहचानते हैं, और "green" अंग्रेज़ी का एक रंग है!) —

h1 {
  color: green;
  font-size: 40px;
}

दाँव का मिलान: पन्ने के हर h1 के अक्षर हरे, और 40 बिंदु (px — पिक्सेल) ऊँचे। अब चीर-फाड़ — चार अंग (कॉपी में, चित्र वाले अंदाज़ में): (1) चुनने वाला (selector — सेलेक्टर): "h1" — नियम किस पर लगे; यहाँ "पन्ने के हर h1 पर"। (2) गुण (property — प्रॉपर्टी): "color", "font-size" — क्या बदलना है (रंग? आकार?)। (3) मूल्य (value — वैल्यू): "green", "40px" — कितना / कैसा। (4) घोषणा (declaration — डिक्लेरेशन): गुण + कोलन (:) + मूल्य + अर्धविराम (;) — एक पूरा हुक्म, जैसे "color: green;"। और घोषणाओं की पूरी पोटली घुंघराले कोष्ठक { } में — यह कोष्ठक-जोड़ी CSS की "खोलो-बंद" है (जोड़ी-सिद्धांत यहाँ भी!)।

पुरानी पहचान, नई भाषा: ग़ौर कीजिए — CSS का ढाँचा आपकी कमाई से कितना मिलता है। गुण-मूल्य की जोड़ी = html की जेब (नाम="मूल्य", पाठ-87) का भाई — बस यहाँ बराबर (=) की जगह कोलन (:), और उद्धरण-चिह्न नहीं। { } की जोड़ी = खोलो-बंद। और चुनने वाला "h1" — वही tag-नाम जो आपने अध्याय-10 में सीखा! यानी CSS आपके html-शरीर के अंगों को नाम से पुकारकर कपड़े पहनाता है। इसीलिए अध्याय 9-12 में मतलब वाले tag (h1, p, th, ul) पर इतना ज़ोर था: सही नाम वाला अंग ही सही कपड़ा पाता है — b-जुगाड़ वाला शीर्षक h1 के कपड़े नहीं पहनेगा, क्योंकि वह h1 है ही नहीं!

दहलीज़ के तीनों दाँव — मिलान: (१) अलग भाषा? — हाँ ✓ (CSS)। (२) border="1" जैसे जुगाड़ों की जगह? — CSS के गुण (किनारा, चौड़ाई, जगह — अगले अध्याय "सजावट व जमावट" में पूरा परिवार)। (३) सौ पन्नों का रंग एक जगह? — CSS-नियम एक जगह लिखे जाते हैं और जितने पन्नों से चाहें, जोड़े जाते हैं (पहली झलक पाठ-105 में) — यही ACS का "एक चीज़ = एक जगह" नियम है: ACS की पूरी website के रंग एक ही जगह से तय होते हैं। बही में तीनों दाँवों पर ✓ या ✗-तारा!

रेखा-चित्र: शरीर और कपड़े

नीचे आज का पूरा दर्शन — एक शरीर, दो कपड़े, और एक नियम की चीर-फाड़ —

ऊपर की तीन तस्वीरें एक ही शरीर की हैं — बीच का html बिल्कुल नहीं बदला, सिर्फ़ दोनों ओर के कपड़े अलग: यही CSS की पूरी ताक़त है।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "एक और भाषा?! अभी html ही पूरी नहीं बैठी, ऊपर से CSS — दो भाषाएँ एक साथ सिर पर! और रंग-रूप तो दिखावा है, असली चीज़ तो जानकारी है। जानकारी सही हो, पन्ना काला-सफ़ेद रहे — क्या फ़र्क़ पड़ता है?"

सच: पहले "दो भाषाएँ सिर पर" वाला डर — यह उतना बड़ा नहीं जितना दिखता है, और आज की चीर-फाड़ ने उसका आधा इलाज कर दिया: CSS का पूरा व्याकरण चार अंग है (चुनने वाला, गुण, मूल्य, घोषणा) — और उनमें से दो आप पहले से जानते हैं (चुनने वाला = आपके html-tag के नाम; गुण-मूल्य = जेब की बनावट)। html के मुक़ाबले CSS की बनावट बहुत छोटी है; उसकी असली दुनिया गुणों का भंडार है — color, font-size, background-color... — और वे एक-एक करके, ज़रूरत पड़ने पर सीखे जाते हैं, ठीक वैसे जैसे आपने tag सीखे (tag-बही की तरह आज से एक "गुण-बही" भी!)। ऊपर से, दोनों भाषाओं का बँटवारा साफ़ है — क्या के सवाल html के, कैसा के CSS के — तो सिर में खिचड़ी नहीं, दो अलग ख़ाने बनते हैं।

अब "रंग-रूप दिखावा है" — यह सबसे गहरी ग़लतफ़हमी है, और ACS के अपने नियम इसे तोड़ते हैं। सोचिए ACS का कौन-सा नियम "रूप" का है: फ़ॉन्ट 16px से नीचे कभी नहीं — क्यों? क्योंकि छोटे अक्षर बुज़ुर्ग आँख के लिए जानकारी को ग़ायब कर देते हैं (पाठ-104 की पूरी कहानी!); रंग अधिकतम 5, गहरा-हल्का साफ़ फ़र्क़ — क्योंकि हल्के पीले पर सफ़ेद अक्षर धूप में फ़ोन पर पढ़े ही नहीं जाते। यानी रूप "दिखावा" नहीं — पहुँच है: जो पढ़ा न जा सके, वह जानकारी सही होकर भी बेकार। और रूप समझ भी देता है — ज़रूरी चेतावनी लाल, सफल काम हरा, शीर्षक बड़ा — आँख बिना पढ़े पन्ने का नक़्शा पा लेती है (h-सीढ़ी की ही अगली मंज़िल)। हाँ, रूप बुरा भी हो सकता है — चमक-दमक जो जानकारी को ढक दे — और उससे बचने की तमीज़ इस अध्याय में सिखाई जाएगी। पर रूप को छोड़ देना हल नहीं: अच्छा रूप जानकारी का सेवक है, दुश्मन नहीं।

अभ्यास-खेल: दर्ज़ी-मश्क़

खेल 1 — चीर-फाड़ अदालत: नीचे के पाँच CSS-टुकड़े कॉपी में उतारिए और हर एक के चारों अंग रंगीन पेंसिल से निशान लगाइए (चुनने वाला · गुण · मूल्य · घोषणा): (क) p { color: blue; } (ख) li { font-size: 20px; } (ग) th { color: white; background-color: navy; } (घ) h2 { color: orange; } (ङ) body { font-size: 19px; }। फिर हर एक पर अंदाज़ा: परदे पर किस चीज़ पर क्या असर? — (ग) में घोषणाएँ कितनी? (दो — एक नियम, दो हुक्म!)

खेल 2 — एक शरीर, तीन कपड़े (काग़ज़ पर): अपनी meriKahani.html (पाठ-79) याद कीजिए। कॉपी में उसके तीन अलग कपड़ों के नक़्शे बनाइए — (क) "त्योहार" (गहरे रंग, बड़ा शीर्षक) (ख) "किताब" (सादा, काला-सफ़ेद, पढ़ने में आराम) (ग) "रात" (गहरी पृष्ठभूमि, हल्के अक्षर)। हर नक़्शे में लिखिए: h1 का रंग? p का आकार? पृष्ठभूमि? — और सबसे ज़रूरी: तीनों में html का एक भी अक्षर बदला? (नहीं! — यही आज का सबक़, पेंसिल से।)

खेल 3 — घर में कपड़ों की तलाश + गुण-बही: घर-आँगन में तीन जगहें खोजिए जहाँ "शरीर" वही रहता है पर "कपड़ा" बदलता है (त्योहार पर घर की सजावट? मौसम के साथ खेत का रंग? स्कूल-ड्रेस बनाम त्योहार के कपड़े?) — हर एक पर एक पंक्ति: क्या वही रहा, क्या बदला? फिर कॉपी में नया पन्ना — गुण-बही (tag-बही की बहन): स्तंभ — गुण · क्या बदलता है · मूल्य के नमूने। आज की दो पंक्तियाँ: color, font-size। अध्याय के अंत तक यह बही आपकी CSS-पोटली होगी।

आगे क्या सीखेंगे

दर्ज़ी की दुकान का परिचय हो गया — CSS = रूप की अलग भाषा, नाम का झरना-अर्थ, नियम के चार अंग, शरीर-कपड़े का बँटवारा और उसके तीन फल, और दहलीज़ के तीनों दाँवों का मिलान। गुण-बही खुल चुकी है।

पर आज का नियम सिर्फ़ काग़ज़ पर था — उसे पन्ने तक पहुँचाया कैसे जाए? CSS-नियम html-पन्ने में बैठने के तीन रास्ते हैं, और कल पहला — सबसे सीधा, सबसे छोटा: tag के भीतर ही, एक नई जेब के ज़रिए — style जेब। वह आपको तुरंत असर दिखाएगी (आपका कहानी-शीर्षक पहली बार हरा होगा!), पर उसके साथ एक छिपी क़ीमत भी है, जिसे आप दो-तीन tag रंगते ही महसूस करेंगे — और वही क़ीमत पाठ-105 के "सब नियम एक जगह" की भूख जगाएगी। पाठ-100: style लगाने का पहला तरीक़ा — टैग के भीतर।
