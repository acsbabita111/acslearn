पाठ परिचय

बीमारियों की पट्टी खोलिए — पंद्रह नाम, और नीचे ख़ाली ख़ाना: "बीमारी-16: ______" (पाठ-97 ने कहा था, रंग-रूप वाला अध्याय अपनी बीमारियाँ लाएगा)। आज चार नाम भरेंगे — और ये चारों एक नए मिज़ाज की बीमारियाँ हैं।

html की बीमारियाँ शोर मचाती थीं: भूला बंद-tag बाक़ी पन्ना मोटा कर देता था (बहाव), भटका माल तालिका से उछल जाता था — लक्षण आँख में चुभते थे। CSS की बीमारियाँ चुप हैं। ग़लत लिखा नियम browser के लिए बस "समझ नहीं आया" है — और browser की रीत है: जो समझ न आए, उसे चुपचाप छोड़ दो, आगे बढ़ो। कोई चेतावनी नहीं, कोई अजीब परदा नहीं — बस आपका रंग नहीं लगता। आप नियम देखते हैं ("लिखा तो है!"), परदा देखते हैं ("लगा तो नहीं!") — और बीच में कुछ नहीं।

चुप बीमारी को पकड़ने के लिए पुराना स्टेथोस्कोप (पेड़ खींचो, जगह गिनो) काम नहीं आता — यहाँ बीमारी पेड़ में नहीं, नियम के अक्षरों में छिपी है। इसलिए आज CSS का अपना स्टेथोस्कोप मिलेगा: दो चालें जो दुनिया भर के कारीगर बरतते हैं — जासूस-रंग और एक-एक नियम सुलाना। और सुलाने के लिए एक नई चीज़: CSS की अपनी टिप्पणी। दस्ताने पहनिए — नक़ल-प्रति पर।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बीमारी 16-19 पहचान पाएँगे — भूला अर्धविराम, ग़लत वर्तनी, भूला }, बिंदु-भूली टोली।

2. CSS-स्टेथोस्कोप चला पाएँगे — (1) जासूस-रंग: चुनने वाला चीज़ तक पहुँचा या नहीं? (2) एक-एक नियम सुलाओ: कौन-सा नियम दोषी?

3. CSS-टिप्पणी /* */ लिख पाएँगे — html की टिप्पणी से उसका फ़र्क़ बोल पाएँगे।

चार चुप बीमारियाँ — और CSS-स्टेथोस्कोप

बीमारी-16 · भूला अर्धविराम: दो घोषणाओं के बीच ; छूटा — color: #1565C0 font-size: 22px; — browser इसे एक घोषणा पढ़ता है: गुण "color", मूल्य "#1565C0 font-size: 22px" — ऐसा कोई रंग नहीं! पूरी घोषणा फेंकी — और font-size भी उसके साथ गया। लक्षण: दो रूप एक साथ ग़ायब (रंग भी नहीं, आकार भी नहीं), जबकि दोनों "लिखे हैं"। (पाठ-100 के खेल-2 में आपने यही देखा था!) इलाज: हर घोषणा के अंत ; — आख़िरी के बाद भी (लोहे का अनुशासन फिर से)।

बीमारी-17 · ग़लत वर्तनी: colour (ब्रिटिश वर्तनी!), font-sise, backgroud-color, मूल्य में "blu" या "#1565C" (एक अक्षर कम) — browser इन्हें पहचानता नहीं, चुपचाप छोड़ता है। लक्षण: सिर्फ़ उसी एक घोषणा का असर ग़ायब, बाक़ी ठीक (बीमारी-16 से फ़र्क़ यहीं — वहाँ दो जाते थे)। इलाज: अक्षर-अक्षर मिलाओ (गुण-बही की सही वर्तनी से — इसीलिए बही थी!)।

बीमारी-18 · भूला } : किसी नियम का बंद-कोष्ठक छूटा — h1 { color: #1565C0; — और उसके नीचे का p-नियम browser को h1-नियम के भीतर का बेतुका माल लगता है। लक्षण: ठीक नीचे वाला नियम (या कई) अचानक बेअसर — जबकि उसमें कोई ग़लती नहीं! यह CSS का "बहाव" है (पाठ-68 की पहली बीमारी का भाई): ग़लती ऊपर, लक्षण नीचे। इलाज: कोष्ठक-गिनती — हर { का एक } (जोड़ी-सिद्धांत, CSS में भी)।

बीमारी-19 · बिंदु-भूली टोली: अलमारी में savdhani { ... } (बिंदु के बिना) — browser <savdhani> नाम का tag ढूँढता है, जो पन्ने में है ही नहीं। लक्षण: टोली का नियम पूरा का पूरा बेअसर, जबकि घोषणाएँ बिल्कुल सही। उलटा भी होता है — अलमारी में .savdhani सही, पर tag पर class="Savdhani" (बड़ा S — साँचा v2 में बड़े-छोटे का फ़र्क़!) या class="savdani" (वर्तनी)। इलाज: नाम का दोनों सिरों पर अक्षर-अक्षर मिलान — अलमारी में और tag पर।

CSS-स्टेथोस्कोप — दो चालें: चाल-1 · जासूस-रंग ("चुनने वाला पहुँचा?"): शक वाले नियम के सबसे ऊपर एक चीख़ता रंग जोड़िए — background-color: #F9A825; — चलाइए: (क) पट्टी आई? → चुनने वाला चीज़ तक पहुँच रहा है, गड़बड़ नीचे की किसी घोषणा में (16/17); (ख) पट्टी नहीं आई? → चुनने वाला ही नहीं पहुँच रहा (19), या ऊपर किसी नियम का } भूला है (18)। एक चाल, बीमारियों के दो परिवार अलग! चाल-2 · एक-एक सुलाओ ("कौन-सा दोषी?"): CSS की टिप्पणी html से अलग है — /* ... */ (बिंदु-तारा खोलो, तारा-बिंदु बंद)। शक वाली घोषणाओं को एक-एक करके सुलाइए; जिसे सुलाते ही बाक़ी जाग उठें, वही दोषी (एक-बदलाव नियम का CSS-रूप!)। काम ख़त्म होते ही जासूस-रंग हटाना न भूलें। 🔮 अंदाज़ा लगाइए — नीचे के सुधरे नियमों में से कौन-सी पंक्ति किस बीमारी का इलाज है? —

/* sudhra hua: chaar beemariyon ka ilaaj */
h1 {
  color: #1565C0;
  font-size: 26px;
}
p {
  background-color: #F5F7FA;
}
.savdhani {
  background-color: #F9A825;
}

मिलान: h1 की दो घोषणाएँ अलग-अलग ; के साथ (16) और color की सही वर्तनी (17); h1 का } अपनी जगह (18) — इसलिए p-नियम अब जागा; और .savdhani का बिंदु (19)। सबसे ऊपर CSS-टिप्पणी — वही /* */ जो सुलाने का औज़ार है, यहाँ फ़ैसला-पर्ची बनकर (पाठ-77 की "क्यों" वाली सीख)।

रेखा-चित्र: दवाख़ाना-5

नीचे चार चुप बीमारियाँ, उनके लक्षण, और CSS-स्टेथोस्कोप की दो चालें —

बीच का हरा डिब्बा आज की असली चाबी है — एक चीख़ता सुनहरा रंग, और एक ही नज़र में पता: गड़बड़ "पहुँचने" में है या "कहने" में। चुप बीमारी को बोलने पर मजबूर करने की यही विद्या है।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "browser इतना होशियार है, तो ग़लत CSS पर चिल्लाता क्यों नहीं? यह तो उसकी कमी है! और रंग न लगे तो कोई बड़ी बात नहीं — html तो सही है, जानकारी पूरी है। CSS की बीमारी छोटी बीमारी है, उस पर इतना दवाख़ाना क्यों?"

सच: पहले "चिल्लाता क्यों नहीं" — यह browser की कमी नहीं, एक सोचा-समझा फ़ैसला है, और इसके पीछे बड़ी समझदारी है। CSS के नए गुण हर साल जुड़ते रहते हैं; आपके पन्ने को दुनिया के हज़ारों तरह के browser खोलते हैं — नए, पुराने, सस्ते फ़ोन वाले (Android 8!)। अगर पुराना browser हर अनजान गुण पर रुककर "ग़लती!" चिल्लाता और पन्ना दिखाना बंद कर देता, तो हर नया गुण दुनिया के आधे पन्ने तोड़ देता। इसलिए रीत बनी: जो समझ न आए, छोड़ दो, बाक़ी दिखाओ — पन्ना कभी नहीं रुकता (ACS का नियम याद है? "image न खुले तो content न रुके" — वही आत्मा, browser के स्तर पर!)। इस रीत की क़ीमत यह है कि आपकी अपनी ग़लतियाँ भी चुप रह जाती हैं — इसलिए उन्हें पकड़ने की ज़िम्मेदारी आपकी, और आज के स्टेथोस्कोप की ज़रूरत।

और "छोटी बीमारी" — पिछले पाँच पाठों ने दिखाया कि CSS सजावट भर नहीं। भूले अर्धविराम ने font-size 19 मार दिया, तो पन्ना browser के आम 16 पर लौट आया — या अलमारी के बड़े नियम में भूला } नीचे के body-नियम को निगल गया, तो पूरा पन्ना छोटे अक्षरों और कम विरोध-अंक वाला — दादी के लिए फिर "यह पन्ना तुम्हारे लिए नहीं"। सावधानी-टोली का बिंदु भूला, तो "बिजली के खंभे से दूर रहो" वाली पंक्ति बाक़ी पंक्तियों में घुलमिल गई — चेतावनी की पहचान गई। यानी CSS की बीमारी जानकारी को मिटाती नहीं, पर उसे पहुँच से बाहर कर देती है — और ACS के लिए पहुँच ही सब कुछ है। ऊपर से, चुप बीमारी सबसे ख़तरनाक इसीलिए है कि वह महीनों छिपी रह सकती है — कोई शिकायत नहीं करता, बस पाठक कम होते जाते हैं। जो बीमारी चिल्लाती नहीं, उसकी जाँच नियम से होती है — इंतज़ार से नहीं।

अभ्यास-खेल: दवाख़ाना-5 मश्क़

खेल 1 — चार मरीज़, चार नक़लें: toli.html (पाठ-106) की चार नक़लें बनाइए — हर एक में ठीक एक बीमारी (16, 17, 18, 19 — एक-एक)। हर नक़ल पर: (1) चलाइए, लक्षण लिखिए (क्या ग़ायब? कितने रूप?) (2) जासूस-रंग चाल — पट्टी आई या नहीं? किस परिवार की बीमारी? (3) एक-एक सुलाओ चाल — दोषी पकड़ा (4) इलाज + ग़लती-बही में पर्चा। चारों पर्चों की तुलना: किन दो बीमारियों के लक्षण सबसे मिलते-जुलते थे? (16 और 17 — दो ग़ायब बनाम एक ग़ायब!)

खेल 2 — साथी-मरीज़ (अनजान बीमारी): अपनी rangKahani.html (साँचा v2 वाली) की नक़ल साथी को दीजिए — वह दो CSS-बीमारियाँ चुपके से डाले (16-19 में से)। आप दोनों चालों से पकड़िए — बिना code को अक्षर-अक्षर पढ़े, पहले सिर्फ़ जासूस-रंग से परिवार तय कीजिए। कितने क़दम में पकड़ा? (कम क़दम = स्टेथोस्कोप बैठ गया!)

खेल 3 — टिप्पणियों का फ़र्क़ + पट्टी-विस्तार: एक प्रयोग: अलमारी के भीतर html वाली टिप्पणी (<!-- ... -->) से एक घोषणा सुलाने की कोशिश कीजिए — 🔮 दाँव: क्या होगा? — चलाइए (वह घोषणा सोई? या आस-पास के नियम भी बिगड़े?) — फिर /* */ से वही काम। सबक़ कॉपी में: "html में html की टिप्पणी, CSS में CSS की"। बीमारी-पट्टी में चार नई पंक्तियाँ (16-19) — लक्षण · जड़ · इलाज — और गुण-बही में एक कोना: CSS-स्टेथोस्कोप की दो चालें।

आगे क्या सीखेंगे

पाँचवाँ दवाख़ाना पार — उन्नीस बीमारियों की पट्टी, CSS की चुप-रीत और उसकी वजह, जासूस-रंग और एक-एक सुलाओ की दो चालें, और CSS की अपनी टिप्पणी। चुप बीमारी अब आपके सामने बोलती है।

और अब अध्याय का आख़िरी पाठ — बनाओ! आपकी कहानी (पाठ-79 वाली, "हवा से परदे पर" उतरी पहली कहानी) अब तक काले-सफ़ेद शरीर में है, कुछ जेबों के टुकड़ों के साथ। कल उसे पूरे कपड़े मिलेंगे: साँचा v2, ACS के पाँच रंग #-कोडों में, 19 का पढ़ाई-आकार, नापे हुए विरोध-अंक वाली जोड़ियाँ, मतलब वाले नामों की टोलियाँ (संवाद, सीख, दोहा...), एक-जगह की अलमारी — और आख़िर में दादी-परीक्षा, धूप-परीक्षा, ग्रेस्केल-परीक्षा। अध्याय-13 के सारे औज़ार एक पन्ने पर। पाठ-108: 🛠 बनाओ — अपने कहानी-पन्ने को रंगो।
