पाठ परिचय

html चलाने के लिए आपको कुछ नया नहीं चाहिए था — फ़ोन का browser ही html पढ़ना जानता है (पाठ-51)। Python के साथ ऐसा नहीं: browser Python नहीं समझता। Python के हुक्म करने के लिए एक ख़ास "मुनीम" चाहिए — एक प्रोग्राम जिसे Python interpreter (इंटरप्रेटर — दुभाषिया: जो Python के हुक्म पढ़कर कंप्यूटर से करवाए) कहते हैं। कंप्यूटर पर यह अलग से लगाया जाता है; फ़ोन पर उसके दो आसान, मुफ़्त रास्ते हैं।

आज यह पाठ ⏱ (तेज़-बदलाव) वाला है — क्योंकि ऐप और websites बदलते रहते हैं: आज जो मुफ़्त है, कल पैसे माँग सकता है; आज जो चलता है, कल बंद हो सकता है। इसलिए आज हम रास्ते सिखाएँगे (browser-रास्ता, ऐप-रास्ता), और उदाहरण के तौर पर दो नाम — पर हर नाम के साथ ACS की पक्की पंक्ति: "बाहरी site — ख़ुद verify करें"। नाम बदल जाएँ, तो रास्ता वही रहेगा।

और सबसे ज़रूरी बात पहले ही: अगर आपके पास इनमें से कोई रास्ता नहीं है — तो भी यह भाग आप पूरा सीख सकते हैं। इस किताब के हर Python code-डिब्बे के साथ उसका नतीजा भी लिखा होगा, और आपके पास भाग-अ का पुराना हथियार है — सूखी-दौड़: ख़ुद मशीन बनकर हर हुक्म काग़ज़ पर चलाना। चलिए — मुनीम ढूँढते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. Python चलाने के तीन रास्ते बता पाएँगे — browser-रास्ता, ऐप-रास्ता, सूखी-दौड़ — और अपने हालात के हिसाब से एक चुन पाएँगे।

2. पाँच सावधानियाँ निभा पाएँगे — सिर्फ़ आधिकारिक दुकान से ऐप, कोई भुगतान नहीं, विज्ञापन न दबाओ, अनुमतियाँ सोचकर, निजी जानकारी नहीं।

3. फ़ोन पर Python के चिह्न टाइप कर पाएँगे, फ़ाइल को .py पूँछ से बचा पाएँगे — और जानेंगे कि ग़लती-संदेश संस्करण से थोड़े बदलते हैं।

तीन रास्ते — और पाँच सावधानियाँ

रास्ता-1 · browser-रास्ता (इंटरनेट चाहिए, कुछ डाउनलोड नहीं): कुछ websites अपने पन्ने के भीतर ही Python चलाती हैं — आप एक ख़ाने में code लिखते हैं, "Run" दबाते हैं, नीचे नतीजा आता है। उदाहरण: Programiz का ऑनलाइन compiler (प्रोग्रामिज़; compiler — कंपाइलर: यहाँ मोटे तौर पर "चलाने वाला") — https://www.programiz.com/python-programming/online-compiler/ — खोलते ही एक नमूना code मिलता है; उसे मिटाकर अपना लिखिए। ख़ूबियाँ: कुछ लगाना नहीं, खाता बनाना ज़रूरी नहीं, किसी भी फ़ोन पर। कमियाँ: इंटरनेट बिना नहीं चलता; पन्ने पर उनके पैसे वाले कोर्स के विज्ञापन दिखते हैं — मुफ़्त चलाने के लिए उनकी कोई ज़रूरत नहीं, अनदेखा कीजिए; और आपका code वहाँ अपने-आप सहेजा नहीं जाता — ज़रूरी code अपनी कॉपी या फ़ोन की किसी नोट-फ़ाइल में रखिए।

रास्ता-2 · ऐप-रास्ता (एक बार डाउनलोड, फिर बिना इंटरनेट): Android के लिए Python चलाने वाले ऐप हैं, जो पूरा "मुनीम" फ़ोन के भीतर ही रखते हैं। उदाहरण: Pydroid 3 (पाईड्रॉइड) — Google Play Store से: https://play.google.com/store/apps/details?id=ru.iiec.pydroid3 — मुफ़्त है, पर उसमें विज्ञापन और पैसे वाली अतिरिक्त सुविधाएँ हैं (आपको उनकी ज़रूरत नहीं); लगभग 65 MB जगह लेता है; Android 6 और ऊपर पर चलता है। ख़ूबियाँ: एक बार लगा, फिर गाँव में बिना नेटवर्क के भी चलता है; फ़ाइलें फ़ोन में सहेजी जाती हैं; ऊपर एक अतिरिक्त पट्टी में Python के चिह्न ( ) " : मिलते हैं। कमियाँ: फ़ोन में जगह चाहिए; विज्ञापन बीच-बीच में आते हैं।

रास्ता-3 · सूखी-दौड़ (कुछ नहीं चाहिए): इस किताब के हर Python-डिब्बे के साथ उसका नतीजा भी लिखा होगा। तरीक़ा वही भाग-अ वाला (पाठ-10): कॉपी पर code उतारिए, हर हुक्म को ख़ुद मशीन बनकर चलाइए, अपना अंदाज़ा लिखिए — फिर किताब के नतीजे से मिलाइए। यह रास्ता "कमज़ोर" नहीं — दुनिया के अच्छे प्रोग्रामर भी कठिन code को पहले काग़ज़ पर सूखा चलाते हैं।

पाँच सावधानियाँ (कॉपी में — अध्याय-8 की सुरक्षा-रीत, अब ऐप पर): (1) ऐप सिर्फ़ आधिकारिक दुकान से (Google Play Store) — किसी website से "APK फ़ाइल" डाउनलोड करने के न्योते कभी नहीं (नक़ली ऐप ठगों का पुराना हथियार है)। (2) कोई भुगतान नहीं — Python सीखने के लिए एक रुपया भी नहीं चाहिए; "PRO", "Premium" के बटन अनदेखा कीजिए। (3) विज्ञापन मत दबाओ — कई विज्ञापन बटन जैसे दिखते हैं; "Run" या ऐप के अपने बटन ही दबाइए। (4) अनुमतियाँ सोचकर — Python-ऐप को फ़ाइलें रखने की अनुमति चाहिए हो सकती है; पर संपर्क-सूची, SMS, कैमरा — उसकी ज़रूरत नहीं, ऐसी माँग पर "नहीं"। (5) निजी जानकारी नहीं — code में या किसी online ख़ाने में अपना नंबर, पता, पासवर्ड कभी नहीं (पाठ-57, 59)। 18 से कम हैं, तो ऐप लगाने से पहले घर के किसी बड़े को बताइए।

तीन व्यावहारिक बातें: (क) चिह्न टाइप करना — फ़ोन के कीबोर्ड पर ( ) और " अक्सर "?123" वाले बटन के पीछे होते हैं; उल्टे-कॉमा सीधे वाले (") ही चाहिए, टेढ़े वाले (“ ”) नहीं — कुछ कीबोर्ड अपने-आप टेढ़े लगा देते हैं (पाठ-134 में उसकी बीमारी!)। (ख) .py पूँछ — Python-फ़ाइलों की पूँछ .py होती है (जैसे html की .html — पाठ-50); नाम Roman, छोटे अक्षर, बिना space: pehla.py। (ग) संस्करण का फ़र्क़ — Python के अलग-अलग संस्करण (version — वर्ज़न) होते हैं; इस किताब के ग़लती-संदेश Python 3.12 से लिए गए हैं; आपके ऐप या website का संस्करण पुराना-नया हो, तो संदेश के शब्द थोड़े अलग दिख सकते हैं — पर मतलब और जगह वही।

जानकारी-जाँची: अक्टूबर 2026 — ऊपर के दोनों उदाहरण (Programiz का ऑनलाइन compiler, Pydroid 3 ऐप) इसी महीने जाँचे गए; बाहरी site — ख़ुद verify करें। नाम, क़ीमत, सुविधाएँ बदल सकती हैं; रास्ते (browser / ऐप / सूखी-दौड़) वही रहेंगे।

रेखा-चित्र: तीन रास्ते

नीचे आज का पूरा पट्ट — तीन रास्ते, उनकी ख़ूबी-कमी, और पाँच सावधानियाँ —

तीसरा डिब्बा कोई "मजबूरी का रास्ता" नहीं — इस भाग का हर पाठ उसी पर भी पूरा चलता है; पहले दो रास्ते मिलें, तो सोने पर सुहागा।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "असली प्रोग्रामिंग के लिए तो महँगा कंप्यूटर चाहिए! फ़ोन पर Python — यह खिलौना है, असली प्रोग्रामर ऐसे नहीं सीखते। और जिसके पास न अच्छा फ़ोन है, न इंटरनेट — उसके लिए प्रोग्रामिंग है ही नहीं।"

सच: "फ़ोन पर Python खिलौना है" — जिस Python से आप फ़ोन पर print(2+3) चलाएँगे, वह वही Python है जो दुनिया की बड़ी-बड़ी कंपनियों के कंप्यूटरों पर चलता है — वही भाषा, वही नियम, वही ग़लती-संदेश। फ़र्क़ सिर्फ़ इतना है कि बड़े कंप्यूटर बड़े काम (लाखों आँकड़े, भारी चित्र) तेज़ी से करते हैं; पर सीखने के लिए — हुक्म, डिब्बे, फ़ैसले, दोहराव — फ़ोन का मुनीम पूरी तरह काफ़ी है। भाषा सीखने के लिए सबसे महँगा कंप्यूटर उतना ही ज़रूरी है जितना हिंदी सीखने के लिए सबसे महँगी क़लम। और ACS का पूरा रास्ता इसी पर टिका है: "फ़ोन ही पाठशाला" — Constitution का नियम: Android 8 पर भी चले।

और "जिसके पास न फ़ोन अच्छा, न इंटरनेट" — उसके लिए आज का तीसरा रास्ता है, और वह सचमुच बराबर का रास्ता है। प्रोग्रामिंग का दिल मशीन नहीं, सोच है: हुक्म का क्रम, हर हुक्म का असर, ग़लती कहाँ होगी — यह सब काग़ज़ पर सूखी-दौड़ से उतना ही सीखा जाता है। इतिहास गवाह है: कंप्यूटर के शुरुआती दिनों में प्रोग्रामर अपना code काग़ज़ पर लिखते, हाथ से जाँचते, और कंप्यूटर पर चलाने का मौक़ा दिनों में एक बार मिलता था — और उन्हीं ने आज की पूरी दुनिया की नींव रखी। आज भी अच्छे प्रोग्रामर कठिन हिस्से पहले काग़ज़ पर सोचते हैं (भाग-अ की वही सीख)। इसलिए इस किताब ने हर Python-डिब्बे के साथ नतीजा छापने का वादा किया है — ताकि कोई भी पाठक, किसी भी हाल में, पीछे न छूटे। मशीन मदद है; सीखना सोच से होता है।

अभ्यास-खेल: मुनीम-मश्क़

(ग) क्या मैं ऐप लगा सकता/सकती हूँ (18 से कम — घर के बड़े से पूछकर)? — जवाबों से अपना रास्ता चुनिए (एक, दो, या तीसरा — या मिलाकर: घर में ऐप, बाहर सूखी-दौड़!), कारण-सहित।

खेल 2 — पहली जाँच (रास्ता-1 या 2 मिले तो): चुने हुए रास्ते में ख़ाली ख़ाना खोलिए, और बिल्कुल वही लिखिए जो पाठ-129 में था: print(2+3) — Run। नीचे 5 आया? (आया = आपका मुनीम तैयार!) न आया, तो लिखा हुआ अक्षर-अक्षर मिलाइए — कोष्ठक दोनों? "print" छोटे अक्षरों में? (पूरा दवाख़ाना पाठ-136 में — आज बस इतना कि घबराना नहीं!) ऐप-रास्ता हो, तो फ़ाइल को सहेजिए: pehla.py।

खेल 3 — सावधानी की घर-बैठक + सूखी-दौड़ की तैयारी: घर के किसी बड़े को आज की पाँच सावधानियाँ सुनाइए — ख़ासकर "APK-न्योते कभी नहीं" और "कोई भुगतान नहीं"। फिर सूखी-दौड़ के लिए कॉपी का एक हिस्सा तय कीजिए: "सूखी-दौड़ पन्ना" — हर code के लिए तीन ख़ाने: code · मेरा अंदाज़ा · किताब/मशीन का नतीजा। कल से हर Python-डिब्बा इसी पन्ने पर भी उतरेगा — मशीन हो या न हो।

आगे क्या सीखेंगे

मुनीम मिल गया — browser-रास्ता, ऐप-रास्ता, और सूखी-दौड़ (बराबर का रास्ता!); पाँच सावधानियाँ; चिह्न टाइप करने, .py पूँछ और संस्करण के फ़र्क़ की बातें; और ⏱ जाँची-तारीख़ की ईमानदारी। आपका सूखी-दौड़ पन्ना तैयार है।

कल वह पल आता है जो पाठ-63 का भाग-स वाला जुड़वाँ है — पहली बार Python से बुलवाना। पर रीत वही पुरानी, PRIMM की पहली दो सीढ़ियाँ: पहले 🔮 अंदाज़ा — print("Namaste") परदे पर क्या छापेगा? उल्टे-कॉमा भी छपेंगे? कोष्ठक? — दाँव-बही में लिखा, कारण-सहित; फिर ▶ चलाओ — और मिलान। साथ में दुनिया भर के प्रोग्रामरों की वह पुरानी रस्म जिसका html-रूप आप पाठ-63 में निभा चुके हैं: पहली भाषा में पहला "नमस्ते दुनिया"। पाठ-131: 🔮 अंदाज़ा → ▶ चलाओ — print("नमस्ते")।
