पाठ परिचय

पाठ-64 याद कीजिए — html के पहले code को "बरतने" के बाद आपने उसकी नसें खोली थीं: tag के तीन अंग, / का मतलब, browser का पढ़ने का क्रम — और एक औज़ार पाया था, "बदल-के-देखो सवाल": नक़ल में एक चीज़ हटाओ या बदलो, दाँव लगाओ, चलाओ — जो टूटा, वही उस चीज़ का काम था। आज वही सीढ़ी — PRIMM की तीसरी, 🔍 जाँचो — Python के print पर।

कल print("Namaste Duniya") चला और आपने चार हिस्से गिने: नाम, मुँह खुला, माल, मुँह बंद। पर क्यों? कोष्ठक न हों तो? उल्टे-कॉमा न हों तो? इकहरे (') लगा दें तो? और सबसे मज़ेदार सवाल: print(2+3) ने 5 छापा था (पाठ-129) — तो print("2+3") क्या छापेगा? बस दो उल्टे-कॉमा का फ़र्क़!

आज के जवाब से Python की सबसे बुनियादी समझ खुलेगी — माल की दो क़िस्में: शब्द (जो जैसे-के-तैसे छपें) और गिनती (जिनका हिसाब हो)। यह फ़र्क़ आगे के हर अध्याय की नींव है। प्रयोग-पर्चा (पाठ-19) और एक-बदलाव नियम (पाठ-42) साथ रखिए। चलिए — print की नसें खोलते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. कोष्ठक का काम बोल पाएँगे — हुक्म का मुँह: बिना मुँह के Python हुक्म को अधूरा मानता है।

2. उल्टे-कॉमा का राज़ समझा पाएँगे — "शब्द-माल" (string — स्ट्रिंग) की हद; और print("2+3") बनाम print(2+3) का फ़र्क़।

3. इकहरे-दोहरे उल्टे-कॉमा, उल्टे-कॉमा के भीतर उल्टे-कॉमा, और कॉमा से कई माल बरत पाएँगे।

मुँह, हद, और माल की दो क़िस्में

सबसे पहले — दो उल्टे-कॉमा का फ़र्क़: 🔮 अंदाज़ा लगाइए, दोनों पंक्तियों पर अलग-अलग दाँव — पहली क्या छापेगी, दूसरी क्या? —

print("2+3")
print(2+3)

नतीजा: पहली पंक्ति 2+3 (अक्षर-अक्षर), दूसरी 5 (हिसाब)। यही आज का दिल है — Python में माल की दो क़िस्में: शब्द-माल (string — स्ट्रिंग: उल्टे-कॉमा के भीतर) — Python उसे छूता नहीं, जैसा लिखा वैसा छापता है (html की दीवार जैसा!); गिनती-माल (number — नंबर: बिना उल्टे-कॉमा के अंक) — Python उसका हिसाब करता है (मुनीम!)। उल्टे-कॉमा Python से कहते हैं: "यह शब्द है — इसे मत सोचो, बस छापो।" (कॉपी में मोटा — आगे के हर अध्याय में यह फ़र्क़ बार-बार लौटेगा।)

बदल-के-देखो-1 · उल्टे-कॉमा हटाओ: print(Namaste) — 🔮 दाँव: क्या होगा? — Python एक लाल संदेश देता है: NameError: name 'Namaste' is not defined — "Namaste नाम की कोई चीज़ मुझे नहीं पता"। क्यों? बिना उल्टे-कॉमा के Python Namaste को शब्द नहीं, किसी चीज़ का नाम समझता है — जैसे print ख़ुद एक नाम है (हुक्म का)! और उस नाम की कोई चीज़ उसने कभी देखी नहीं। (यही "नाम" अगले अध्याय का पूरा विषय है — डिब्बे, जिन्हें नाम देकर माल रखा जाता है; तब print(Namaste) सचमुच कुछ छापेगा!) सीख: शब्द छापना है, तो उल्टे-कॉमा ज़रूरी; अंक छापना है, तो नहीं।

बदल-के-देखो-2 · कोष्ठक हटाओ: print "Namaste" — Python का संदेश: SyntaxError: Missing parentheses in call to 'print'. Did you mean print(...)? — वह ख़ुद बता रहा है कि कोष्ठक भूले! कोष्ठक हुक्म का मुँह हैं: print नाम है, और कोष्ठक कहते हैं "इस हुक्म को अभी चलाओ, और भीतर का माल उसे दो"। बिना मुँह के हुक्म बस एक शब्द है, जो कुछ नहीं करता। (मुँह और नाम के बीच space — print ("Namaste") — Python माफ़ कर देता है; पर कारीगर-रीत: सटाकर लिखो, print("...") — पढ़ने में साफ़, दुनिया भर की आदत।)

बदल-के-देखो-3 · इकहरे उल्टे-कॉमा, और भीतर उल्टे-कॉमा: 🔮 तीनों पंक्तियों पर दाँव — क्या इकहरे (') चलेंगे? भीतर वाले उल्टे-कॉमा छपेंगे? कॉमा से दो माल? —

print('Namaste')
print("Ram ki 'gaay' doodh deti hai")
print("Namaste", "Duniya")

नतीजा: Namaste — इकहरे भी उतने ही ठीक (Python दोनों को बराबर मानता है; बस खोलो-बंद एक ही क़िस्म के — ' से खोला तो ' से बंद); Ram ki 'gaay' doodh deti hai — दोहरे के भीतर इकहरे छप गए! (बाहर की हद दोहरी है, तो भीतर के इकहरे माल का हिस्सा बन जाते हैं — घोंसले जैसा, पाठ-66); और Namaste Duniya — कॉमा से दो माल, और Python ने बीच में अपने-आप एक space डाल दिया। तीन बातें कॉपी में: (1) ' और " दोनों ठीक, पर जोड़ी एक-सी; (2) माल में उल्टे-कॉमा छापने हों, तो बाहर दूसरी क़िस्म के; (3) कॉमा = "अगला माल", बीच में space अपने-आप।

रेखा-चित्र: मुँह, हद और दो क़िस्में

नीचे आज का पूरा पट्ट — शब्द-माल बनाम गिनती-माल, तीन बदल-के-देखो प्रयोग, और उल्टे-कॉमा के क़ायदे —

ऊपर के दो डिब्बे आज की सबसे बड़ी सीख हैं — उल्टे-कॉमा की एक जोड़ी तय करती है कि Python दीवार बनेगा या मुनीम।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "इतने चिह्न — कोष्ठक, उल्टे-कॉमा, इकहरे-दोहरे — यह सब याद रखना बहुत भारी है! Python तो इतना होशियार है, वह ख़ुद समझ ले कि Namaste शब्द है और 2+3 हिसाब। उल्टे-कॉमा की ज़िद बेकार की है।"

सच: "Python ख़ुद समझ ले" — यह वही माँग है जो पाठ-71 में html के बंद-tag से की गई थी ("browser ख़ुद समझ ले कि मोटाई कहाँ तक") — और जवाब भी वही: अंदाज़े की सरकार आफ़त है। सोचिए Python को अंदाज़ा लगाना पड़े: print(Namaste) — शब्द है? या किसी डिब्बे का नाम (अगले अध्याय में डिब्बों के नाम ठीक ऐसे ही होंगे!)? print(2+3) — हिसाब है, या कोई शब्द जो किसी ने टेलीफ़ोन-नंबर जैसा लिखा? print(12) — गिनती बारह, या किसी बस का नंबर "12" (जिससे हिसाब नहीं करना)? हर सवाल पर Python को आपकी मंशा का अंदाज़ा लगाना पड़ता — और मशीन मंशा नहीं पढ़ती (भाग-अ का सबसे पुराना सच!)। एक बार अंदाज़ा ग़लत, और आपका "बस-नंबर 12" किसी हिसाब में जुड़ जाता। उल्टे-कॉमा उस अंदाज़े को ख़त्म करते हैं: आप साफ़ बता देते हैं, Python साफ़ करता है।

और "भारी है" — गिनिए, असल में कितना याद रखना है: दो बातें। (1) हुक्म के बाद मुँह: ( ); (2) शब्द को उल्टे-कॉमा में। बस। इकहरे-दोहरे का क़ायदा "एक-सी जोड़ी" — वही जोड़ी-सिद्धांत जो आप अध्याय-10 से निभा रहे हैं (खोलो-बंद एक ही tag!)। और सबसे बड़ी राहत: अगर भूले, तो Python चुप नहीं रहता — आज ही देखा: "Missing parentheses... Did you mean print(...)?" — वह ख़ुद बता देता है क्या भूले। CSS की चुप बीमारियाँ याद कीजिए (पाठ-107) — वहाँ भूला चिह्न आपको घंटों ढुँढवाता था; Python का भूला चिह्न एक पंक्ति में पकड़ा जाता है। चिह्न बोझ नहीं — साफ़ बात कहने का औज़ार हैं, और भूलने पर Python ख़ुद याद दिलाता है।

अभ्यास-खेल: जाँच-मश्क़

खेल 1 — शब्द या गिनती? अदालत: कॉपी में आठ पंक्तियाँ — हर एक पर दाँव: क्या छपेगा? (मशीन हो तो चलाकर मिलाइए, न हो तो किताब के नियम से सूखी-दौड़): (क) print("10-4") (ख) print(10-4) (ग) print("7") (घ) print(7) (ङ) print("Ram") (च) print('Sita') (छ) print("Mera ank", 90) (ज) print("5", 5)। — (ग) और (घ) परदे पर एक-से दिखते हैं (7) — पर Python के लिए अलग क्यों हैं? (एक शब्द, एक गिनती — कल के पाठ में यह फ़र्क़ एक प्रयोग में चीख़ेगा!)

खेल 2 — बदल-के-देखो, प्रयोग-पर्चे के साथ: नक़ल पर तीन प्रयोग, हर एक का पूरा प्रयोग-पर्चा (पाठ-19: क्या बदला · दाँव · नतीजा · सीख): (क) print("Namaste") में बंद-उल्टा-कॉमा हटाओ (ख) खुला कोष्ठक हटाओ (ग) print को Print लिखो (बड़ा P)। तीनों के लाल संदेश की आख़िरी पंक्ति कॉपी में उतारिए — परसों के पाठ (ग़लती-संदेश से दोस्ती) में यही तीन पंक्तियाँ आपकी पहली पढ़ाई बनेंगी। (मशीन न हो, तो बस दाँव लिखिए — पाठ-134 में मिलान!)

खेल 3 — उल्टे-कॉमा की पहेली + हुक्म-बही: ऐसा print बनाइए जो परदे पर ठीक यह छापे: Dadi boli: 'jo seekhe so paaye' — (संकेत: भीतर इकहरे हैं, तो बाहर?) फिर ऐसा जो छापे: Namaste Duniya 2026 — दो माल से (एक शब्द, एक गिनती, कॉमा से)। हुक्म-बही में print की पंक्ति में नए नोट: "मुँह = ( ) · शब्द = उल्टे-कॉमा · गिनती = बिना · कॉमा = अगला माल"।

आगे क्या सीखेंगे

print की नसें खुल गईं — कोष्ठक हुक्म का मुँह, उल्टे-कॉमा शब्द-माल की हद, माल की दो क़िस्में (शब्द और गिनती — आज की सबसे बड़ी कमाई!), इकहरे-दोहरे का एक-सी-जोड़ी क़ायदा, भीतर दूसरी क़िस्म, और कॉमा से कई माल। साथ में पहली झलक: Python ग़लती पर चुप नहीं रहता।

कल PRIMM की चौथी सीढ़ी — ✏ बदलो: किताब का code अपनाकर अपना बनाना। और आज कुछ बड़ा: तीन लाइन की कविता छपवाओ — दादी की कोई कहावत, कोई दोहा, या अपनी लिखी तीन पंक्तियाँ — हर पंक्ति अपने print में; बीच में एक ख़ाली पंक्ति कैसे (एक बिना-माल वाला print!); कविता का शीर्षक; और html की कविता (पाठ-74 का br वाला दोहा) से उसकी तुलना। साथ में पाठ-65 वाला लिपि-उत्सव, Python में: कविता अपनी लिपि में। पाठ-133: ✏ बदलो — तीन लाइन की कविता छपवाओ।
