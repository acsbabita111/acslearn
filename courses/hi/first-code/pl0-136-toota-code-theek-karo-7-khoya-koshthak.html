पाठ परिचय

बीमारी-पट्टी खोलिए — तेईस नाम (html की बनावट, चित्र-कड़ी, तालिका-सूची, CSS-रंग, जमावट), और परसों आपने उसके नीचे एक नया हिस्सा शुरू किया: "Python बीमारी-पट्टी — बीमारी-24 से"। आज उसकी पहली पाँच पंक्तियाँ भरेंगी।

और आज का दवाख़ाना पिछले छह से बिल्कुल अलग है। html का मरीज़ गूँगा था — बस अजीब दिखता था (मोटा बहाव, भटका माल), और आपको लक्षण से जड़ तक ख़ुद पहुँचना पड़ता था। CSS का मरीज़ तो और भी चुप — कुछ दिखता ही नहीं था, जासूस-रंग से टटोलना पड़ता था। Python का मरीज़ बोलता है: "मुझे line 3 पर, ठीक यहाँ (^), यह बीमारी है।" वैद्य का आधा काम मरीज़ ख़ुद कर देता है!

पर बोलते मरीज़ की बात भी सुननी पड़ती है — और वह परसों सीखा: चिट्ठी नीचे से ऊपर, तीन सवाल (क्या? कहाँ? ठीक कहाँ?)। आज वही स्टेथोस्कोप पाँच असली मरीज़ों पर — Python सीखने वालों की सबसे आम, सबसे पहली पाँच बीमारियाँ, जिनमें से एक सिर्फ़ फ़ोन पर होती है, और जिसे आपका कीबोर्ड चुपचाप पैदा करता है। दस्ताने पहनिए — मरीज़ बोलने को तैयार है।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बीमारी 24-28 उनकी असली चिट्ठी से पहचान पाएँगे — खोया कोष्ठक, खोया उल्टा-कॉमा, बिना-कॉमा शब्द, बड़े-छोटे अक्षर, टेढ़े उल्टे-कॉमा।

2. हर बीमारी पर वैद्य-रीत चला पाएँगे — चिट्ठी नीचे से ऊपर पढ़ो → जड़ → एक इलाज → फिर चलाओ।

3. बीमारी-परिवार पहचान पाएँगे — SyntaxError वाले (कुछ नहीं चला) बनाम NameError वाले (बीच में रुका)।

पाँच बोलते मरीज़

बीमारी-24 · खोया बंद-कोष्ठक — print("Ek" (मुँह खुला, बंद नहीं)। चिट्ठी:

  File "bimar.py", line 1
    print("Ek"
         ^
SyntaxError: '(' was never closed

नीचे से: क्या? — "( कभी बंद नहीं हुआ" · कहाँ? — line 1 · ठीक कहाँ? — ^ खुले कोष्ठक के नीचे। इलाज: पंक्ति के अंत में ) — जोड़ी-सिद्धांत, Python में भी। ध्यान: कई पंक्तियों के प्रोग्राम में ^ उस पंक्ति पर इशारा करता है जहाँ कोष्ठक खुला था — बीमारी वहीं है, भले Python को पता बाद में चला। (उलटी बीमारी — फ़ालतू ) — print("Ek")) — पर चिट्ठी: unmatched ')' — "बिना जोड़ी का )"।)

बीमारी-25 · खोया उल्टा-कॉमा — print("Ek) (शब्द का अंत भूला):

  File "bimar.py", line 1
    print("Ek)
          ^
SyntaxError: unterminated string literal (detected at line 1)

क्या? — "string literal" (शब्द-माल) "unterminated" (बिना अंत का) — शब्द शुरू हुआ, ख़त्म नहीं; ठीक कहाँ? — ^ खुले उल्टे-कॉमा पर: "यहाँ से शुरू हुआ शब्द कभी बंद नहीं हुआ"। Python को दिक़्क़त यह है कि बंद-कोष्ठक ) भी शब्द के भीतर समझा गया! इलाज: Ek के बाद " लगाइए।

बीमारी-26 · उल्टे-कॉमा बिना शब्द — print(Ek) — पाठ-132 और 134 वाला पुराना दोस्त:

Traceback (most recent call last):
  File "bimar.py", line 1, in <module>
    print(Ek)
          ^^
NameError: name 'Ek' is not defined

क्या? — "Ek नाम की कोई चीज़ नहीं" — Python ने शब्द को नाम समझा। इलाज: "Ek"। परिवार-पहचान: Traceback वाला शीर्षक मौजूद — चलते-चलते की बीमारी (ऊपर की पंक्तियाँ छप चुकी होंगी)।

बीमारी-27 · बड़े-छोटे अक्षर की गड़बड़ — Print("Ek") (बड़ा P), या prnt (अक्षर छूटा):

Traceback (most recent call last):
  File "bimar.py", line 1, in <module>
    Print("Ek")
    ^^^^^
NameError: name 'Print' is not defined. Did you mean: 'print'?

क्या? — "Print नहीं पता — क्या आप print कहना चाहते थे?" Python के लिए P और p बिल्कुल अलग अक्षर हैं (CSS के रंग-नामों जैसी माफ़ी नहीं — वहाँ Red और red एक थे, पाठ-101; Python में हर नाम पर पाठ-106 वाली class जैसी सख़्ती!)। सुराग़ ख़ुद इलाज बता रहा है। फ़ोन की एक आदत ध्यान रखिए: कीबोर्ड पंक्ति का पहला अक्षर अपने-आप बड़ा कर देता है — इसलिए Print सबसे आम बीमारियों में है!

बीमारी-28 · टेढ़े उल्टे-कॉमा (फ़ोन-ख़ास) — print(“Ek”) — कीबोर्ड ने सीधे " को "सुंदर" टेढ़े “ ” में बदल दिया:

  File "bimar.py", line 1
    print(“Ek”)
          ^
SyntaxError: invalid character '“' (U+201C)

क्या? — "invalid character" (अमान्य अक्षर) — Python टेढ़े उल्टे-कॉमा को पहचानता ही नहीं! आँख से दोनों लगभग एक-से दिखते हैं — यही इस बीमारी का धोखा है। ठीक कहाँ? — ^ टेढ़े अक्षर पर, और चिट्ठी उसका पूरा नाम भी देती है (U+201C — दुनिया के अक्षर-कोश में उसका अंक)। इलाज: टेढ़े हटाकर सीधे " टाइप कीजिए; पक्का इलाज — कीबोर्ड की सेटिंग में "स्मार्ट उल्टे-कॉमा" जैसी सुविधा बंद करना (अगर हो), या Python-ऐप का अपना कीबोर्ड-पट्टी वाला " बरतना (पाठ-130)।

पाँचों का इलाज एक साथ — 🔮 अंदाज़ा: नीचे के सुधरे प्रोग्राम में हर पंक्ति किस बीमारी की दवा है? और परदा? —

print("Ek")
print("Do")
print("Teen")
print("Char")
print("Paanch")

मिलान: पाँचों पंक्तियाँ अब सेहतमंद — बंद कोष्ठक (24), बंद उल्टा-कॉमा (25), शब्द उल्टे-कॉमा में (26), छोटा p (27), सीधे उल्टे-कॉमा (28)। परदा: Ek, Do, Teen, Char, Paanch।

रेखा-चित्र: दवाख़ाना-7

नीचे पाँच बोलते मरीज़ — हर एक की चिट्ठी की आख़िरी पंक्ति, परिवार, और इलाज —

पाँचों डिब्बों में बीच की पंक्ति चिट्ठी की आख़िरी पंक्ति है — वही पंक्ति जो पढ़ते ही बीमारी का नाम बता देती है; रंग बताता है परिवार, और हरी पंक्ति इलाज।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "Python इतना नख़रेबाज़ क्यों है! एक कोष्ठक भूला, एक अक्षर बड़ा हुआ, उल्टे-कॉमा थोड़े टेढ़े — और पूरा प्रोग्राम ठप! इंसान तो समझ जाता कि मेरा मतलब क्या था। यह मशीन मूर्ख है।"

सच: "इंसान समझ जाता" — हाँ, और यही इंसान और मशीन का सबसे बड़ा फ़र्क़ है, जो भाग-अ के पहले पन्नों से यह कोर्स कह रहा है: इंसान मतलब पढ़ता है, मशीन हुक्म। पर सोचिए, मशीन अगर "मतलब समझने" लगे — तो किसका मतलब? Print और print अलग हो सकते हैं (आगे आप ख़ुद ऐसे नाम बनाएँगे, और बड़े-छोटे अक्षर से फ़र्क़ करना पड़ेगा!); टेढ़ा “ किसी भाषा में शब्द का हिस्सा हो सकता है; भूला कोष्ठक — कहाँ बंद करना था, एक पंक्ति बाद या दस? अंदाज़ा लगाने वाली मशीन कभी-कभी ग़लत अंदाज़ा लगाती — और आपका प्रोग्राम चुपचाप कुछ और कर देता, बिना बताए (CSS की चुप बीमारी, Python में!)। Python ने उल्टा रास्ता चुना: "मुझे पक्का नहीं पता, तो मैं रुकूँगा और पूछूँगा"। यह नख़रा नहीं — ईमानदारी है।

और "मशीन मूर्ख है" — ज़रा आज की चिट्ठियों को फिर देखिए: "Did you mean: 'print'?" — मूर्ख मशीन यह नहीं कहती! Python आपकी ग़लती पकड़ता है, ठीक पंक्ति और ठीक अक्षर दिखाता है, बीमारी का नाम बताता है, और कई बार इलाज तक सुझाता है। वह सख़्त है, मूर्ख नहीं — जैसे अच्छा उस्ताद, जो आधे-अधूरे काम को "चल जाएगा" नहीं कहता, पर ग़लती की जगह उँगली रखकर बताता है। और यह सख़्ती आपको एक बड़ा तोहफ़ा देती है: आपके हाथ सटीक बनते हैं — दो हफ़्ते की Python के बाद आप कोष्ठक, उल्टे-कॉमा, अक्षरों पर इतने सधे होंगे कि किसी भी भाषा, किसी भी औज़ार में वही सटीकता काम आएगी (सरकारी फ़ॉर्म, बैंक-पर्ची, हिसाब-बही — हर जगह)। सख़्त मशीन सटीक कारीगर बनाती है।

अभ्यास-खेल: दवाख़ाना-7 मश्क़

खेल 1 — पाँच मरीज़, पाँच पर्चे: पाँच-पंक्ति का सेहतमंद प्रोग्राम (ऊपर वाला) लीजिए, और उसकी पाँच नक़लें — हर एक में ठीक एक बीमारी (24 से 28, एक-एक)। हर नक़ल पर: चलाइए → चिट्ठी की तीन बातें कॉपी में (आख़िरी पंक्ति · line · ^) → कुछ छपा या नहीं? → इलाज → फिर चलाइए। (मशीन न हो, तो इस पाठ की चिट्ठियों से सूखी-दौड़: कौन-सी चिट्ठी किस नक़ल की होती?) पाँचों पर्चे Python बीमारी-पट्टी में — नाम · आख़िरी पंक्ति · छपा कुछ? · इलाज।

खेल 2 — छिपा मरीज़ (बीच की पंक्ति): पाँच-पंक्ति प्रोग्राम में तीसरी पंक्ति में बीमारी-26 डालिए (print(Teen))। 🔮 दाँव: परदे पर क्या-क्या दिखेगा? — फिर उसी प्रोग्राम में तीसरी पंक्ति में बीमारी-24 (खोया कोष्ठक) — अब? दोनों नतीजों से नियम दोबारा अपनी आँख से: NameError से पहले की पंक्तियाँ छपती हैं, SyntaxError में कुछ नहीं।

खेल 3 — अपने फ़ोन की बीमारी-28: अपने फ़ोन के कीबोर्ड पर उल्टे-कॉमा टाइप करके देखिए — सीधे (") आते हैं या टेढ़े (“ ”)? किसी नोट-ऐप में दोनों अगल-बग़ल लिखकर ध्यान से फ़र्क़ देखिए। अगर टेढ़े आते हैं, तो कीबोर्ड की सेटिंग्स में ऐसी कोई सुविधा खोजिए ("smart quotes" या ऐसा कुछ — हर कीबोर्ड में अलग; न मिले तो Python-ऐप की अपनी चिह्न-पट्टी)। जो मिला, कॉपी में — यह आपके फ़ोन का अपना इलाज-नोट है।

आगे क्या सीखेंगे

सातवाँ दवाख़ाना पार — पहला बोलता मरीज़: पाँच बीमारियाँ (24-28), हर एक की असली चिट्ठी, नीचे-से-ऊपर के तीन सवाल, दो परिवार (SyntaxError — कुछ नहीं चला; NameError — बीच में रुका), और फ़ोन-ख़ास टेढ़े उल्टे-कॉमा का धोखा। Python बीमारी-पट्टी की पहली पाँच पंक्तियाँ भरीं।

और अब अध्याय-16 का आख़िरी पाठ — बनाओ! Python में आपका पहला प्रोग्राम — एक छोटा "परिचय-कार्ड" जो परदे पर छपे: ऊपर-नीचे सजावटी रेखा (एक मज़ेदार चाल से — शब्द का गुणा!), नाम, गाँव-ज़िला (लक्ष्मण-रेखा code में भी!), हुनर, सपना, और कोर्स में अपनी प्रगति का प्रतिशत — Python ख़ुद गिनेगा। print, शब्द-माल, गिनती-माल, कॉमा, गुणा-पहले नियम, बँटवारा — अध्याय-16 की पूरी पेटी एक प्रोग्राम में। पाठ-137: 🛠 बनाओ — नाम-पता-सपना छापने वाला पहला प्रोग्राम।
