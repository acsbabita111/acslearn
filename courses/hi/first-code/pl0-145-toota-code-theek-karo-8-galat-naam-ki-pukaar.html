पाठ परिचय

गाँव की चौपाल पर कोई "रमेस!" पुकारे — तो रमेश मुड़ जाता है; इंसान अधूरी पुकार भी समझ लेता है। पर कोई "सुरेश!" पुकारे जबकि वहाँ सुरेश नाम का कोई है ही नहीं — तो कोई नहीं मुड़ता। और अगर कोई ऐसे आदमी को पुकारे जो अभी गाँव पहुँचा ही नहीं — तो भी जवाब में चुप्पी।

Python में डिब्बे को पुकारना — print(umar), kul = bhav * kilo — ऐसी ही पुकार है, बस Python इंसान जितना माफ़ नहीं करता: एक अक्षर ग़लत, और डिब्बा नहीं मिलता। आज प्रोग्राम का दवाख़ाना-8 — इस अध्याय की बीमारियाँ, सबकी सब डिब्बों के नाम और पुकार से जुड़ीं। Python बीमारी-पट्टी में 24-28 भर चुकी हैं; आज 29-33।

और एक अच्छी ख़बर: इन बीमारियों में Python का सबसे मददगार सुराग़ जागता है — "Did you mean: 'umar'?" — यह सुराग़ आपके अपने बनाए डिब्बों के नाम तक सुझाता है! पर साथ में एक सच्ची चेतावनी भी (आज एक मरीज़ पर दिखेगी): सुराग़ Python का अंदाज़ा है — कभी-कभी वह ग़लत दिशा में भी इशारा करता है। वैद्य सुराग़ पढ़ता है, पर फ़ैसला अपनी जाँच से करता है। चलिए — पुकार की जाँच करते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बीमारी 29-33 उनकी असली चिट्ठी से पहचान पाएँगे — ग़लत वर्तनी, बड़े-छोटे, भरने से पहले पुकार, हुक्म-नाम डिब्बा, नाम में space-डैश।

2. "Did you mean" सुराग़ बरत पाएँगे — और पहचान पाएँगे कि वह कब ग़लत दिशा में इशारा करता है।

3. डिब्बा-तालिका और चिट्ठी, दोनों मिलाकर "डिब्बा कहाँ भरा, कहाँ पुकारा" की जाँच कर पाएँगे।

पाँच ग़लत पुकारें

बीमारी-29 · ग़लत वर्तनी की पुकार — डिब्बा umar बनाया, पुकारा umr:

Traceback (most recent call last):
  File "dibba.py", line 2, in <module>
    print(umr)
          ^^^
NameError: name 'umr' is not defined. Did you mean: 'umar'?

नीचे से: "umr नहीं पता — क्या umar कहना था?" — Python ने आपके अपने डिब्बों में मिलता-जुलता नाम खोजा और सुझा दिया! इलाज: वर्तनी हूबहू। (लंबे नाम पर यह बीमारी ज़्यादा होती है — पाठ-143 की "बहुत लंबा नहीं" वाली तमीज़ यहीं काम आती है।)

बीमारी-30 · बड़े-छोटे की उलझन — Naam = "Sita" बनाया (बड़ा N — शायद फ़ोन ने पहला अक्षर अपने-आप बड़ा किया!), पुकारा naam:

Traceback (most recent call last):
  File "dibba.py", line 2, in <module>
    print(naam)
          ^^^^
NameError: name 'naam' is not defined. Did you mean: 'Naam'?

Python के लिए Naam और naam दो अलग डिब्बे — और उसने ख़ुद पकड़ा कि आपके पास "Naam" है। इलाज: एक ढंग चुनिए (पाठ-143: सब छोटे अक्षर) और उसी पर टिकिए — बनाने वाली पंक्ति भी, पुकार भी।

बीमारी-31 · भरने से पहले पुकार — print(kul) पहले, kul = 135 बाद में:

Traceback (most recent call last):
  File "dibba.py", line 1, in <module>
    print(kul)
          ^^^
NameError: name 'kul' is not defined

इस बार कोई "Did you mean" नहीं — क्योंकि उस पल तक कोई डिब्बा बना ही नहीं था, सुझाने को कुछ नहीं। जड़: क्रम — Python ऊपर से नीचे चलता है (पाठ-133); पंक्ति-1 पर kul अभी "गाँव पहुँचा ही नहीं"। यह बीमारी अक्सर तब होती है जब कोई पंक्ति इधर-उधर खिसकाई जाती है। इलाज: डिब्बा-तालिका (पाठ-140) से देखिए — डिब्बा किस पंक्ति पर पहली बार भरा, और पुकार उसके बाद है या पहले?

बीमारी-32 · हुक्म-नाम वाला डिब्बा — कल का चुप ख़तरा: print = 5, फिर print("Sita") → TypeError: 'int' object is not callable। चिट्ठी पंक्ति-2 पर आती है, ग़लती पंक्ति-1 में है — "ग़लती ऊपर, चिट्ठी नीचे"। पहचान का सुराग़: जब कोई जाना-पहचाना हुक्म (print, type, input) अचानक "not callable" कहे, तो ऊपर खोजिए — कहीं उसी नाम पर डिब्बा तो नहीं भरा? इलाज: डिब्बे का नाम बदलिए (ank, kul — कुछ भी जो हुक्म न हो)। (फ़ोन-ऐप में अगर पूरा प्रोग्राम दोबारा चलाने पर भी print टूटा रहे, तो ऐप बंद-चालू कीजिए — कुछ ऐप पुराने डिब्बे याद रखते हैं।)

बीमारी-33 · नाम में space या डैश — mera naam = "Sita" → SyntaxError: invalid syntax; और mera-naam = "Sita":

  File "dibba.py", line 1
    mera-naam = "Sita"
    ^^^^^^^^^
SyntaxError: cannot assign to expression here. Maybe you meant '==' instead of '='?

यहाँ सुराग़ ग़लत दिशा में है! Python कहता है "शायद == कहना था?" — पर असली जड़ डैश है (Python को mera-naam "mera माइनस naam" लगा — एक हिसाब, जिसमें कुछ रखा नहीं जा सकता)। सीख: "Did you mean" Python का अंदाज़ा है, फ़ैसला नहीं — वैद्य पर्ची पढ़ता है, पर नब्ज़ ख़ुद देखता है। इलाज: mera_naam (अंडरस्कोर — पाठ-143)।

पाँचों का इलाज एक साथ — 🔮 अंदाज़ा: नीचे का सेहतमंद प्रोग्राम किस बीमारी की दवा कहाँ लिए है? परदा? —

mera_naam = "Sita"
umar = 14
bhav = 45
kilo = 3
kul = bhav * kilo
print(mera_naam, umar)
print("Kul:", kul)

मिलान: अंडरस्कोर वाला नाम (33), सब छोटे अक्षर (30), हर पुकार की वर्तनी बनाने वाली पंक्ति जैसी (29), kul पहले भरा फिर पुकारा (31), कोई हुक्म-नाम डिब्बा नहीं (32)। परदा: Sita 14 और Kul: 135।

रेखा-चित्र: दवाख़ाना-8

नीचे पाँच ग़लत पुकारें — हर एक की चिट्ठी, सुराग़ मिला या नहीं, और इलाज —

पाँचों डिब्बों में तीसरी पंक्ति देखिए — दो में सुराग़ सीधा इलाज तक ले गया, तीन में नहीं; इसीलिए चिट्ठी के साथ अपनी डिब्बा-तालिका भी चाहिए।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "Python तो 'Did you mean' बता ही देता है — तो सोचने की क्या ज़रूरत? जो सुझाए, आँख बंद करके कर दो! वह मशीन है, ग़लत नहीं हो सकती।"

सच: आज की बीमारी-33 ने ही इस ग़लतफ़हमी को तोड़ दिया: mera-naam पर Python ने सुझाया "शायद == कहना था?" — आँख बंद करके मानते, तो mera-naam == "Sita" लिखते, और एक नई, ज़्यादा उलझी बीमारी पैदा होती (mera और naam नाम के डिब्बे खोजे जाते — दोनों मौजूद नहीं!)। Python का सुराग़ एक अंदाज़ा है, जो वह कुछ आम ग़लतियों के नमूनों से लगाता है — ज़्यादातर बार सही (umr → umar, naam → Naam), पर हर बार नहीं। और कुछ बीमारियों में सुराग़ आता ही नहीं (बीमारी-31), या ग़लत जगह की ओर ले जाता है (बीमारी-32: चिट्ठी पंक्ति-2 पर, ग़लती पंक्ति-1 में)। यह पाठ-115 वाली u-कहानी जैसा है — इशारे काम के होते हैं, पर इशारा सच की जगह नहीं लेता।

दूसरी बात: "मशीन ग़लत नहीं हो सकती" — मशीन गिनती में ग़लत नहीं होती (पाठ-135); पर अंदाज़े में — कि आपका मतलब क्या था — वह इंसान से भी कमज़ोर है (भाग-अ का सबसे पुराना सच: मशीन मतलब नहीं पढ़ती)। "Did you mean" ठीक वही हिस्सा है जहाँ मशीन आपका मतलब अंदाज़ने की कोशिश करती है — इसलिए वहीं सबसे ज़्यादा सावधानी चाहिए। वैद्य की तरह सोचिए: सुराग़ (लक्षण) → अपनी जाँच (डिब्बा-तालिका: कौन-सा डिब्बा कहाँ भरा, कहाँ पुकारा?) → फ़ैसला → एक इलाज → फिर चलाओ। यही वह रीत है जो सात दवाख़ानों से आप निभा रहे हैं; Python का सुराग़ उसमें एक मदद जुड़ा है, रीत की जगह नहीं। सुराग़ सुनो, फ़ैसला अपना।

अभ्यास-खेल: दवाख़ाना-8 मश्क़

खेल 1 — पाँच मरीज़, पाँच पर्चे: ऊपर का सेहतमंद प्रोग्राम लीजिए, पाँच नक़लें, हर एक में ठीक एक बीमारी (29-33)। हर नक़ल पर: चलाइए → चिट्ठी के तीन सवाल (क्या? कहाँ? ठीक कहाँ?) → सुराग़ आया? सही दिशा में? → डिब्बा-तालिका से पुष्टि → एक इलाज → फिर चलाइए। पाँचों पर्चे Python बीमारी-पट्टी में — एक नया स्तंभ जोड़िए: "सुराग़: सही / नहीं / ग़लत दिशा"।

खेल 2 — सुराग़-परीक्षा: तीन डिब्बे बनाइए — bhav_aalu, bhav_pyaaz, kilo — फिर तीन ग़लत पुकारें: (क) bhav_alu (ख) bhav_pyaz (ग) kilos। 🔮 हर एक पर दाँव: Python क्या सुझाएगा? — चलाइए। (ख) पर ध्यान: Python bhav_pyaaz सुझाएगा या bhav_aalu? (दोनों मिलते-जुलते हैं — किसे चुना, और क्यों सही/ग़लत?) सीख कॉपी में: "मिलते-जुलते नाम = सुराग़ भी उलझ सकता है" — पाठ-143 की एक और तमीज़: बहुत मिलते-जुलते नाम मत रखो।

खेल 3 — क्रम-जासूस (बीमारी-31): आठ पंक्तियों का कोई प्रोग्राम (पाठ-139 की हाट-बही जैसा) लिखिए, फिर उसकी पंक्तियों को काग़ज़ की पर्चियों पर काटकर मिला दीजिए। साथी उन्हें फिर से जमाए — शर्त: हर डिब्बा पुकार से पहले भरा हो। डिब्बा-तालिका से जाँचिए। कितने क्रम सही बने? (कुछ पंक्तियों का क्रम आपस में बदला जा सकता है, कुछ का नहीं — कौन-सी? यही "निर्भरता" की पहली समझ है!)

आगे क्या सीखेंगे

आठवाँ दवाख़ाना पार — पाँच ग़लत पुकारें (29-33), "Did you mean" जो आपके अपने डिब्बे सुझाता है, सुराग़ के तीन रूप (सही, नहीं, ग़लत दिशा), "ग़लती ऊपर, चिट्ठी नीचे" की पहचान, और वैद्य-रीत: सुराग़ सुनो, फ़ैसला अपना। Python बीमारी-पट्टी में अब दस बीमारियाँ।

और अब अध्याय-17 का आख़िरी पाठ — बनाओ! आपकी अपनी (या किसी पहचान वाले की) दुकान की तीन चीज़ों का भाव-हिसाब: हर चीज़ के डिब्बे (भाव, मात्रा), हर चीज़ का कुल एक नए डिब्बे में, सबका जोड़, ग्राहक के दिए नोट से बाक़ी, और एक सुंदर बिल जो प्रेस के साँचे (पाठ-141) से छपे — मतलब-नामों के साथ (पाठ-143), सूखी-दौड़ की डिब्बा-तालिका से जँचा। भाग-ब में आपने दुकान का भाव-पत्र बनाया था (पाठ-96 — दिखाने वाला); आज भाव-हिसाब — गिनने वाला। पाठ-146: 🛠 बनाओ — अपनी दुकान की 3 चीज़ों का भाव-हिसाब।
