पाठ परिचय

पाठ-134 में आपने एक अच्छी ख़बर दर्ज की थी: "Python की बीमारियाँ चिल्लाती हैं" — CSS के उलट, वह ग़लती पर रुकता है और चिट्ठी लिखता है। आठ दवाख़ानों तक यह सच रहा। आज पहली बार एक मरीज़ आएगा जो चुप है: कोई चिट्ठी नहीं, कोई लाल रंग नहीं — प्रोग्राम आराम से चलता है, और बस ग़लत जवाब देता है।

वह मरीज़ है — "5" + "3" = 53। कैलकुलेटर ने पूछा, आपने 5 और 3 दिए, और जवाब आया 53 (आठ नहीं)! Python चुप इसलिए है कि उसकी नज़र में कुछ ग़लत हुआ ही नहीं: दो शब्द मिले, उसने उन्हें सटा दिया — शब्दों का जोड़ यही है (पाठ-135)। ग़लती Python की नहीं, आपके इरादे और code के बीच की है — और इरादा Python पढ़ नहीं सकता। यह दुनिया भर के Python सीखने वालों की सबसे मशहूर उलझन है।

चुप मरीज़ को पकड़ने के लिए चिट्ठी काम नहीं आती — इसलिए आज तीन पुराने औज़ार फिर से धार पाएँगे: 🔮 अंदाज़ा-पहले (जवाब पहले से सोचो — 8 सोचा, 53 आया = पकड़ा!), type() (पाठ-142 की तराज़ू), और डिब्बा-तालिका (पाठ-140)। साथ में चार बोलते मरीज़ भी — ताकि Python बीमारी-पट्टी 34-38 तक भरे। चलिए — चुप मरीज़ को बुलवाते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. पहली चुप Python-बीमारी ("5"+"3"=53) पहचान पाएँगे — और तीन औज़ारों (अंदाज़ा-पहले, type(), डिब्बा-तालिका) से पकड़ पाएँगे।

2. ValueError पढ़ पाएँगे — int() को ऐसा शब्द मिला जो गिनती नहीं बन सकता ("14 saal", "2.5", ख़ाली Enter)।

3. बाक़ी तीन — शब्द+गिनती का TypeError, int(input( का भूला कोष्ठक, और डिब्बे बिना input — उनकी चिट्ठी से पहचानकर इलाज कर पाएँगे।

एक चुप, चार बोलते

बीमारी-34 · "5"+"3"=53 (चुप!) — a = input(...) · b = input(...) · print(a + b) — जवाब 5 और 3 दिए। परदा:

53

कोई चिट्ठी नहीं। जड़: input हमेशा शब्द देता है (पाठ-150); दो शब्द + = सटे। पकड़ने के तीन औज़ार: (1) अंदाज़ा-पहले — चलाने से पहले कॉपी में लिखा था "8 आना चाहिए"; आया 53 → बीमारी पकड़ी! (जिसने अंदाज़ा नहीं लगाया, वह शायद 53 को ही मान लेता — PRIMM के 🔮 का सबसे बड़ा फ़ायदा यहीं है); (2) type() — print(type(a)) → <class 'str'> — जड़ सामने; (3) डिब्बा-तालिका — a: "5" (उल्टे-कॉमा लिखकर!), b: "3" — सटना दिख गया। इलाज: int() — a = int(input(...))। सीख कॉपी में मोटा: चुप बीमारी को चिट्ठी नहीं पकड़ती — अंदाज़ा पकड़ता है।

34 का बोलता भाई: शब्द + गिनती — Python नहीं जानता सटाए या गिने, इसलिए चिल्लाया। (~~~~~^~~ — इस बार इशारा + चिह्न पर: "यहीं उलझा"।) इलाज: umar = int(umar)।

बीमारी-36 · ValueError — गिनती बनने लायक़ नहीं — umar = int(input("Umar? ")) सही लिखा, पर उपयोगकर्ता ने लिखा "14 saal":

Traceback (most recent call last):
  File "bimar.py", line 1, in <module>
    umar = int(input("Umar? "))

नया परिवार — ValueError (वैल्यू एरर — "माल ग़लत क़िस्म का"): int() बाबू को ऐसा शब्द मिला जिसे वह गिनती नहीं बना सकता — "14 saal" (अक्षर भी हैं)। आख़िरी पंक्ति बताती है कौन-सा शब्द: '14 saal'। तीन आम रूप: "14 saal" (साथ में शब्द), "2.5" (दशमलव — int नहीं जानता; float() चाहिए — पाठ-150), और '' (ख़ाली — बिना लिखे Enter दबा दिया!)। (int(" 14 ") — आगे-पीछे space — चल जाता है; int उन्हें ख़ुद हटा देता है।) ख़ास बात: यहाँ code सही है — ग़लती उपयोगकर्ता के जवाब में है! इलाज आज: सवाल साफ़ करो — "Umar (sirf ank, jaise 14)? " — ताकि लोग सही लिखें; पक्का इलाज ("ग़लत जवाब आए तो फिर से पूछो") फ़ैसलों और दोहराव वाले अध्यायों में।

बीमारी-37 · int(input( का भूला कोष्ठक — umar = int(input("Umar? ") — दो खुले, एक बंद → SyntaxError: '(' was never closed (पाठ-136 की बीमारी-24 — भीतर वाले हुक्म के साथ और भी आम!)। इलाज: भीतर से बाहर गिनो — int( input( ... ) ) — दो खुले, दो बंद।

बीमारी-38 · डिब्बे बिना input — input("Naam? ") (बिना naam =) · फिर print(naam):

सवाल पूछा, जवाब आया — और फेंका गया (पाठ-147 वाली बात!); naam कभी भरा ही नहीं। अजीब बात: परदे पर सवाल और जवाब दोनों दिखे, इसलिए लगता है "जवाब तो दिया था!" — पर दिखना रखना नहीं है। इलाज: naam = input("Naam? ")।

पाँचों का इलाज एक साथ — 🔮 अंदाज़ा: माने जवाब: Sita, 5, 3 — परदे पर Jod कितना? —

naam = input("Naam? ")
a = int(input("Pehli sankhya (sirf ank)? "))
b = int(input("Doosri sankhya (sirf ank)? "))
print(naam + ", jod hai:", a + b)

नतीजा: Sita, jod hai: 8 — naam डिब्बे में (38), int() से गिनती (34, 35), कोष्ठक पूरे (37), सवाल साफ़ — "sirf ank" (36)।

रेखा-चित्र: दवाख़ाना-9

नीचे एक चुप और चार बोलते मरीज़ — उनकी चिट्ठी, और चुप मरीज़ के तीन स्टेथोस्कोप —

सबसे ऊपर का सुनहरा डिब्बा आज का असली मरीज़ है — बिना चिट्ठी वाला; उसके नीचे के तीन औज़ार वही पुराने हैं जो आप पहले दिन से बरत रहे हैं, और आज पहली बार उनकी असली क़ीमत दिखी।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "प्रोग्राम चल गया, कोई लाल चिट्ठी नहीं आई — मतलब सब सही है! Python ग़लती पर हमेशा चिल्लाता है, यह तो पाठ-134 में ही सीखा था।"

सच: पाठ-134 ने सिखाया था कि Python की ज़्यादातर बीमारियाँ चिल्लाती हैं — और आज उस सच की हद मिली। Python तभी चिल्लाता है जब उसकी नज़र में कुछ असंभव हो — बनावट टूटी (SyntaxError), नाम नहीं मिला (NameError), दो क़िस्में नहीं मिलतीं (TypeError), माल बदलने लायक़ नहीं (ValueError)। पर "5" + "3" उसकी नज़र में बिल्कुल ठीक है — शब्द सटाना एक जायज़ काम है, जो आपने पाठ-137 में ख़ुद "=" * 30 के साथ जान-बूझकर किया था! Python नहीं जानता कि आपका इरादा जोड़ने का था। इसलिए नियम (कॉपी में मोटा): चिट्ठी न आना = Python को कुछ असंभव नहीं दिखा; इसका मतलब यह नहीं कि जवाब सही है। दुनिया के प्रोग्रामर इसे सबसे ख़तरनाक क़िस्म की ग़लती मानते हैं — क्योंकि वह चुपचाप ग़लत नतीजे बनाती रहती है, और अक्सर तब पकड़ी जाती है जब नुक़सान हो चुका (सोचिए किसी दुकान का बिल-प्रोग्राम जो हफ़्ते भर "53" जैसे जोड़ बनाता रहा!)।

तो इससे बचाव क्या? — वही आदत जो इस कोर्स ने पहले दिन से बोई है: 🔮 अंदाज़ा-पहले। जो प्रोग्रामर चलाने से पहले सोचता है "5 और 3 दूँगा, तो 8 आना चाहिए", उसे 53 देखते ही झटका लगता है — बीमारी उसी पल पकड़ी जाती है। जो बिना सोचे चलाता है, वह 53 देखकर शायद आगे बढ़ जाता है। यानी PRIMM का पहला क़दम (🔮) सिर्फ़ "सीखने का तरीक़ा" नहीं था — वह चुप ग़लतियों के ख़िलाफ़ असली ढाल है, जिसे बड़े प्रोग्रामर भी हर दिन बरतते हैं (उनके पास इसके बड़े रूप होते हैं — "परीक्षा-प्रोग्राम" जो हर हिसाब का अपेक्षित जवाब पहले से रखते हैं; इस कोर्स का robot भी ठीक यही करता है — हर code-डिब्बे का अपेक्षित नतीजा पहले से लिखा, और मिलान!)। चिट्ठी Python की चौकीदारी है; अंदाज़ा आपकी — और चुप चोर दूसरी चौकी पर ही पकड़ा जाता है।

अभ्यास-खेल: दवाख़ाना-9 मश्क़

खेल 1 — पाँच मरीज़, पाँच पर्चे: ऊपर का सेहतमंद प्रोग्राम लीजिए, पाँच नक़लें — हर एक में ठीक एक बीमारी (34-38)। हर एक पर पहले अंदाज़ा ("सही होता तो परदे पर ___ आता"), फिर चलाइए, फिर: चिट्ठी आई? (34 पर नहीं!) → तीन औज़ारों में से कौन-सा पकड़ा? → इलाज → फिर चलाइए। Python बीमारी-पट्टी में पाँचों — और 34 के आगे लाल ✗ नहीं, एक ख़ास निशान: "चुप" (बीमारी-पट्टी का नया स्तंभ: "चिल्लाती / चुप")।

खेल 2 — ValueError के तीन जवाब: umar = int(input("Umar? ")) — तीन बार चलाइए, तीन जवाबों से: "14 saal", "2.5", और बिना कुछ लिखे Enter। हर चिट्ठी की आख़िरी पंक्ति कॉपी में — उसमें आपका दिया जवाब दिखा? (हाँ — '14 saal', '2.5', '' — Python बताता है कौन-सा माल नहीं बदला!) फिर सवाल बदलिए — "Umar (sirf ank, jaise 14)? " — और किसी घर-साथी से चलवाइए: क्या उन्होंने सही लिखा?

खेल 3 — चुप-चोर शिकार + robot की बात: तीन छोटे प्रोग्राम कॉपी में — हर एक पर पहले अंदाज़ा, फिर पहचानिए कि कौन-सा चुपचाप ग़लत है (मशीन हो तो चलाकर): (क) a = input() · b = input() · print(a * 2) ("5" दिया) (ख) kilo = input() · print(kilo + kilo) ("2" दिया) (ग) a = int(input()) · print(a + a) ("5" दिया)। कॉपी में एक पंक्ति: "इस कोर्स का robot हर code-डिब्बे का अपेक्षित नतीजा पहले से रखता है — यह 🔮 जैसा क्यों है?"

आगे क्या सीखेंगे

नौवाँ दवाख़ाना पार — Python की पहली चुप बीमारी ("5"+"3"=53) और उसके तीन स्टेथोस्कोप (अंदाज़ा-पहले, type(), डिब्बा-तालिका), नया परिवार ValueError (code सही, जवाब ग़लत — सवाल साफ़ करो), शब्द+गिनती का TypeError, भूला कोष्ठक, और "दिखना ≠ रखना"। बीमारी-पट्टी में अब पंद्रह Python-बीमारियाँ — और एक नया स्तंभ: चिल्लाती या चुप।

और अब अध्याय-18 का बनाओ-पाठ — "मुझसे मिलो" सवाल-जवाब प्रोग्राम: आपका पहला प्रोग्राम जो किसी और से सचमुच बात करेगा — नाम पूछे, कहाँ से (बड़ा इलाक़ा), पसंदीदा चीज़, एक गिनती वाला सवाल (int() के साथ, साफ़ सवाल-शब्दों में!), और फिर एक गर्म, बुना हुआ परिचय-पत्र छापे — अपने हिसाब के साथ। अध्याय की पूरी पेटी: input, डिब्बे, बुनाई, int(), ईमानदार छपाई, पूछने की तमीज़, और आज के पाँचों मरीज़ों से बचाव। पाठ-154: 🛠 बनाओ — "मुझसे मिलो" सवाल-जवाब प्रोग्राम।
