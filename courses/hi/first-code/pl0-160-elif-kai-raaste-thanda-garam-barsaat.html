पाठ परिचय

किसान सुबह आसमान देखकर तय करता है कि आज क्या करना है — और उसके पास दो नहीं, कई रास्ते होते हैं: बहुत गरमी हो, तो सुबह-सुबह काम निपटाओ और पानी ज़्यादा पियो; मौसम सुहाना हो, तो पूरे दिन खेत में; ठंड हो, तो धूप चढ़ने का इंतज़ार और गरम कपड़े। वह ऊपर से सोचता है: "बहुत गरम है? — नहीं। तो सुहाना है? — हाँ!" — और जैसे ही एक जवाब "हाँ" मिला, आगे के सवाल पूछता ही नहीं।

if-else के दो रास्ते (पाठ-158) यहाँ कम पड़ते हैं। आज Python की सीढ़ी: elif (एल-इफ़ — else + if — "नहीं तो अगर")। एक if, बीच में जितने चाहें elif, और अंत में (चाहें तो) else। Python ऊपर से हर शर्त पूछता है — और पहली सच शर्त पर उसकी राह चलाकर, बाक़ी पूरी सीढ़ी छोड़ देता है। किसान वाली सोच, हूबहू।

और इस सीढ़ी में एक ख़तरनाक जाल है जो कल की "सीमा" वाली चुप बीमारी का बड़ा भाई है: क्रम। शर्तें ग़लत क्रम में लिखीं, तो Python कोई चिट्ठी नहीं देता — बस चुपचाप ग़लत राह पकड़ लेता है। आज वह ग़लत-क्रम वाला प्रोग्राम भी चलेगा, और इस किताब का robot ख़ुद जाँचेगा कि वह सचमुच ग़लत जवाब देता है! चलिए — सीढ़ी बनाते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. if-elif-else की सीढ़ी लिख पाएँगे — और समझा पाएँगे कि पहली सच शर्त जीतती है, बाक़ी छोड़ी जाती हैं।

2. क्रम का जाल पहचान पाएँगे — बड़ी सीमा पहले, वरना चुपचाप ग़लत राह — और सही क्रम चुन पाएँगे।

3. सीढ़ी की हर राह और हर सीमा की दौड़ बना पाएँगे — तीन राहें, दो सीमाएँ।

शर्तों की सीढ़ी

तीन रास्ते — 🔮 अंदाज़ा पहले: नीचे दिन की गरमी पूछी जाती है (डिग्री में; सीमाएँ उदाहरण के लिए हैं — आपके इलाक़े में अलग हो सकती हैं)। पाँच दाँव — 38, 25, 10, और दोनों सीमाओं पर: ठीक 35, ठीक 20 —

t = int(input("Aaj kitni garmi (degree)? "))
if t >= 35:
    print("Garam din - paani zyada piyo.")
elif t >= 20:
    print("Suhana din - khet me kaam achha.")
else:
    print("Thanda din - garam kapde pehno.")

नतीजे: 38 → Garam din · 25 → Suhana din · 10 → Thanda din · ठीक 35 → Garam din (>= — "या बराबर") · ठीक 20 → Suhana din। पाँचों दौड़ें, हर एक में ठीक एक पंक्ति (पाठ-158 का वादा सीढ़ी में भी!)।

Python सीढ़ी कैसे उतरता है — 25 पर (कॉपी में, तीर से): सवाल-1: t >= 35? — 25 >= 35 → False → आगे। सवाल-2 (elif): t >= 20? — True → "Suhana din" छापा → बाक़ी सीढ़ी छोड़ दी (else तक गया ही नहीं)। और 38 पर? — सवाल-1 ही True → "Garam din" → elif और else दोनों छोड़े — elif की शर्त (38 >= 20) भी सच थी, पर पूछी ही नहीं गई! यही आज का दिल है (कॉपी में मोटा): सीढ़ी में पहली सच शर्त जीतती है — बाद वाली सच हों तब भी नहीं पूछी जातीं। elif के नियम: सीध if जैसी, अपनी शर्त और कोलन (else की तरह बिना शर्त नहीं — वह "नहीं तो अगर" है), नीचे हाशिया; जितने चाहें elif; else आख़िर में एक (या कोई नहीं — तब किसी भी शर्त के सच न होने पर कुछ नहीं चलेगा)।

क्रम का जाल — चुप, और ख़तरनाक: अब वही सीढ़ी, बस पहली दो शर्तें उलटी — छोटी सीमा (20) पहले। 🔮 अंदाज़ा: 38 डिग्री पर क्या छपेगा? —

t = int(input("Aaj kitni garmi (degree)? "))
if t >= 20:
    print("Suhana din")
elif t >= 35:
    print("Garam din")
else:
    print("Thanda din")

38 पर: Suhana din — 38 डिग्री को "सुहाना" कहा! वजह: पहला सवाल 38 >= 20 → True → बस, सीढ़ी ख़त्म; "Garam din" वाली राह तक कोई गरमी कभी नहीं पहुँचेगी (35 से ऊपर की हर संख्या 20 से भी ऊपर है — पहला सवाल हमेशा उसे पकड़ लेगा)। कोई चिट्ठी नहीं, कोई लाल रंग नहीं — कल की सीमा-बीमारी से भी चुप, क्योंकि यहाँ पूरी एक राह ही मर गई। (इस डिब्बे का नतीजा भी robot ने असली Python चलाकर पक्का किया है — ग़लत जवाब सचमुच यही आता है।) नियम: ">=" वाली सीढ़ी में बड़ी सीमा सबसे ऊपर, फिर घटती हुई (35, फिर 20, फिर बाक़ी); "<" वाली में उलटा — छोटी सीमा ऊपर। और जाँच: हर राह की एक दौड़ + हर सीमा की एक दौड़ — कोई राह "कभी न चलने वाली" तो नहीं बची?

रेखा-चित्र: शर्तों की सीढ़ी

नीचे आज का पूरा पट्ट — सीढ़ी पर Python का उतरना, पहली-सच-जीते नियम, और क्रम का जाल —

दाएँ की बिंदु-रेखा वाले डिब्बे "मरी हुई राह" हैं — code में लिखे, पर कोई भी संख्या वहाँ तक कभी नहीं पहुँचती; ऐसी राह कोई चिट्ठी नहीं देती, इसलिए उसे सिर्फ़ हर-राह वाली दौड़ ही पकड़ सकती है।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "elif की जगह कई अलग-अलग if लिख दूँ — क्या फ़र्क़? if t >= 35: ... फिर अलग से if t >= 20: ... फिर if t < 20: ... — सब शर्तें तो वही हैं! elif बस एक नया शब्द याद करने की झंझट है।"

सच: फ़र्क़ बहुत बड़ा है, और ठीक "पहली सच जीते" वाले नियम में छिपा है। अलग-अलग if हों, तो Python हर if की शर्त पूछता है — एक-दूसरे से अनजान। अब 38 डिग्री सोचिए: पहला if (38 >= 35) — True → "Garam din"; दूसरा, अलग if (38 >= 20) — वह भी True → "Suhana din"! परदे पर एक ही दिन के लिए दो बातें: "गरम दिन" भी, "सुहाना दिन" भी — एक आदमी एक साथ दो रास्ते पर (पाठ-34 का "ठीक एक" वादा टूटा!)। elif की सीढ़ी में यह असंभव है: पहली सच शर्त मिलते ही बाक़ी छोड़ दी जाती हैं — हमेशा ठीक एक राह। यानी elif "नया शब्द" नहीं, एक वादा है: "इन सब रास्तों में से ठीक एक"।

हाँ, कभी-कभी आपको सचमुच अलग-अलग, आपस में स्वतंत्र फ़ैसले चाहिए — जैसे "अगर बारिश, तो छाता" और (अलग से) "अगर ठंड, तो स्वेटर" — दोनों एक साथ सच हो सकते हैं, और दोनों चीज़ें चाहिए! तब दो अलग if ही सही हैं। फ़ैसले का सवाल एक (कॉपी में मोटा): "क्या ये रास्ते आपस में एक-दूसरे को काटते हैं (ठीक एक चाहिए), या अलग-अलग फ़ैसले हैं (कोई भी, कितने भी)?" — काटते हैं → if-elif-else; अलग हैं → अलग if। मौसम ठंडा-सुहाना-गरम — एक ही चीज़ की तीन हालतें, आपस में काटती हैं → elif। छाता और स्वेटर — दो अलग चीज़ें → अलग if। elif झंझट नहीं — "ठीक एक" का पक्का वादा है।

अभ्यास-खेल: सीढ़ी-मश्क़

खेल 1 — अपनी सीढ़ी, अपना फ़ैसला: किसी चीज़ की तीन-चार हालतें चुनिए, जिनमें ठीक एक चलनी चाहिए — जैसे दूध की मात्रा ("bahut kam / kaafi / zyada"), या फ़सल की ऊँचाई, या गल्ले में रोज़ की बिक्री। सीमाएँ अपने हिसाब से (उदाहरण!) — फिर if-elif-else, बड़ी सीमा ऊपर। दौड़ें: हर राह की एक + हर सीमा की एक — कॉपी में तालिका (जवाब · कौन-सी राह · सही?)।

खेल 2 — क्रम-जासूस (मरी राह खोजो): आज की सही सीढ़ी की नक़ल में तीन अलग क्रम-बदलाव करके देखिए — (क) 20 वाली ऊपर (ख) else को बीच में लाने की कोशिश (क्या होता है? — चिट्ठी! else आख़िर में ही) (ग) दोनों elif की जगह अलग-अलग if। हर एक पर 🔮 दाँव, फिर 38, 25, 10 से दौड़ें। किसमें कोई राह मरी? किसमें दो बातें एक साथ छपीं?

खेल 3 — elif या अलग if? (अदालत) + हुक्म-बही: छह जोड़ियाँ — फ़ैसला और कारण: (क) अंक: बढ़िया/अच्छा/पास/मेहनत (ख) बारिश तो छाता; धूप तो टोपी; ठंड तो स्वेटर (ग) उम्र: बच्चा/जवान/बुज़ुर्ग (घ) टंकी कम तो मोटर; रात हो तो बत्ती (ङ) दिन: सोमवार/मंगलवार/... (च) भूख तो खाना; प्यास तो पानी। हुक्म-बही के if-पन्ने पर: "elif = नहीं तो अगर · पहली सच जीते · बड़ी सीमा ऊपर · आपस में काटें → elif, अलग → अलग if · हर राह + हर सीमा की दौड़"।

आगे क्या सीखेंगे

शर्तों की सीढ़ी बन गई — elif ("नहीं तो अगर"), पहली-सच-जीते नियम, हर बार फिर भी ठीक एक राह, क्रम का चुप जाल (और मरी हुई राह — robot ने असली Python से जाँची!), बड़ी-सीमा-ऊपर नियम, और "elif या अलग if" का फ़ैसला-सवाल। किसान की सुबह वाली सोच अब code में।

पिछले पाँच पाठों में एक चीज़ हर बार आई और हर बार कहा गया "पूरी कहानी पाठ-161 में" — हाशिया। कल वह कहानी: Python की अपनी लक्ष्मण-रेखा। ज़्यादातर भाषाएँ code के टुकड़ों को कोष्ठकों से बाँधती हैं; Python उन्हें खिसकाव (space) से बाँधता है — इसलिए Python में हाशिया सजावट नहीं, मतलब है: एक space इधर-उधर, और पंक्ति छाते के नीचे से बाहर (या बाहर से भीतर)! हाशिए के क्या नियम हैं, कितने space, कब ख़त्म होता है, if के भीतर if (घोंसला — पाठ-66 की वापसी!), और tab-space की उलझन। पाठ-161: हाशिया (इंडेंट / Indent) — पाइथन की लक्ष्मण-रेखा।
