पाठ परिचय

रामायण की लक्ष्मण-रेखा याद कीजिए — एक लकीर, और उसके भीतर-बाहर का मतलब बिल्कुल अलग: भीतर सुरक्षा, बाहर ख़तरा। लकीर दिखने में बस मिट्टी पर खिंची रेखा थी — पर उसने तय किया कि कौन कहाँ है। पाठ-59 में आपने निजता की "लक्ष्मण-रेखा" खींची थी; आज Python की अपनी लक्ष्मण-रेखा — हाशिया (indent — इंडेंट: पंक्ति को आगे से खिसकाना)।

पिछले पाँच पाठों में हर if, else, elif के नीचे वाली पंक्ति 4 space अंदर थी, और हर बार कहा गया "पूरी कहानी पाठ-161 में"। आज वह कहानी — और वह Python की सबसे अनोखी बात है। दुनिया की ज़्यादातर प्रोग्रामिंग-भाषाएँ code के टुकड़ों को कोष्ठकों से बाँधती हैं (html जैसे खुला-बंद tag — पाठ-71!) — हाशिया वहाँ बस सजावट होता है। Python में हाशिया ही बाँधता है: कौन-सी पंक्ति छाते के नीचे, कौन-सी बाहर — यह सिर्फ़ खिसकाव से तय होता है।

इसका मतलब: Python में एक space इधर-उधर करना सजावट बदलना नहीं, मतलब बदलना है — और कभी-कभी बिना किसी चिट्ठी के! आज हाशिए के नियम, टुकड़ा कहाँ ख़त्म होता है, if के भीतर if (घोंसला — पाठ-66 की वापसी), और tab-space की वह उलझन जो फ़ोन पर सबसे ज़्यादा होती है। चलिए — रेखा खींचते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. समझा पाएँगे कि Python में हाशिया ही टुकड़ा बाँधता है — और एक खिसकाव से मतलब कैसे चुपचाप बदलता है।

2. हाशिए के नियम निभा पाएँगे — 4 space, एक टुकड़े में एक-सी सीध, टुकड़ा कहाँ ख़त्म।

3. if के भीतर if (घोंसला) लिख पाएँगे — और tab-space की उलझन (TabError) पहचान पाएँगे।

रेखा के भीतर, रेखा के बाहर

एक space का फ़र्क़ — 🔮 अंदाज़ा पहले: नीचे दो प्रोग्राम लगभग एक-से हैं — फ़र्क़ सिर्फ़ "Wah!" वाली पंक्ति के आगे के 4 space का। ank = 50 है, यानी if की शर्त (ank > 100) झूठ। दोनों पर दाँव — कौन क्या छापेगा? —

ank = 50
if ank > 100:
    print("Bahut!")
    print("Wah!")
print("Khatam")

ank = 50
if ank > 100:
    print("Bahut!")
print("Wah!")
print("Khatam")

पहला: सिर्फ़ Khatam — "Wah!" 4 space अंदर था, यानी छाते के नीचे — शर्त झूठ, तो "Bahut!" और "Wah!" दोनों छूटे। दूसरा: Wah! और Khatam — "Wah!" बाहर खिसक आया, यानी छाते के बाहर — अब वह हर हाल में चलता है! दोनों प्रोग्राम सही Python हैं — कोई चिट्ठी नहीं — पर मतलब अलग। ठीक लक्ष्मण-रेखा: पंक्ति वही, बस रेखा के किस ओर है, उससे तय होता है कि उसके साथ क्या होगा। (कॉपी में मोटा: Python में हाशिया सजावट नहीं, मतलब है।)

हाशिए के नियम (कॉपी में): (1) कोलन के बाद हाशिया — if, elif, else की पंक्ति कोलन (:) पर ख़त्म, और अगली पंक्ति आगे खिसकती है। (2) 4 space — Python को बस इतना चाहिए कि एक टुकड़े की सब पंक्तियाँ एक-सी खिसकी हों (2 space भी चलेंगे); पर दुनिया भर की पक्की रीत 4 space है — पढ़ने में साफ़, सब एक-से। (3) एक टुकड़ा, एक सीध — छाते के नीचे की सब पंक्तियाँ बिल्कुल एक ही सीध में; कोई 4, कोई 5 — तो चिट्ठी (परसों के दवाख़ाने में!)। (4) टुकड़ा कहाँ ख़त्म — जैसे ही कोई पंक्ति वापस बाहर (if की सीध में) आई, टुकड़ा ख़त्म — कोई "बंद" लिखने की ज़रूरत नहीं; बाहर आना ही बंद करना है। (Python-ऐप अक्सर कोलन के बाद Enter पर अपने-आप हाशिया लगा देते हैं; बाहर आने के लिए space मिटाने पड़ते हैं — यह ख़ुद देखना होता है!)

घोंसला — if के भीतर if: पाठ-66 में html के tag एक-दूसरे के भीतर बैठते थे; Python में भी एक फ़ैसले के भीतर दूसरा फ़ैसला। 🔮 अंदाज़ा — तीन दौड़ें: (बारिश, ठंड) = (haan, haan), (haan, nahi), (nahi, haan) —

barish = input("Baarish? (haan/nahi) ")
thand = input("Thand? (haan/nahi) ")
if barish == "haan":
    print("Chhata lo.")
    if thand == "haan":
        print("Sweater bhi pehno.")
print("Chalo!")

(haan, haan): Chhata lo. Sweater bhi pehno. Chalo! — (haan, nahi): Chhata lo. Chalo! — (nahi, haan): सिर्फ़ Chalo! — ठंड "haan" थी, फिर भी स्वेटर नहीं! क्यों? भीतरी if (ठंड वाला) बाहरी छाते के नीचे है (4 space) — बाहरी शर्त (बारिश) झूठ हुई, तो पूरा भीतरी टुकड़ा छूटा, और ठंड वाला सवाल पूछा ही नहीं गया। हाशिए गिनिए: बाहरी if के नीचे 4, भीतरी if के नीचे 8 — हर घोंसला 4 और। (यह प्रोग्राम "बारिश हो तब ही ठंड की परवाह" कहता है — अगर आप हर हाल में स्वेटर की सलाह चाहते थे, तो ठंड वाला if बाहर होना चाहिए — पाठ-160 का "अलग फ़ैसले = अलग if"! हाशिया ही वह फ़ैसला है।)

tab-space की उलझन: कीबोर्ड पर Tab (टैब) बटन भी खिसकाता है — पर Python के लिए Tab और space अलग अक्षर हैं। एक टुकड़े में कुछ पंक्तियाँ space से, कुछ Tab से खिसकीं, तो चिट्ठी: TabError: inconsistent use of tabs and spaces in indentation — और मज़ा यह कि परदे पर दोनों एक-से दिखते हैं! नियम: सिर्फ़ space (ज़्यादातर Python-ऐप Tab दबाने पर भी space ही डालते हैं — पर दूसरी जगह से copy किया code ध्यान से)।

रेखा-चित्र: Python की लक्ष्मण-रेखा

नीचे आज का पूरा पट्ट — एक खिसकाव का फ़र्क़, हाशिए के नियम, और घोंसला —

ऊपर के दो काले परदे एक ही पंक्ति की दो जगहें दिखाते हैं — सुनहरी रेखा के भीतर वह छाते के नीचे है, बाहर वह हर हाल में; पंक्ति वही, सिर्फ़ उसकी जगह ने उसका भाग्य तय किया।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "हाशिया तो सुंदरता के लिए होता है — html में भी तो मैंने code सुंदर दिखाने के लिए खिसकाया था (पाठ-66), और browser ने उसकी परवाह नहीं की! Python में भी space से क्या फ़र्क़ पड़ेगा? जैसे चाहूँ लिखूँ।"

सच: html में आपकी याद बिल्कुल सही है — वहाँ खिसकाव सिर्फ़ पढ़ने वाले इंसान के लिए था; browser whitespace को समेट देता था (पाठ-63!), और tag के खुला-बंद होने से ही तय होता था कि क्या किसके भीतर है। Python ने एक साहसी फ़ैसला लिया: "जो इंसान को भीतर दिखता है, वही मशीन के लिए भी भीतर हो"। आज के पहले प्रयोग में ठीक यही दिखा — एक पंक्ति का खिसकाव बदला, और उसका चलना-न-चलना बदल गया। तो Python में "जैसे चाहूँ लिखूँ" वाली आज़ादी नहीं — पर बदले में एक बड़ी चीज़ मिलती है।

वह बड़ी चीज़ है ईमानदार code। कोष्ठक वाली भाषाओं में एक मशहूर आफ़त होती है: इंसान को code एक तरह खिसका दिखता है ("यह पंक्ति if के भीतर लगती है"), पर कोष्ठक कुछ और कहते हैं ("असल में बाहर है") — आँख धोखा खाती है, और बीमारी घंटों छिपी रहती है। Python में यह धोखा असंभव है: जो दिखता है, वही है — भीतर दिखी, तो भीतर है। इसीलिए Python पढ़ने में सबसे साफ़ भाषाओं में गिना जाता है, और बहुत-से स्कूलों में पहली भाषा के रूप में चुना जाता है। हाँ, बदले में आपको खिसकाव पर उतना ही ध्यान देना है जितना कोष्ठक पर (पाठ-136) — एक space भी मायने रखता है। Python की लक्ष्मण-रेखा बंधन नहीं — वह वादा है कि आँख और मशीन हमेशा एक ही बात देखें।

अभ्यास-खेल: रेखा-मश्क़

खेल 1 — भीतर या बाहर? (खिसकाव-खेल): यह प्रोग्राम कॉपी में: ank = 120 · if ank > 100: · (भीतर) print("A") · (भीतर) print("B") · (बाहर) print("C")। अब चार रूप बनाइए — हर रूप में ठीक एक पंक्ति का खिसकाव बदलकर (A बाहर, B बाहर, C भीतर, सब भीतर)। 🔮 हर रूप पर दो दाँव — ank = 120 पर परदा? ank = 50 पर? — फिर (मशीन हो तो) आठों दौड़ें। कौन-सा रूप दोनों संख्याओं पर एक-सा छापता है? क्यों?

खेल 2 — घोंसला: अपना फ़ैसला अपनी जगह: आज के बारिश-ठंड प्रोग्राम के दो रूप — (क) ठंड वाला if भीतर (आज जैसा) (ख) ठंड वाला if बाहर (बारिश वाले if की सीध में)। चारों जोड़ियों (haan/haan, haan/nahi, nahi/haan, nahi/nahi) से दोनों रूप चलाइए — तालिका कॉपी में। किस जोड़ी पर दोनों रूप अलग छापते हैं? कौन-सा रूप आपकी असली सलाह से मेल खाता है — और यह फ़ैसला किस चीज़ ने किया? (हाशिए ने!)

खेल 3 — अपने ऐप की हाशिया-आदत + हुक्म-बही: अपने Python-ऐप में if ...: लिखकर Enter दबाइए — हाशिया अपने-आप आया? कितने space? बाहर आने के लिए क्या करना पड़ा? Tab बटन दबाने पर space आते हैं या Tab? (कॉपी में अपने ऐप का नोट — पाठ-136 के बीमारी-28 वाले कीबोर्ड-नोट की तरह!) हुक्म-बही के if-पन्ने पर: "हाशिया = मतलब · 4 space · एक टुकड़ा एक सीध · बाहर आना = बंद · घोंसला = 4 और · सिर्फ़ space, Tab नहीं"।

आगे क्या सीखेंगे

Python की लक्ष्मण-रेखा खिंच गई — हाशिया ही टुकड़ा बाँधता है (एक खिसकाव, बदला मतलब, बिना चिट्ठी), चार नियम (कोलन के बाद, 4 space, एक सीध, बाहर आना = बंद), घोंसला (भीतरी फ़ैसला तभी जब बाहरी सच — 8 space), और tab-space की उलझन। और सबसे बड़ा सच: Python में जो आँख को दिखता है, वही मशीन को।

कल फ़ैसलों में एक नई ताक़त: दो शर्तें साथ। भाग-अ का पाठ-35 — "कई शर्तें साथ" — याद है? "अगर दुकान खुली है और पैसे हैं, तो दूध लाओ"; "अगर रविवार है या छुट्टी है, तो स्कूल नहीं"। कल Python के दो जोड़ने वाले शब्द: and (और — दोनों सच हों) और or (या — कोई एक भी सच हो), उनकी चार-ख़ाने वाली सच-तालिका, "14 से 18 के बीच" जैसी सीमा-जोड़ी, और आज के घोंसले से तुलना — कब and, कब घोंसला? पाठ-162: and, or — दो शर्तें साथ।
