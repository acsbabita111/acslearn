पाठ परिचय

पाठ-161 में आपने Python की लक्ष्मण-रेखा खींची — हाशिया, जो सजावट नहीं, मतलब है। आज वह रेखा जहाँ-जहाँ टूटती है, वहाँ के मरीज़ — प्रोग्राम का दवाख़ाना-10। Python बीमारी-पट्टी 24-38 तक भरी है; आज 39-45।

इस अध्याय की बीमारियों की एक ख़ासियत है: उनमें से कई दिखती नहीं। भूला कोष्ठक (पाठ-136) आँख से दिख जाता था; पर एक space कम, या Tab और space की मिलावट — परदे पर बिल्कुल एक-सी दिखती हैं! इसलिए आज दो नए चिट्ठी-परिवार मिलेंगे — IndentationError (इंडेंटेशन एरर — "हाशिए की ग़लती") और TabError — और एक नया स्टेथोस्कोप: हाशिया-जासूस — हर पंक्ति के आगे के space गिनना।

और अंत में फिर एक चुप मरीज़ — पाठ-153 वाले परिवार का: एक ऐसा फ़ैसला जो कभी सच नहीं होता, कोई चिट्ठी नहीं देता, और प्रोग्राम हमेशा else-राह पर चलता रहता है। उसे पकड़ता है वही पुराना औज़ार — दोनों राहें जाँचो (पाठ-156)। दस्ताने पहनिए — रेखा जाँचते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बीमारी 39-45 उनकी असली चिट्ठी से पहचान पाएँगे — कोलन, हाशिया (तीन रूप), एक =, tab-space, और चुप "18" == 18।

2. हाशिया-जासूस बरत पाएँगे — हर पंक्ति के आगे के space गिनकर (0, 4, 4, 0) टूटी रेखा खोजना।

3. चुप फ़ैसले-बीमारी को दोनों राहें जाँचो से पकड़ पाएँगे — और जानेंगे कि "कभी न चलने वाली राह" ख़ुद एक सुराग़ है।

सात मरीज़ — रेखा जहाँ टूटी

बीमारी-39 · भूला कोलन — if barish == "haan" (अंत में : नहीं):

  File "faisla.py", line 2
    if barish == "haan"
                       ^
SyntaxError: expected ':'

"कोलन की उम्मीद थी" — ^ ठीक वहाँ जहाँ : होना था। सबसे आसान इलाज, सबसे आम बीमारी (else पर भी: else बिना कोलन — वही चिट्ठी)।

बीमारी-40 · हाशिया नहीं — if के नीचे वाली पंक्ति खिसकी ही नहीं:

  File "faisla.py", line 3
    print("Chhata lo")
    ^
IndentationError: expected an indented block after 'if' statement on line 2

"line 2 वाले if के बाद खिसका हुआ टुकड़ा चाहिए था" — Python को छाता मिला, पर उसके नीचे कुछ नहीं! इलाज: 4 space।

बीमारी-41 · बेवजह हाशिया — बिना किसी if के पंक्ति खिसका दी:

  File "faisla.py", line 2
    print("Chhata lo")
IndentationError: unexpected indent

"अनचाहा खिसकाव" — ऊपर कोई कोलन नहीं, तो यह पंक्ति किसके नीचे? (अक्सर तब होता है जब कोई पंक्ति copy करके चिपकाई जाए, या if मिटाया पर नीचे की पंक्ति वैसी ही रही।) इलाज: पंक्ति बाहर (0 space)।

बीमारी-42 · if में एक = — पाठ-157 वाला मशहूर मरीज़: if x = 5: → SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='? — इलाज: ==।

बीमारी-43 · भटका else — else 2 space पर, जबकि if 0 पर:

  File "faisla.py", line 4
    else:
         ^
IndentationError: unindent does not match any outer indentation level

"वापस बाहर आए, पर किसी भी बाहरी सीध से मेल नहीं" — else न if की सीध में (0), न भीतर (4) — 2 पर, अधर में लटका। इलाज: else ठीक if की सीध में (पाठ-158 का नियम-1)।

बीमारी-44 · tab-space की मिलावट — एक पंक्ति space से, अगली Tab से — परदे पर एक-सी:

  File "faisla.py", line 3
    print("b")
TabError: inconsistent use of tabs and spaces in indentation

सबसे धोखेबाज़ — आँख को कुछ ग़लत नहीं दिखता! इलाज: उस टुकड़े की सब पंक्तियों का हाशिया मिटाकर space से फिर लगाइए।

बीमारी-45 · चुप फ़ैसला — "18" == 18: umar = input("Umar? ") · if umar == 18: → print("Ab vote de sakte ho!") — जवाब 18 दिया। परदा: सिर्फ़ Dhanyavaad — शाबाशी कभी नहीं! कोई चिट्ठी नहीं। जड़: umar शब्द ("18"), 18 गिनती — == चुपचाप False (पाठ-157 का जाल-3)। सुराग़: दोनों राहें जाँचो — जो जवाब if-राह चलाना चाहिए था (18), उस पर भी else चला → कोई राह "कभी न चलने वाली" है → शर्त की क़िस्में जाँचो (type() — पाठ-142)। इलाज: int()।

हाशिया-जासूस — नया स्टेथोस्कोप (कॉपी में): टूटे प्रोग्राम की हर पंक्ति के आगे लिखिए उसके शुरू के space — जैसे 0, 0, 4, 2, 4 — फिर देखिए: (1) हर कोलन वाली पंक्ति के नीचे अंक बढ़ा? (बीमारी-40) (2) कहीं बिना कोलन के अंक बढ़ा? (41) (3) वापस आते समय अंक किसी पुराने अंक से मेल खाया? (43 — 2 किसी से मेल नहीं!) (4) एक टुकड़े के सब अंक एक-से? (फ़ोन पर Tab-space पहचानने का पक्का तरीक़ा: पंक्ति के शुरू में कर्सर रखकर तीर-बटन से एक-एक खिसकाइए — space पर कर्सर एक-एक क़दम चलता है, Tab पर एक लंबी छलाँग!)

सातों का इलाज एक साथ — 🔮 अंदाज़ा, दोनों राहें: जवाब 18 पर? 15 पर? —

umar = int(input("Umar? "))
if umar >= 18:
    print("Ab vote de sakte ho!")
else:
    print("Abhi", 18 - umar, "saal aur.")
print("Dhanyavaad")

18 → Ab vote de sakte ho! · 15 → Abhi 3 saal aur. — दोनों राहें ज़िंदा। हाशिया-जासूस: 0, 0, 4, 0, 4, 0 ✓ — कोलन (39 ✓), हाशिया (40, 41 ✓), >= (42 — == भी नहीं, यहाँ >= ही चाहिए था!), else सीध में (43 ✓), सब space (44 ✓), int() (45 ✓)।

रेखा-चित्र: दवाख़ाना-10

नीचे सात मरीज़ — छह बोलते, एक चुप — और हाशिया-जासूस का तरीक़ा —

नीचे के काले डिब्बे में बाईं ओर सुनहरे अंक हाशिया-जासूस की गिनती हैं — 0, 0, 4, 2, 4 — और वह 2 किसी पुरानी सीध से मेल नहीं खाता; टूटी रेखा आँख से नहीं, गिनती से दिखी।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "हाशिए की इतनी बीमारियाँ — Python बड़ी झंझट वाली भाषा है! कोष्ठक वाली भाषाएँ बेहतर होंगी, वहाँ space की परवाह ही नहीं करनी पड़ती।"

सच: "space की परवाह नहीं" — कोष्ठक वाली भाषाओं में space की परवाह मशीन नहीं करती, पर इंसान को तब भी करनी पड़ती है — क्योंकि बिना साफ़ खिसकाव के उनका code पढ़ा ही नहीं जाता, और वहाँ की सबसे मशहूर बीमारी ठीक यही है: खिसकाव कुछ दिखाए, कोष्ठक कुछ और (पाठ-161)। यानी झंझट दोनों तरफ़ है — फ़र्क़ बस इतना कि Python में ग़लत खिसकाव पर चिट्ठी आती है (IndentationError — ठीक पंक्ति के साथ!), और कोष्ठक वाली भाषाओं में ग़लत-दिखता खिसकाव चुप रहता है। गिनिए आज के सात मरीज़ों में: छह बोलते थे, एक चुप — और वह चुप वाला ("18" == 18) हाशिए का नहीं, क़िस्म का था। हाशिए की हर बीमारी पर Python बोला।

और "इतनी बीमारियाँ" — गिनिए असल में याद क्या रखना है: चार आदतें। (1) हर if/elif/else के अंत में कोलन। (2) कोलन के बाद 4 space। (3) else/elif ठीक if की सीध में। (4) सिर्फ़ space। बस — आज की सात में से पाँच बीमारियाँ इन चार आदतों से कभी पैदा ही नहीं होंगी। और ज़्यादातर Python-ऐप कोलन के बाद हाशिया ख़ुद लगाते हैं — आधी मेहनत मशीन की। दो हफ़्ते में ये आदतें उँगलियों में बैठ जाती हैं (जैसे साइकिल पर संतुलन), और फिर हाशिया सोचना नहीं पड़ता। Python की सख़्ती शुरू में झंझट लगती है — फिर वह आपकी उँगलियों की आदत और आँख का भरोसा बन जाती है।

अभ्यास-खेल: दवाख़ाना-10 मश्क़

खेल 1 — सात मरीज़, सात पर्चे: ऊपर का सेहतमंद वोट-प्रोग्राम लीजिए, सात नक़लें — हर एक में ठीक एक बीमारी (39-45)। हर एक पर: पहले हाशिया-जासूस (हर पंक्ति के space कॉपी में), फिर चलाइए (दोनों राहें — 18 और 15!), फिर चिट्ठी नीचे से ऊपर (या चुप — तब कौन-सी राह मरी?), फिर इलाज। Python बीमारी-पट्टी में सातों — 44 के आगे नोट: "आँख को नहीं दिखती"; 45 के आगे: "चुप"।

खेल 2 — जासूस की गिनती (बिना मशीन): यह प्रोग्राम कॉपी में, हर पंक्ति के शुरू के space ठीक जैसे लिखे हैं: (0) x = int(input()) · (0) if x > 10: · (4) print("bada") · (6) print("bahut") · (0) elif x > 5: · (4) print("theek") · (2) else: · (4) print("chhota")। सिर्फ़ अंकों से बताइए: कहाँ-कहाँ बीमारी है, कौन-सी (40/41/43)? फिर सुधरे अंक लिखिए।

खेल 3 — मरी राह खोजो (चुप-शिकार): तीन फ़ैसले-प्रोग्राम जिनमें एक-एक चुप बीमारी छिपी है — हर एक को दोनों राहों से चलाइए और "कभी न चलने वाली" राह खोजिए: (क) jawab = input() · if jawab == 5: ... (ख) पाठ-160 का ग़लत-क्रम वाला मौसम (ग) if umar > 18: ("18 और ऊपर" के लिए)। हर एक पर: कौन-सा जवाब मरी राह दिखाता है, और जड़ क्या (क़िस्म? क्रम? सीमा?)। तीनों चुप — पर तीनों अलग परिवार!

आगे क्या सीखेंगे

दसवाँ दवाख़ाना पार — सात मरीज़ (39-45): भूला कोलन, हाशिया नहीं, बेवजह हाशिया, if में एक =, भटका else, tab-space मिलावट, और चुप "18" == 18; दो नए परिवार — IndentationError और TabError; हाशिया-जासूस (अंक गिनो, मेल देखो); और फ़ोन पर Tab पहचानने की तरकीब। Python बीमारी-पट्टी में अब बाईस बीमारियाँ।

और अब अध्याय-19 का बनाओ-पाठ — "पास-फ़ेल बताने वाला" प्रोग्राम — पर ACS-ढंग से: "फ़ेल!" नहीं, "अभी और मेहनत"। अंक पूछो (int()!), पहले जाँचो कि अंक 0-100 के बीच हैं भी या नहीं (or वाली सीमा-जाँच — ग़लत अंक पर ईमानदार चिट्ठी), फिर elif की सीढ़ी — बहुत बढ़िया / अच्छा / पास / मेहनत — बड़ी सीमा ऊपर, हर सीमा की दौड़, हर राह में इज़्ज़त की भाषा। पूरे अध्याय की पेटी — if, ==, else, >=, elif, हाशिया, and/or — एक प्रोग्राम में। पाठ-164: 🛠 बनाओ — "पास-फ़ेल बताने वाला" प्रोग्राम।
