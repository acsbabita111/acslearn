पाठ परिचय

हाट में आप सब्ज़ी वाले से पूछते हैं: "तीन किलो आलू का कितना?" वह मन में हिसाब करता है — और आपको एक जवाब देता है: "एक सौ बीस।" उस जवाब से आप आगे काम करते हैं — जेब से पैसे गिनते हैं, बाक़ी सामान का हिसाब जोड़ते हैं, घर जाकर माँ को बताते हैं। हिसाब उसने किया, पर जवाब आपके हाथ आया।

अब तक के पुर्ज़े काम करते थे — परदे पर छापते थे (namaste, pahada)। पर बहुत बार पुर्ज़े से हमें एक जवाब चाहिए, जिसे आगे बरतना हो। उसके लिए Python का तोहफ़ा: return (रिटर्न — "लौटाओ")। पुर्ज़ा अपना हिसाब करता है, और return से एक माल बुलाने वाले को लौटा देता है — वह माल किसी डिब्बे में रखिए, हिसाब में जोड़िए, जो चाहे कीजिए।

आप ऐसे पुर्ज़े पहले से बरत रहे हैं: len(saman) एक गिनती लौटाता है (परदे पर छापता नहीं — इसीलिए print(len(...)) लिखना पड़ता था!), input(...) जवाब लौटाता है, int(...) गिनती लौटाता है। आज आप अपने ऐसे पुर्ज़े बनाएँगे। और return की एक ख़ास आदत भी देखेंगे — वह पुर्ज़े को उसी पल रोक देता है (पाठ-171 के break जैसा!)। चलिए — सब्ज़ी वाले का हिसाब-पुर्ज़ा बनाते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. return वाला पुर्ज़ा बना पाएँगे — और लौटे माल को डिब्बे में रखकर, हिसाब में, print में बरत पाएँगे।

2. समझा पाएँगे कि return पर पुर्ज़ा वहीं रुकता है — उसके नीचे की पंक्तियाँ उस बुलावे में कभी नहीं चलतीं।

3. True/False लौटाने वाला पुर्ज़ा बनाकर if में बरत पाएँगे — सीमा की दौड़ समेत।

सब्ज़ी वाले का जवाब

पहला लौटाने वाला पुर्ज़ा — 🔮 अंदाज़ा पहले: jod हिसाब करके लौटाता है — छापता नहीं। दो दाँव: x में क्या? और आख़िरी पंक्ति पर (लौटे माल का दोगुना) क्या? —

def jod(a, b):
    return a + b

x = jod(2, 3)
print(x)
print(jod(10, 20) * 2)

नतीजा: 5 और 60। क्या हुआ (कॉपी में, चित्र के साथ): x = jod(2, 3) — दाएँ से बाएँ (पाठ-148 की पढ़ाई): पहले jod(2, 3) बुलाया → भीतर a = 2, b = 3 → return a + b → 5 लौटा → बुलावे की जगह मानो "5" आ गया → x = 5। दूसरी पंक्ति: jod(10, 20) → 30 लौटा → 30 * 2 = 60 → print। यानी जिस जगह पुर्ज़ा बुलाया, लौटा माल ठीक वहीं बैठ जाता है — जैसे सब्ज़ी वाले का "एक सौ बीस" आपके हिसाब की उस जगह बैठ गया। (पुर्ज़े के भीतर कोई print नहीं था — छपाई बाहर वाले ने की, अपनी मर्ज़ी से। यही आज का दिल है!)

दुकान का हिसाब — और return के बाद की पंक्ति: daam(kilo, bhav) — किलो × भाव लौटाओ। ग़ौर कीजिए return के नीचे एक print है — 🔮 दाँव: वह छपेगा? —

def daam(kilo, bhav):
    return kilo * bhav
    print("Yeh kabhi nahi chhapega")

aalu = daam(3, 40)
pyaaz = daam(2, 30)
print("Aalu:", aalu, "| Pyaaz:", pyaaz, "| Kul:", aalu + pyaaz)

नतीजा: Aalu: 120 | Pyaaz: 60 | Kul: 180 — और "Yeh kabhi nahi chhapega" कभी नहीं छपा! return = "यह लो जवाब, मैं चला" — return चलते ही पुर्ज़ा उसी पल रुकता है, और प्रोग्राम बुलाने वाली जगह लौट जाता है (पाठ-171 का break लूप को तोड़ता था; return पूरे पुर्ज़े को)। उसके नीचे की पंक्ति तक Python कभी पहुँचता ही नहीं — इसलिए return अक्सर पुर्ज़े की आख़िरी पंक्ति होता है। और देखिए लौटे माल की ताक़त: aalu और pyaaz डिब्बों में रखे, फिर आपस में जोड़े — कुल 180। अगर daam सिर्फ़ छापता, तो यह जोड़ असंभव होता (कल का पूरा पाठ इसी पर!)।

True/False लौटाने वाला पुर्ज़ा — 🔮 अंदाज़ा, तीन दौड़ें (40, 20, और सीमा — ठीक 33): पाठ-157 का सच-माल भी लौटाया जा सकता है —

def paas_hai(ank):
    return ank >= 33

ank = int(input("Ank? "))
if paas_hai(ank):
    print("Paas - shabash!")
else:
    print("Abhi aur mehnat.")

40 → Paas · 20 → Abhi aur mehnat. · 33 → Paas (सीमा — >=, पाठ-159!)। paas_hai(ank) True या False लौटाता है, और if सीधे उसी लौटे माल को पढ़ता है — "if paas_hai(ank):" पढ़िए जैसे बोलते हैं: "अगर पास है, तो..."। फ़ायदा: पास-अंक का नियम (33) एक जगह — पुर्ज़े के भीतर; कल 35 हो, तो एक पंक्ति बदली, हर जगह नया नियम (पाठ-190 का पूरा विषय!)। ऐसे पुर्ज़ों के नाम अक्सर सवाल जैसे होते हैं — paas_hai, khaali_hai, bada_hai।

रेखा-चित्र: सब्ज़ी वाले का जवाब

नीचे आज का पूरा पट्ट — return का लौटना, लौटा माल बुलावे की जगह, return पर रुकना, और True/False वाला पुर्ज़ा —

ऊपर का सुनहरा तीर आज का तोहफ़ा है — पुर्ज़े के भीतर हिसाब हुआ, और जवाब (5) लौटकर ठीक वहीं बैठ गया जहाँ पुर्ज़ा बुलाया गया था।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "return से पुर्ज़ा जवाब परदे पर दिखाता है — return और print एक ही चीज़ के दो नाम हैं! return लिखूँ या print, जवाब तो आ ही जाएगा।"

सच: आज के पहले प्रोग्राम में ही देखिए: jod के भीतर कोई print नहीं, सिर्फ़ return a + b — और x = jod(2, 3) पर परदे पर कुछ नहीं छपा! छपा तब, जब बाहर वाले ने ख़ुद print(x) लिखा। यानी return परदे से बात करता ही नहीं; वह जवाब बुलाने वाले को थमाता है — चुपचाप, हाथ में। सब्ज़ी वाला "एक सौ बीस" आपके कान में कहे या आपके हाथ में पर्ची थमा दे — दोनों अलग बातें हैं: कान में कही बात (print) सुनाई दी, पर आपके हिसाब में अपने-आप नहीं जुड़ी; हाथ की पर्ची (return) आप जेब में रख सकते हैं, दूसरी पर्ची से जोड़ सकते हैं, माँ को दिखा सकते हैं।

यह फ़र्क़ इतना ज़रूरी और इतना आम उलझन वाला है कि कल का पूरा पाठ इसी पर है — ग़लतफ़हमी-रजिस्टर का #10, "print बनाम return — दिखाना बनाम थमाना"। आज बस इतनी पक्की बात (कॉपी में मोटा): print परदे पर दिखाता है; return बुलाने वाले को थमाता है। एक तरकीब से जाँचिए: पुर्ज़े के जवाब से आगे कोई हिसाब करना है (जोड़ना, तुलना करना, if में पूछना)? — तो return; बस इंसान को दिखाना है, और कुछ नहीं? — तो print भी चलेगा (पर तब भी, अक्सर बेहतर है कि पुर्ज़ा return करे और बाहर वाला print — पाठ-190 की वजह!)। return दिखाता नहीं, थमाता है — और थमाया हुआ ही आगे काम आता है।

अभ्यास-खेल: तोहफ़ा-मश्क़

खेल 1 — हिसाब के चार पुर्ज़े: हर एक return करे, छापे नहीं: (क) ghatav(a, b) (ख) dugna(n) (ग) ausat(teen_ank_ka_jod) — या तीन पैरामीटर, औसत लौटाओ (घ) daam(kilo, bhav)। फिर बाहर, लौटे मालों से एक बड़ा हिसाब: dugna(jod(3, 4)) — 🔮 दाँव: भीतर से बाहर (पाठ-150!) — पहले jod → 7, फिर dugna(7) → 14। चलाकर जाँचिए। एक पुर्ज़े का लौटा माल दूसरे की खिड़की में!

खेल 2 — सवाल वाले पुर्ज़े (True/False): (क) bada_hai(a, b) — a > b? (ख) sam_hai(n) — सम है? (पाठ-158) (ग) khaali_hai(suchi) — len == 0? (पाठ-179)। हर एक को if में बरतिए, दोनों राहें जाँचिए — और sam_hai पर सीमा: 0 सम है? (हाँ!)। कॉपी में: "सवाल वाले पुर्ज़े का नाम पढ़कर if कैसा लगता है?"

खेल 3 — return के नीचे + हुक्म-बही: (नक़ल पर) daam में return से पहले एक print("Hisab ho raha hai...") और बाद में एक print। 🔮 दोनों पर दाँव — कौन-सा छपेगा? कितनी बार (daam दो बार बुलाया)? चलाइए। हुक्म-बही के पुर्ज़ा-पन्ने पर: "return = जवाब थमाओ · लौटा माल बुलावे की जगह बैठे · return पर पुर्ज़ा रुके (नीचे कुछ नहीं) · True/False भी लौटे · return ≠ print — कल पूरी बात"।

आगे क्या सीखेंगे

तोहफ़ा मिल गया — return (जवाब लौटाओ), लौटा माल बुलावे की जगह बैठता है (डिब्बे में, हिसाब में, print में), दुकान का daam और कुल, return पर पुर्ज़ा वहीं रुकता है, True/False लौटाने वाले सवाल-पुर्ज़े (if paas_hai(ank)), और len-input-int भी लौटाने वाले पुर्ज़े हैं।

आज की ग़लतफ़हमी-तोड़ में एक वादा था — कल उसका पूरा पाठ: print बनाम return — दिखाना बनाम थमाना (ग़लतफ़हमी-रजिस्टर #10)। एक प्रयोग जो हर नए प्रोग्रामर को चौंकाता है: पुर्ज़ा return की जगह print करे, और बाहर कोई उसका जवाब डिब्बे में रखे — तो डिब्बे में क्या आता है? परदे पर तो जवाब दिख गया था... पर डिब्बे में एक अजीब, नया शब्द: None ("कुछ नहीं")! और फिर उस None से हिसाब करने पर चिट्ठी। सब्ज़ी वाले ने कान में कहा, हाथ में कुछ नहीं दिया — और आप उस ख़ाली हाथ से जोड़ लगाने चले! पाठ-189: print बनाम return — दिखाना बनाम थमाना (मशहूर ग़लतफ़हमी #2)।
