पाठ परिचय

कल वाला सब्ज़ी वाला याद है? आज दो सब्ज़ी वाले हैं। पहला आपके पूछने पर ज़ोर से बोलता है — "एक सौ बीस!" — आसपास सब सुन लेते हैं, पर आपके हाथ में कुछ नहीं आता। दूसरा चुपचाप एक पर्ची लिखकर आपके हाथ में थमा देता है — "120"। घर पहुँचकर माँ पूछती हैं: "कुल कितना हुआ?" — पहले वाले का जवाब हवा में उड़ गया; दूसरे वाले की पर्ची आपकी जेब में है, उसे बाक़ी पर्चियों से जोड़ सकते हैं।

यही Python का print और return है — और यही इस कोर्स के ग़लतफ़हमी-रजिस्टर का #10 (Founder की v2-सूची का दूसरा नया जोड़)। दुनिया भर में नए प्रोग्रामर इन दोनों को सबसे ज़्यादा उलझाते हैं, क्योंकि परदे पर दोनों में "जवाब दिखता" लगता है। पर print सिर्फ़ दिखाता है (ज़ोर से बोलना), return थमाता है (हाथ में पर्ची)।

और आज एक नया Python-शब्द मिलेगा जो इसी उलझन से पैदा होता है: None (नन — "कुछ नहीं", ख़ाली हाथ)। जो पुर्ज़ा return नहीं करता, वह चुपचाप None थमाता है — और उस None से हिसाब करने चलो, तो चिट्ठी। आज यह पूरा राज़ खुलेगा, और वह पक्का ढंग भी जो दुनिया के अच्छे प्रोग्रामर अपनाते हैं। चलिए — दोनों सब्ज़ी वालों से मिलते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. print (दिखाना) और return (थमाना) का फ़र्क़ बोल पाएँगे — और बता पाएँगे कि दोनों में परदा कब एक-सा दिखता है, फिर भी अलग क्यों।

2. None पहचान पाएँगे — return-रहित पुर्ज़े का ख़ाली हाथ — और None से हिसाब की चिट्ठी पढ़ पाएँगे।

3. पक्का ढंग अपना पाएँगे — पुर्ज़ा return करे, बाहर वाला print करे।

दो सब्ज़ी वाले

दिखाने वाला बनाम थमाने वाला — 🔮 अंदाज़ा पहले: दो पुर्ज़े — एक भीतर print करता है, दूसरा return। दोनों के जवाब डिब्बों में रखे, फिर दोनों डिब्बे छापे। दाँव: परदे पर क्या-क्या, और किस क्रम में? x में क्या? y में? —

def jod_dikhao(a, b):
    print(a + b)

def jod_thamao(a, b):
    return a + b

x = jod_dikhao(2, 3)
y = jod_thamao(2, 3)
print("x:", x, "| y:", y)

नतीजा: पहले अकेला 5 (jod_dikhao ने बुलाते ही परदे पर दिखा दिया — ज़ोर से बोला), फिर x: None | y: 5। ग़ौर कीजिए — x में None! jod_dikhao ने 5 परदे पर दिखाया, पर बुलाने वाले के हाथ में कुछ नहीं थमाया; और Python का नियम है (कॉपी में मोटा): जो पुर्ज़ा return नहीं करता, वह अपने-आप None लौटाता है — ख़ाली हाथ। jod_thamao ने परदे पर कुछ नहीं दिखाया, पर 5 थमाया — y = 5।

None — "कुछ नहीं" का अपना नाम: None Python का एक ख़ास शब्द है (True-False की तरह बड़े अक्षर से, बिना उल्टे-कॉमा — पाठ-157)। वह 0 नहीं (0 एक गिनती है), "" नहीं (ख़ाली शब्द भी एक शब्द है) — वह "यहाँ कोई माल ही नहीं" का नाम है। मज़ेदार बात: print ख़ुद भी एक ऐसा ही पुर्ज़ा है — x = print("Ha") — परदे पर Ha दिखेगा, और x में None! (print का काम दिखाना है, थमाना नहीं।) पाठ-177 का saman = saman.append(...) वाला मरीज़ भी यही था — append कुछ नहीं थमाता, तो saman में None।

ख़ाली हाथ से हिसाब — चिट्ठी: x = jod_dikhao(2, 3) के बाद print(x * 2) —

Traceback (most recent call last):
  File "purza.py", line 5, in <module>
    print(x * 2)
          ~~^~~
TypeError: unsupported operand type(s) for *: 'NoneType' and 'int'

"None और गिनती का गुणा नहीं होता" — ख़ाली हाथ को दो से गुणा! और ध्यान दीजिए: इस चिट्ठी से पहले परदे पर 5 छप चुका होता है — जो धोखा देता है: "5 तो आया था!" — हाँ, आया था, पर हवा में (परदे पर), हाथ में नहीं। जाँच-सवाल (कॉपी में): डिब्बे में None दिखे या NoneType की चिट्ठी आए, तो पूछो — "जिस पुर्ज़े से यह माल आया, उसमें return है?"

पक्का ढंग — पुर्ज़ा थमाए, बाहर वाला दिखाए: 🔮 अंदाज़ा — तीन चीज़ों का बिल, और 200 से ज़्यादा पर छूट —

def daam(kilo, bhav):
    return kilo * bhav

kul = daam(3, 40) + daam(2, 30) + daam(1, 50)
print("Bill:", kul, "rupaye")
if kul > 200:
    print("200 se zyada - 10 rupaye chhoot!")
    print("Dena hai:", kul - 10)

नतीजा: Bill: 230 rupaye, फिर छूट, फिर Dena hai: 220। तीन लौटे माल जुड़े (120 + 60 + 50), कुल पर if चला, छूट घटी — यह सब इसलिए संभव कि daam थमाता है। अगर daam भीतर print करता, तो तीन संख्याएँ परदे पर छप जातीं, और kul = None + None + None → चिट्ठी! नियम (कॉपी में मोटा): हिसाब वाला पुर्ज़ा return करे; दिखाना बाहर वाले का काम — तब वही पुर्ज़ा किसी भी प्रोग्राम में लगे: कहीं छापो, कहीं जोड़ो, कहीं if में पूछो।

रेखा-चित्र: दो सब्ज़ी वाले

नीचे आज का पूरा पट्ट — ज़ोर से बोलना बनाम पर्ची थमाना, None का ख़ाली हाथ, और पक्का ढंग —

ऊपर के दो डिब्बों के नीचे के "हाथ" देखिए — बाएँ ख़ाली (None), दाएँ पर्ची (5); परदा दोनों में कुछ न कुछ दिखाता लगा, पर आगे के हिसाब में सिर्फ़ थमाया हुआ ही काम आया।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "तो print बुरा है और return अच्छा! आज से हर पुर्ज़े में सिर्फ़ return — print कभी नहीं।"

सच: दोनों अच्छे हैं — बस अलग काम के। print का काम है इंसान से बात करना — परदे पर कुछ दिखाना, जिसे कोई आँख पढ़े; return का काम है प्रोग्राम के दूसरे हिस्से को माल देना — जिससे आगे हिसाब हो। दोनों की ज़रूरत है: बिना print के कोई प्रोग्राम किसी इंसान को कुछ बता ही नहीं सकता (पाठ-131 से आज तक का हर परदा print का है!); बिना return के पुर्ज़े एक-दूसरे को कुछ दे नहीं सकते। ग़लती सिर्फ़ तब है जब जिसे थमाना था, उसे दिखा दिया (हिसाब वाले पुर्ज़े में print — आज का None वाला मरीज़), या कभी-कभी उलटा — जिसे दिखाना था, उसे सिर्फ़ थमा दिया और किसी ने छापा ही नहीं (परदा ख़ाली — पाठ-186 का चुप-परिवार!)।

और कुछ पुर्ज़े ऐसे होते हैं जिनका काम ही दिखाना है — namaste(naam), pahada(n, tak) — उनमें print बिल्कुल सही है (परसों-कल के पुर्ज़े!), और वे None लौटाते हैं, जो ठीक है, क्योंकि उनसे कोई हिसाब की उम्मीद ही नहीं करता। फ़ैसला-सवाल (कॉपी में): "इस पुर्ज़े का नतीजा किसी इंसान की आँख के लिए है, या प्रोग्राम के अगले हिसाब के लिए?" — आँख के लिए → print (दिखाने वाला पुर्ज़ा); हिसाब के लिए → return (हिसाब वाला पुर्ज़ा); दोनों के लिए → return करो, और बाहर वाला print करे (क्योंकि थमाया हुआ बाद में दिखाया जा सकता है, पर दिखाया हुआ बाद में थमाया नहीं जा सकता!)। print और return दुश्मन नहीं — एक मुँह है, एक हाथ; मुँह से बताओ, हाथ से थमाओ।

अभ्यास-खेल: मुँह-हाथ मश्क़

खेल 1 — दिखाने वाला या थमाने वाला? (अदालत): आठ पुर्ज़े — हर एक पर फ़ैसला (print या return) और कारण: (क) swagat(naam) (ख) jod(a, b) (ग) pahada(n, tak) (घ) daam(kilo, bhav) (ङ) paas_hai(ank) (च) parchi_dikhao(saman) (छ) ausat(suchi) (ज) janamdin(naam)। फिर (ख) और (घ) को दोनों तरह लिखिए, और हर एक के जवाब से kul बनाने की कोशिश कीजिए — कौन-सा चिट्ठी देता है?

खेल 2 — None-जासूस: चार प्रयोग — हर एक पर पहले दाँव (परदा? डिब्बे में क्या?): (क) x = print("Ha") · print(x) (ख) s = सूची जिसमें बस "aalu" · y = s.append("pyaaz") · print(y, s) (ग) def kuchh_nahi(): · print("hello") — फिर z = kuchh_nahi() · print(z) (घ) def sirf_hisab(a): · a * 2 (न print, न return!) — फिर print(sirf_hisab(5))। (घ) सबसे चालाक: हिसाब हुआ, पर किसी को दिया ही नहीं — None!

खेल 3 — अपनी दुकान का बिल + हुक्म-बही: daam (return) से पाँच चीज़ों का बिल — लूप से (पाठ-178: भावों और किलो की दो सूचियाँ, पतों पर लूप — पाठ-179!), kul जमा, फिर छूट का नियम (अपना तय कीजिए), फिर बाहर सुंदर छपाई। पहले पाँच-चीज़ का हिसाब हाथ से कॉपी पर — मशीन से मिलाइए। हुक्म-बही के पुर्ज़ा-पन्ने पर: "print = दिखाना (मुँह) · return = थमाना (हाथ) · return-रहित = None · None से हिसाब = TypeError · हिसाब वाला return, दिखाना बाहर · ग़लतफ़हमी #10"।

आगे क्या सीखेंगे

दोनों सब्ज़ी वाले पहचान लिए — print दिखाता (ज़ोर से बोलना), return थमाता (हाथ में पर्ची); return-रहित पुर्ज़ा None (ख़ाली हाथ) लौटाता है; None से हिसाब की TypeError (और पहले छपे 5 का धोखा); print और append भी None; और पक्का ढंग — हिसाब वाला पुर्ज़ा return करे, बाहर वाला print करे। ग़लतफ़हमी #10 अब साफ़।

पाठ-138 से एक नियम पूरे कोर्स में चला आ रहा है — ACS का अपना नियम: "एक चीज़ = एक जगह" (भाव एक डिब्बे में, बदलो तो एक जगह)। पाठ-185 और 188 में दो बार कहा गया: "इसकी पूरी कहानी पाठ-190 में।" कल वह कहानी: एक प्रोग्राम जिसमें एक ही हिसाब तीन जगह दोहराया गया है (और एक जगह किसी ने बदलना भूल दिया — चुप बीमारी!), और उसे एक पुर्ज़े में समेटना — फिर नियम बदले, तो एक पंक्ति। ACS की website के करोड़ों पन्ने इसी नियम पर टिके हैं (एक मास्टर-टेम्पलेट, एक generator) — कल वही नियम आपके code में। पाठ-190: "एक चीज़ = एक जगह" — दोहराया कोड पुर्ज़े में समेटो (ACS का अपना नियम, कोड में!)।
