पाठ परिचय

भाग-अ का पाठ-39 याद कीजिए — "बड़ी समस्या के छोटे टुकड़े — शादी की तैयारी का गणित"। गाँव में शादी हो, तो घर का बड़ा सब कुछ अकेले नहीं करता। वह काम बाँटता है: टेंट वाले चाचा, खाने वाली टोली, निमंत्रण-पत्र वाले भैया, बाजे वाले। हर टोली अपना काम पूरा जानती है; बड़े की योजना बस इतनी — "टेंट लगवाओ, खाना बनवाओ, निमंत्रण भिजवाओ।" तीन वाक्य, पूरी शादी।

उस दिन यह काग़ज़ की सोच थी। आज वह code में आती है — पुर्ज़ों से बना प्रोग्राम। पाठ-164 का अंक-पत्र याद है? बारह पंक्तियाँ, एक के नीचे एक, पाँच तल का हाशिया। आज वही अंक-पत्र तीन पुर्ज़ों में बँटेगा — एक अंक पूछे, एक श्रेणी तय करे, एक छापे — और मुख्य हिस्सा सिर्फ़ तीन पंक्तियों का रह जाएगा, जो एक कहानी की तरह पढ़ा जाए।

साथ में पुर्ज़ों की दो नई बातें। पहली: एक पुर्ज़ा दूसरे पुर्ज़े को बुला सकता है (जैसे खाने वाली टोली ख़ुद पानी वाले को बुलाए)। दूसरी: पुर्ज़े के भीतर बने डिब्बे बाहर नहीं दिखते — रसोई का बर्तन रसोई में रहता है, आँगन में नहीं! यह पहली बार अजीब लगता है, पर यही पुर्ज़ों को एक-दूसरे से सुरक्षित रखता है। चलिए — शादी की योजना बनाते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. एक बड़े प्रोग्राम को पुर्ज़ों में बाँट पाएँगे — हर पुर्ज़ा एक काम, मुख्य हिस्सा छोटा और कहानी जैसा।

2. कई return वाला पुर्ज़ा (हर राह अपना जवाब) और पुर्ज़े के भीतर पुर्ज़े का बुलावा लिख पाएँगे।

3. समझा पाएँगे कि पुर्ज़े के भीतर के डिब्बे बाहर नहीं दिखते — और हर पुर्ज़ा अलग से जाँच पाएँगे।

शादी की योजना, code में

टुकड़े पहले, काग़ज़ पर (पाठ-39 का ढंग): अंक-पत्र के काम — (1) अंक पूछो (गिनती चाहिए — int!); (2) अंक से श्रेणी तय करो (बढ़िया / अच्छा / पास / मेहनत — पाठ-164 की सीढ़ी); (3) नाम, अंक, श्रेणी एक पंक्ति में छापो। तीन काम, तीन पुर्ज़े — और तीनों के नाम काम बताएँ (पाठ-185)।

तीन पुर्ज़े, एक कहानी — 🔮 अंदाज़ा पहले (चार दौड़ें: Sita 82, Ramu 45, Mohan 20, और सीमा — Gita 75) —

def ank_poochho():
    return int(input("Ank (0 se 100)? "))

def shreni(ank):
    if ank >= 75:
        return "Bahut badhiya"
    elif ank >= 60:
        return "Achha"
    elif ank >= 33:
        return "Paas"
    else:
        return "Abhi aur mehnat"

def chhapo(naam, ank):
    print(naam + ":", ank, "ank -", shreni(ank))

naam = input("Naam? ")
ank = ank_poochho()
chhapo(naam, ank)

नतीजे: 82 → Bahut badhiya · 45 → Paas · 20 → Abhi aur mehnat · ठीक 75 → Bahut badhiya (>= — सीमा सही)।

तीन पुर्ज़े, तीन तरह के (कॉपी में): (1) ank_poochho() — खिड़की ख़ाली, पर लौटाता है: भीतर input से पूछा, int() किया, return (पाठ-188: input भी लौटाने वाला पुर्ज़ा था — यह उसका भाई!)। (2) shreni(ank) — कई return: हर राह का अपना return, और जो राह चली, उसका return चलते ही पुर्ज़ा रुका (पाठ-188 — "यह लो जवाब, मैं चला"); इसलिए elif-सीढ़ी की "ठीक एक राह" (पाठ-160) यहाँ "ठीक एक जवाब" बन गई। (3) chhapo(naam, ank) — दिखाने वाला (print — पाठ-189 का फ़ैसला-सवाल: नतीजा आँख के लिए), और ध्यान दीजिए — इसके भीतर shreni(ank) बुलाया गया: एक पुर्ज़ा दूसरे को बुला सकता है (खाने वाली टोली ने पानी वाले को बुलाया!)।

मुख्य हिस्सा — तीन पंक्ति, एक कहानी: नाम पूछो → अंक पूछो → छापो। पढ़िए ज़ोर से — लगभग हिंदी वाक्य है! पाठ-164 में यही काम बारह पंक्तियों में गुँथा था; अब हर टुकड़ा अपने नाम वाले डिब्बे में, और योजना अलग। दो-मंज़िला ढंग (पाठ-186) भी साफ़ दिखता है: ऊपर तीन def (पुर्ज़ों की अलमारी), नीचे तीन पंक्ति (योजना)। पास-अंक 33 से 35 करना हो? — सिर्फ़ shreni में; छपाई का ढंग बदलना हो? — सिर्फ़ chhapo में। हर बदलाव की एक जगह (पाठ-190!)।

रसोई का बर्तन रसोई में — पुर्ज़े के भीतर के डिब्बे: एक पुर्ज़ा def bill(): · kul = 100 · return kul — फिर बाहर bill() बुलाया, और print(kul) —

    print(kul)
          ^^^
NameError: name 'kul' is not defined

"kul नाम परिभाषित नहीं" — पर पुर्ज़े में तो kul था! राज़ (कॉपी में मोटा): पुर्ज़े के भीतर बना डिब्बा सिर्फ़ पुर्ज़े के भीतर रहता है — पुर्ज़ा ख़त्म, डिब्बा ख़त्म (भीतर-भीतर ही; पैरामीटर भी ऐसे ही भीतरी डिब्बे हैं)। बाहर माल चाहिए — तो return से थमाओ, और बाहर किसी डिब्बे में रखो: kul = bill()। यह रोक नहीं, सुरक्षा है — तीस पुर्ज़ों में तीस अलग kul हों, तो भी कोई किसी का माल नहीं बिगाड़ता; हर टोली के बर्तन अपनी रसोई में।

रेखा-चित्र: शादी की योजना

नीचे आज का पूरा पट्ट — योजना (मुख्य हिस्सा) और टोलियाँ (पुर्ज़े), पुर्ज़े से पुर्ज़े का बुलावा, और रसोई का बर्तन —

ऊपर की काली पट्टी योजना है, नीचे के तीन रंगीन डिब्बे टोलियाँ — योजना को बस टोलियों के नाम पुकारने हैं; हर टोली के भीतर क्या होता है, वह उसकी अपनी रसोई की बात है।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "पुर्ज़े के भीतर के डिब्बे बाहर नहीं दिखते — यह Python की कमी है! अगर सब डिब्बे हर जगह दिखते, तो return की झंझट ही न होती — जो चाहिए, सीधे ले लो।"

सच: सोचिए शादी में हर टोली के सारे बर्तन एक ही आँगन में रखे हों — खाने वाली टोली का "बड़ा पतीला", पानी वाली टोली का "बड़ा पतीला", चाय वाली टोली का "बड़ा पतीला" — सबका नाम एक, सब एक जगह। कोई टोली "बड़ा पतीला" उठाए, तो किसका? और खाने वाली टोली ने उसमें दाल डाली, तभी चाय वाली ने उसमें पानी उबाल दिया — दाल बर्बाद! यही होता अगर पुर्ज़ों के भीतरी डिब्बे सबको दिखते: तीस पुर्ज़ों में तीस kul, तीस ginti, तीस i — सब एक-दूसरे का माल बिगाड़ते, और कौन-सी ग़लती किसने की, खोजना असंभव। पुर्ज़ों का अपना भीतरी संसार होना ही उन्हें भरोसेमंद बनाता है: shreni के भीतर कुछ भी हो, वह chhapo के डिब्बे नहीं छू सकता।

और "return की झंझट" — असल में return ही वह साफ़ दरवाज़ा है जिससे पता रहता है कि पुर्ज़े से क्या बाहर आया। जैसे टोली का मुखिया बड़े को बताए: "खाना तैयार, 200 थालियाँ" — बस यही बाहर आता है; टोली के भीतर कितने चूल्हे जले, कितने बर्तन धुले — बड़े को उससे मतलब नहीं। इसी से हर टोली (हर पुर्ज़ा) अलग से जाँची जा सकती है: shreni(82), shreni(20), shreni(75) — बाक़ी प्रोग्राम के बिना — और जब तीनों पुर्ज़े अलग-अलग ठीक, तो पूरा प्रोग्राम भी ठीक होने की संभावना बहुत बड़ी (पाठ-173 का "छोटे पर पहले जाँचो", पुर्ज़ों के रूप में!)। भीतरी डिब्बे छिपे रहना कमी नहीं — हर टोली की अपनी रसोई है, और return उसका इकलौता साफ़ दरवाज़ा।

अभ्यास-खेल: टोली-मश्क़

खेल 1 — हर पुर्ज़ा अलग से: आज के तीनों पुर्ज़े, पर मुख्य हिस्से की जगह जाँच-बुलावे: print(shreni(82)), print(shreni(60)), print(shreni(59)), print(shreni(33)), print(shreni(0)) — हर एक पर पहले दाँव (सीमाएँ!), फिर चलाइए। फिर chhapo("Test", 50) अकेले। सब ठीक? तब पूरा प्रोग्राम। कॉपी में: "टुकड़े अलग से जाँचने से क्या आसान हुआ?"

खेल 2 — अपना प्रोग्राम पुर्ज़ों में: पाठ-174 का पहाड़ा-छापू या पाठ-184 का पर्ची-ऐप लीजिए — उसे पुर्ज़ों में बाँटिए (जैसे: poochho_pahada(), pahada(n, tak), menu_dikhao(), jodo(saman), dekho(saman)...)। पहले कॉपी पर टुकड़े और नाम (पाठ-39 का ढंग), फिर code। मुख्य हिस्सा कितनी पंक्तियों का रह गया? पहले जैसी सब दौड़ें फिर से — परदे एक-से?

खेल 3 — रसोई-प्रयोग + हुक्म-बही: तीन प्रयोग, हर एक पर पहले दाँव: (क) def bill(): · kul = 100 — फिर बाहर print(kul) (ख) वही, पर kul = bill() और return के साथ (ग) बाहर kul = 5, फिर def badlo(): · kul = 99 — badlo() बुलाओ, फिर print(kul) — बाहर वाला kul बदला? (नहीं! भीतर एक नया, अलग kul बना — बाहर वाला अछूता 5)। हुक्म-बही के पुर्ज़ा-पन्ने पर: "बड़ा काम → टुकड़े → पुर्ज़े · मुख्य हिस्सा = योजना · कई return, ठीक एक चले · पुर्ज़ा पुर्ज़े को बुला सकता · भीतरी डिब्बे भीतर ही · बाहर चाहिए → return · हर पुर्ज़ा अलग से जाँचो"।

आगे क्या सीखेंगे

शादी की योजना code में — बड़ा काम छोटे पुर्ज़ों में (ank_poochho, shreni, chhapo), कई return और ठीक एक जवाब, पुर्ज़े से पुर्ज़े का बुलावा, तीन पंक्ति की कहानी-जैसी योजना, भीतरी डिब्बे भीतर ही (रसोई का बर्तन), और हर पुर्ज़ा अलग से जाँचने की आदत। भाग-अ का पाठ-39 अब पूरी तरह code में।

और अब — दवाख़ाना-13! पुर्ज़ों की बीमारियाँ — और इस बार कई चुप: बिन बुलाया पुर्ज़ा (पाठ-186 का #9), कोष्ठक भूले, return की जगह print (None — पाठ-189 का #10), भटका return (लूप के भीतर return — पहले ही चक्कर में पुर्ज़ा भाग गया, जोड़ अधूरा!), और बोलने वाले: बनाने से पहले बुलाया (NameError), सामान कम-ज़्यादा (TypeError), भीतरी डिब्बा बाहर पुकारा (NameError)। स्टेथोस्कोप: "ख़ाली परदा" वाली जाँच-सूची (पाठ-186), हर पुर्ज़ा अलग से, और हाशिया-जासूस (return किस तल पर?)। पाठ-192: टूटा कोड ठीक करो-13 — बिन बुलाया पुर्ज़ा, भटका return।
