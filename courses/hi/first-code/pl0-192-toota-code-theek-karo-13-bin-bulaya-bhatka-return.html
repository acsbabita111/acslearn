पाठ परिचय

शादी में एक टोली का मुखिया सुबह-सुबह बड़े के पास आया: "खाना तैयार!" बड़े ने राहत की साँस ली — पर दोपहर को पता चला कि सिर्फ़ पहली हांडी पकी थी; मुखिया पहली हांडी देखते ही ख़बर देने दौड़ पड़ा, बाक़ी हांडियाँ चूल्हे पर पड़ी रहीं! काम शुरू हुआ, ख़बर आ गई, काम अधूरा — यही आज के दवाख़ाने का शीर्षक-मरीज़ है: भटका return।

प्रोग्राम का दवाख़ाना-13 — पुर्ज़ों की बीमारियाँ। Python बीमारी-पट्टी 24-58 तक भरी है; आज 59-65। और इस अध्याय के मरीज़ों में एक ख़ास बात है: पुर्ज़े दो हिस्सों से बनते हैं — बनाना (def) और बुलाना — इसलिए बीमारी किसी भी हिस्से में हो सकती है, और कई बार चिट्ठी उस हिस्से में आती है जहाँ ग़लती नहीं है (पाठ-189 का None — ग़लती पुर्ज़े में, चिट्ठी बाहर के हिसाब में!)।

सात मरीज़ों में चार चुप हैं — बिन बुलाया पुर्ज़ा, भूले कोष्ठक, None वाला (आधा-चुप), और भटका return। इसलिए आज के स्टेथोस्कोप वही हैं जो इस अध्याय ने दिए: पाठ-186 की ख़ाली-परदा जाँच-सूची, पाठ-191 का हर पुर्ज़ा अलग से, पाठ-163 का हाशिया-जासूस (return किस तल पर?), और पाठ-170 की दो-रास्ते की जाँच। दस्ताने पहनिए — टोलियों की जाँच करते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बीमारी 59-65 पहचान पाएँगे — चार चुप (बिन बुलाया, कोष्ठक, None, भटका return) और तीन बोलते (NameError दो रूप, TypeError)।

2. भटका return हाशिया-जासूस से पकड़ पाएँगे — return लूप के भीतर (8) या बाहर (4)?

3. चार स्टेथोस्कोप एक साथ बरत पाएँगे — ख़ाली-परदा सूची, हर पुर्ज़ा अलग, return का तल, दो रास्ते।

सात मरीज़ — टोलियों की जाँच

बीमारी-59 · बिन बुलाया पुर्ज़ा (चुप) — def namaste(): ... लिखा, नीचे बुलावा नहीं। परदा ख़ाली, चिट्ठी नहीं (पाठ-186, ग़लतफ़हमी #9)। पहचान: ख़ाली-परदा जाँच-सूची का पहला सवाल — "बुलाया?" इलाज: नीचे namaste()।

बीमारी-60 · कोष्ठक भूले (चुप) — namaste (बिना कोष्ठक) — सिर्फ़ नाम पुकारा, काम नहीं कहा। फिर ख़ाली परदा। इलाज: namaste()। (इसका रिश्तेदार: x = len — बिना कोष्ठक — x में गिनती नहीं, पुर्ज़ा ख़ुद आ बैठता है; छापो तो एक अजीब पंक्ति दिखती है जिसमें पुर्ज़े का नाम और एक लंबा अंक होता है — वह "पुर्ज़े का पता" है, जवाब नहीं!)

बीमारी-61 · बनाने से पहले बुलाया (बोलता) — NameError: name 'namaste' is not defined (पाठ-186)। इलाज: दो-मंज़िला ढंग — def ऊपर, बुलावे नीचे।

बीमारी-62 · सामान कम-ज़्यादा (बोलता) — TypeError: namaste() missing 1 required positional argument: 'naam' / takes 1 positional argument but 2 were given (पाठ-187)। इलाज: जितने पैरामीटर, उतना सामान, उसी क्रम में।

बीमारी-63 · return की जगह print (आधा-चुप) — हिसाब वाले पुर्ज़े में print — बाहर x में None; चिट्ठी बाद में, हिसाब पर: TypeError ... 'NoneType' (पाठ-189, ग़लतफ़हमी #10)। धोखा: परदे पर जवाब पहले छप चुका होता है! पहचान: "यह माल जिस पुर्ज़े से आया, उसमें return है?" इलाज: हिसाब वाला पुर्ज़ा return करे।

बीमारी-64 · भटका return (चुप) — आज का शीर्षक-मरीज़: सूची का जोड़ लौटाने वाला पुर्ज़ा — 🔮 अंदाज़ा: 5, 10, 15 का जोड़ क्या आना चाहिए? और यह code क्या देगा? —

def jod_suchi(ank):
    kul = 0
    for a in ank:
        kul = kul + a
        return kul

print(jod_suchi([5, 10, 15]))

नतीजा: 5 — जबकि होना था 30! कोई चिट्ठी नहीं। जड़ — हाशिया-जासूस से (कॉपी में): 0 (def) · 4 (kul = 0) · 4 (for) · 8 (kul = kul + a) · 8 (return) — return लूप के भीतर है! पहले चक्कर में: kul = 0 + 5 = 5 → return 5 → पुर्ज़ा उसी पल ख़त्म (पाठ-188 — "यह लो जवाब, मैं चला") — 10 और 15 तक कभी पहुँचा ही नहीं। पहली हांडी देखकर ख़बर देने दौड़ा मुखिया! इलाज: return को लूप के बाहर (4 space — for की सीध में) — "सब चक्कर पूरे हों, फिर जवाब" —

def jod_suchi(ank):
    kul = 0
    for a in ank:
        kul = kul + a
    return kul

bikri = [5, 10, 15]
print("Kul:", jod_suchi(bikri))
print("sum() se jaanch:", sum(bikri))

नतीजा: Kul: 30 — और sum() भी 30: दो रास्ते, एक जवाब (पाठ-170)। यह पाठ-173 की बीमारी-49 ("भटका print") का पुर्ज़ा-रूप है — एक हाशिया इधर-उधर, पूरा मतलब बदला। फ़र्क़ बस इतना: भटका print ज़्यादा छापता है, भटका return कम काम करता है — और यह पहचानना कठिन, क्योंकि जवाब एक साफ़-सुथरी गिनती है।

बीमारी-65 · भीतरी डिब्बा बाहर पुकारा (बोलता) — पुर्ज़े के भीतर kul बना, बाहर print(kul) → NameError: name 'kul' is not defined (पाठ-191 — रसोई का बर्तन)। इलाज: kul = jod_suchi(...) — return से थमाओ, बाहर रखो। (और रिश्तेदार: def बिना कोलन → SyntaxError: expected ':'; def के नीचे हाशिया नहीं → IndentationError: expected an indented block after function definition — बीमारी-39/40 के पुर्ज़ा-रूप।)

रेखा-चित्र: दवाख़ाना-13

नीचे सात मरीज़ और भटके return की पूरी तस्वीर —

बीच के दो काले-हरे परदे एक ही पुर्ज़े के दो रूप हैं — फ़र्क़ सिर्फ़ return की सुनहरी पंक्ति के आगे के अंक का (8 बनाम 4); उस एक हाशिए ने तय किया कि मुखिया पहली हांडी पर दौड़ेगा या सब पकने के बाद।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "पुर्ज़े में ग़लती हो, तो चिट्ठी पुर्ज़े की पंक्ति पर ही आएगी — अगर चिट्ठी बाहर किसी हिसाब पर आई, तो ग़लती बाहर ही होगी। पुर्ज़ा तो ठीक लिखा था!"

सच: पुर्ज़ों के साथ यह सबसे भटकाने वाली बात है: ग़लती पुर्ज़े में, चिट्ठी बाहर। बीमारी-63 सोचिए — पुर्ज़े में return की जगह print; पुर्ज़ा अपनी पंक्ति पर कोई चिट्ठी नहीं देता (print करना जायज़ है!); बाहर x = jod(2, 3) — कोई चिट्ठी नहीं (None रखना जायज़ है!); और तीन पंक्ति नीचे x * 2 पर अचानक TypeError। चिट्ठी उस पंक्ति की ओर इशारा करती है — "यहाँ None और गिनती का गुणा" — पर जड़ वहाँ नहीं, ऊपर पुर्ज़े के भीतर है। पाठ-134 का "चिट्ठी नीचे से ऊपर पढ़ो" और पाठ-143 का "ग़लती ऊपर, चिट्ठी नीचे" — दोनों यहाँ और गहरे: चिट्ठी बताती है कि कहाँ गड़बड़ दिखी; ग़लती कहाँ पैदा हुई, वह आपको खोजना है।

खोजने का ढंग (कॉपी में): चिट्ठी जिस डिब्बे या माल की शिकायत करे ("NoneType", "5 की जगह 30 चाहिए था") — उस माल का सफ़र पीछे की ओर देखो: यह माल कहाँ से आया? — किसी पुर्ज़े से? — तो उस पुर्ज़े को अकेले बुलाकर देखो (पाठ-191 का "हर पुर्ज़ा अलग से"): print(jod(2, 3)) — None आया? तो पुर्ज़े में return नहीं। jod_suchi को 5, 10, 15 वाली सूची दी — 5 आया, 30 नहीं? तो पुर्ज़े के भीतर हाशिया-जासूस। यह वही वैद्य-रीत है जो भाग-अ से चली आ रही है (पाठ-42): लक्षण जहाँ दिखा, जड़ वहाँ नहीं भी हो सकती — लक्षण से पीछे की ओर चलो। पुर्ज़ों के साथ यह सफ़र छोटा हो जाता है, क्योंकि हर पुर्ज़ा अलग से जाँचा जा सकता है। चिट्ठी पता बताती है कि आग कहाँ दिखी — चिंगारी पुर्ज़े के भीतर हो सकती है।

अभ्यास-खेल: दवाख़ाना-13 मश्क़

खेल 1 — सात मरीज़, सात पर्चे: आज का सेहतमंद jod_suchi प्रोग्राम (और पाठ-187 का namaste) लीजिए, सात नक़लें — हर एक में ठीक एक बीमारी (59-65)। हर एक पर पहले अंदाज़ा, फिर चलाइए; चिट्ठी आए तो नीचे से ऊपर पढ़कर लक्षण से पीछे जड़ तक; चुप हो, तो चार स्टेथोस्कोप में से कौन-सा पकड़ता है? Python बीमारी-पट्टी में सातों — 63 के आगे नोट: "ग़लती पुर्ज़े में, चिट्ठी बाहर"।

खेल 2 — भटके return का शिकार: तीन पुर्ज़े — हर एक में return किस तल पर रखें, पहले कॉपी पर फ़ैसला: (क) सूची में सबसे बड़ा अंक लौटाओ (लूप, if, एक डिब्बा — return कहाँ?) (ख) सूची में पहला सम अंक लौटाओ (यहाँ return भीतर ही सही है! — पहला मिलते ही लौटना ही काम है) (ग) सूची में सम अंकों की गिनती लौटाओ। (ख) सबसे मज़ेदार — कभी-कभी भीतर वाला return ही सही! कॉपी में: "return भीतर कब सही, बाहर कब?" (जब पहला मिलना ही जवाब हो → भीतर; जब सब देखकर जवाब बने → बाहर।)

खेल 3 — पुर्ज़ों की जाँच-सूची + हुक्म-बही: पाठ-186 वाली ख़ाली-परदा सूची में चार पंक्तियाँ और जोड़िए: "(4) None आया? → return है? (5) जवाब अधूरा? → return किस तल पर? (6) NameError? → पुर्ज़ा ऊपर? या भीतरी डिब्बा बाहर पुकारा? (7) TypeError (argument)? → सामान गिनो"। इसे पाठ-127 की अपनी जाँच-सूची से चिपकाइए — अब आपके पास वेब-पन्नों और पुर्ज़ों, दोनों की जाँच-सूची। हुक्म-बही के पुर्ज़ा-पन्ने पर: "बीमारी 59-65 · चार चुप · ग़लती पुर्ज़े में, चिट्ठी बाहर → माल का सफ़र पीछे देखो · return का तल · पहला-मिला → भीतर, सब-देखकर → बाहर"।

आगे क्या सीखेंगे

तेरहवाँ दवाख़ाना पार — सात मरीज़ (59-65): बिन बुलाया पुर्ज़ा, भूले कोष्ठक, बनाने से पहले बुलाया, सामान कम-ज़्यादा, return की जगह print, भटका return (30 की जगह 5!), भीतरी डिब्बा बाहर; चार स्टेथोस्कोप; और "ग़लती पुर्ज़े में, चिट्ठी बाहर" वाली खोज-रीत। Python बीमारी-पट्टी में अब बयालीस बीमारियाँ।

और अब अध्याय-22 का बनाओ-पाठ — हिसाब-पुर्ज़ों की अपनी पेटी: तीन पुर्ज़े — namaste(naam) (दिखाने वाला), jod(a, b) (लौटाने वाला), pahada(n, tak) (दिखाने वाला, जाँच के साथ) — और उन्हें बरतने वाला एक छोटा प्रोग्राम। Founder की v2-सूची का यह अध्याय यहाँ पूरा होगा, और आपके पास होगी अपनी पहली पुर्ज़ा-पेटी — जिसे आगे के हर प्रोग्राम में लगाया जा सके। उसके बाद अगला अध्याय — कोर्स का दूसरा बड़ा प्रोजेक्ट, "अंदाज़ा लगाओ" खेल — जिसमें यही पेटी सबसे काम आएगी। पाठ-193: 🛠 बनाओ — हिसाब-पुर्ज़े (जोड़, पहाड़ा, नमस्ते — तीन पुर्ज़ों की अपनी पेटी)।
