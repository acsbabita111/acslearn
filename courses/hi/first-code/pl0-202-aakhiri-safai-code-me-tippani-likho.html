पाठ परिचय

पुराने मिस्त्री की औज़ार-पेटी में कभी-कभी औज़ारों पर छोटी-छोटी पर्चियाँ चिपकी मिलती हैं — "यह पाना सिर्फ़ पंप के लिए", "इस पेचकस की नोक नाज़ुक — ज़ोर मत लगाना"। ये पर्चियाँ औज़ार का काम नहीं करतीं, पर अगला कारीगर उन्हें पढ़कर बहुत-सी ग़लतियों से बच जाता है। और कभी-कभी वह अगला कारीगर ख़ुद मिस्त्री होता है — दस साल बाद, जब वह भूल चुका होता है कि यह पाना अलग क्यों रखा था।

भाग-ब का पाठ-77 याद है — "कोड में अपनी परची — टिप्पणी" (html की टिप्पणी, जो browser पढ़ता नहीं)? आज वही परची Python में: # (हैश) से शुरू होने वाली कोई भी पंक्ति (या पंक्ति का बचा हिस्सा) — टिप्पणी (comment) — जिसे Python पूरी तरह अनदेखा करता है, और जो सिर्फ़ इंसान के लिए लिखी जाती है।

खेल पूरा है, जँचा है, दोस्तों ने खेला है। आज की आख़िरी सफ़ाई उसे छह महीने बाद के आपके लिए तैयार करती है — टिप्पणियाँ, और एक छोटी सफ़ाई-सूची। और आज का सबसे ज़रूरी सबक़ टिप्पणी का लिखना नहीं, क्या लिखना है: अच्छी टिप्पणी "क्यों" बताती है, "क्या" नहीं। चलिए — पेटी पर पर्चियाँ चिपकाते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. # से टिप्पणी लिख पाएँगे — पूरी पंक्ति की, और किसी पंक्ति के अंत में — और जानेंगे कि Python उसे अनदेखा करता है।

2. अच्छी और बेकार टिप्पणी का फ़र्क़ बता पाएँगे — "क्यों" लिखो, "क्या" नहीं।

3. आख़िरी सफ़ाई-सूची से अपना खेल सजा पाएँगे — और # से जाँच-पंक्ति को अस्थायी रूप से बंद करना सीख जाएँगे।

पेटी पर पर्चियाँ

# — Python का "यह मत पढ़ो": किसी पंक्ति में # आया, तो उसके बाद का पूरा हिस्सा (उस पंक्ति के अंत तक) Python के लिए मौजूद ही नहीं। दो रूप (कॉपी में): (1) पूरी पंक्ति — # khiladi ka swagat — एक अकेली परची, अगले पुर्ज़े के ऊपर; (2) पंक्ति के अंत में — return # jeet gaye - khel yahin khatam — code के साथ चिपकी परची। (# उल्टे-कॉमा के भीतर हो — print("#1") — तो वह शब्द का हिस्सा है, टिप्पणी नहीं; पाठ-132 का "उल्टे-कॉमा के भीतर सब माल"।)

टिप्पणी वाला पूरा खेल — 🔮 अंदाज़ा पहले: नीचे कल का खेल है, बस टिप्पणियों के साथ। दाँव: परदे पर कुछ बदलेगा? (दौड़ें कल वाली — दो खेल, और पहली बार में जीत) —

import random

# --- purzon ki peti ---

# khiladi ka swagat - sirf dikhata hai
def swagat():
    print("Andaaza Lagao! 1 se 20 ke beech ek sankhya maine soch li hai.")

# andaaza poochho, ginti bana kar lautao
def poochho():
    return int(input("Aapka andaaza? "))

# chhota/bada/barabar - teen me se ek ishara lautao
def ishara(andaaza, gupt):
    if andaaza < gupt:
        return "Upar!"
    elif andaaza > gupt:
        return "Neeche!"
    else:
        return "Sahi!"

# jeet par koshishon ke hisab se alag shabashi
def jashn(koshish):
    if koshish == 1:
        print("Kamaal! Pehli hi baar me!")
    elif koshish <= 3:
        print("Bahut badhiya!", koshish, "koshish me pakda.")
    else:
        print("Shabash!", koshish, "koshish me pakda.")

# ek poora khel - zyada se zyada 5 koshish (suraksha-ginti)
def khel():
    gupt = random.randint(1, 20)
    koshish = 0
    while koshish < 5:
        andaaza = poochho()
        koshish = koshish + 1
        jawab = ishara(andaaza, gupt)
        print(jawab)
        if jawab == "Sahi!":
            jashn(koshish)
            return   # jeet gaye - khel yahin khatam
    print("Koshishein khatam - sankhya thi", gupt)

# --- kahani: swagat, phir khel jab tak "haan" ---
swagat()
while True:
    khel()
    phir = input("Phir khelein? (haan/nahi) ")
    if phir != "haan":
        break
print("Khelne ke liye dhanyavaad!")

नतीजा: परदा हूबहू कल जैसा — Python ने एक भी टिप्पणी नहीं पढ़ी (इस किताब का robot भी यही जाँचता है — दोनों दौड़ों के परदे कल वाले से मेल!)। पर code पढ़ने वाले के लिए अब हर पुर्ज़े के ऊपर एक पंक्ति है जो बताती है वह किसलिए है। (टिप्पणियाँ यहाँ Roman में हैं क्योंकि इस किताब के code-डिब्बे Roman रखते हैं; अपनी फ़ाइल में देवनागरी टिप्पणी बिल्कुल चलती है — # khiladi ka swagat की जगह # खिलाड़ी का स्वागत — Python को फ़र्क़ नहीं पड़ता, वह पढ़ता ही नहीं!)

"क्यों" लिखो, "क्या" नहीं — आज का दिल (कॉपी में दो स्तंभ): बेकार टिप्पणी — koshish = koshish + 1 # koshish me 1 jodo — यह तो code ख़ुद कह रहा है! पढ़ने वाला code पढ़ सकता है; टिप्पणी बस वही दोहराती है (और बुरा — code बदले, टिप्पणी नहीं, तो दोनों झूठ बोलें!)। अच्छी टिप्पणी — # ek poora khel - zyada se zyada 5 koshish (suraksha-ginti) — यह बताती है वह बात जो code से नहीं दिखती: क्यों 5, क्यों सीमा। या return # jeet gaye - khel yahin khatam — क्यों यहाँ return (झंडे की जगह — पाठ-200!)। नियम: टिप्पणी वह लिखो जो छह महीने बाद तुम भूल जाओगे — फ़ैसले का कारण, कोई चालाकी, कोई ख़तरा।

# से जाँच-पंक्ति बंद करो — एक काम का ढंग: पाठ-196 की झाँकने वाली पंक्ति याद है (print(gupt) — जाँच के लिए, फिर हटाओ)? उसे मिटाने की जगह आगे # लगा दीजिए: # print("(jaanch)", gupt) — अब Python उसे नहीं पढ़ता (गुप्त संख्या छिपी), पर पंक्ति वहीं है; अगली बार जाँच करनी हो, तो बस # हटाओ। इसे "code को टिप्पणी बनाना" (commenting out — कमेंटिंग आउट) कहते हैं। (पर सावधानी — अंतिम खेल में ऐसी बंद पंक्तियाँ भी साफ़ कर देनी चाहिए; ज़्यादा हों, तो पढ़ना उलझता है।)

आख़िरी सफ़ाई-सूची (पाठ-127 की जाँच-सूची का Python-रूप — कॉपी में): (1) हर पुर्ज़े के ऊपर एक "किसलिए" वाली टिप्पणी · (2) नाम साफ़ (पाठ-143: gupt, koshish, andaaza — मतलब वाले) · (3) पुर्ज़ों के बीच ख़ाली पंक्ति — साँस (पाठ-133) · (4) झाँकने वाली/जाँच वाली पंक्तियाँ हटीं · (5) नियम का हर अंक एक जगह (5 कोशिश, 1-20 — पाठ-190) · (6) दो-मंज़िला बनावट — ऊपर पेटी, नीचे कहानी (पाठ-186) · (7) पूरी दौड़ें फिर से — सफ़ाई के बाद भी परदा वही?

रेखा-चित्र: पेटी पर पर्चियाँ

नीचे आज का पूरा पट्ट — # के दो रूप, बेकार बनाम अच्छी टिप्पणी, जाँच-पंक्ति बंद करना, और सफ़ाई-सूची —

ऊपर के काले परदे की सुनहरी पंक्तियाँ खेल में कुछ नहीं करतीं — Python उन्हें छोड़ देता है; वे सिर्फ़ उस इंसान के लिए हैं जो छह महीने बाद यह पेटी खोलेगा।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "जितनी ज़्यादा टिप्पणियाँ, उतना अच्छा code! हर पंक्ति के साथ एक टिप्पणी लिखूँगा — तब कोई भी समझ लेगा।"

सच: "हर पंक्ति के साथ" — ठीक उलटा असर होता है। सोचिए एक किताब जिसकी हर पंक्ति के नीचे कोई लिख दे "यह पंक्ति बताती है कि..." — पढ़ना दोगुना लंबा, और असली कहानी शोर में खो जाती है। हर पंक्ति वाली टिप्पणी ज़्यादातर "क्या" वाली होती है (koshish me 1 jodo, gupt sankhya rakho) — वह code को दोहराती है, कुछ नया नहीं बताती। और सबसे बड़ा ख़तरा: code बदलता है, टिप्पणी अक्सर नहीं बदलती — कल किसी ने 5 को 7 किया, पर ऊपर टिप्पणी अब भी कहती है "5 koshish" — अब टिप्पणी झूठ बोल रही है, और पढ़ने वाला किस पर भरोसा करे? (पाठ-190 का "एक चीज़ कई जगह = कोई छूटेगी" — टिप्पणी भी एक "जगह" है!)

दुनिया के अच्छे प्रोग्रामर एक मोटा नियम मानते हैं: पहले code को इतना साफ़ बनाओ कि उसे टिप्पणी की ज़रूरत ही न पड़े — अच्छे नाम (gupt, koshish, ishara — पाठ-143), छोटे पुर्ज़े (पाठ-191), सीधी बनावट; और फिर टिप्पणी सिर्फ़ वहाँ जहाँ code "क्यों" नहीं बता सकता। आज के खेल में गिनिए — हर पुर्ज़े पर एक, और दो-तीन ख़ास जगह (सीमा का कारण, return का कारण) — बस। पुर्ज़े के नाम ख़ुद आधी टिप्पणी हैं (पाठ-190 — "नाम = मुफ़्त टिप्पणी")। टिप्पणी नमक जैसी है — सही जगह थोड़ी, तो स्वाद; हर कौर में मुट्ठी भर, तो खाना ख़राब।

अभ्यास-खेल: सफ़ाई-मश्क़

खेल 1 — अपने खेल की आख़िरी सफ़ाई: कल का अपना पूरा खेल — ऊपर की सात-बात सफ़ाई-सूची से एक-एक करके। हर पुर्ज़े पर एक "किसलिए" टिप्पणी (अपनी फ़ाइल में देवनागरी में भी!), दो-तीन ख़ास "क्यों" वाली टिप्पणियाँ, जाँच-पंक्तियाँ साफ़। फिर पूरी दौड़ें — परदा कल जैसा? (होना ही चाहिए — टिप्पणी Python के लिए हवा है!)

खेल 2 — टिप्पणी-अदालत: दस टिप्पणियाँ — हर एक पर फ़ैसला: "क्यों" वाली (रखो) या "क्या" वाली (हटाओ): (क) # gupt sankhya banao (ख) # 0 pehredar hai - kabhi gupt nahi hota (ग) # print karo (घ) # andaaza bada ho to neeche (ङ) # yahan break nahi, return - poora khel chhodna hai (च) # 1 jodo (छ) # Haan bade H wale ko bhi rokta hai - haan likhein (ज) # loop (झ) # randint khel ke bheetar - har khel nayi sankhya (ञ) # khel khatam। कॉपी में कारण।

खेल 3 — छह महीने बाद का प्रयोग + हुक्म-बही: अपने खेल की टिप्पणी-रहित नक़ल किसी साथी (जिसने code सीखा हो — या अपनी कॉपी पर ख़ुद, दो हफ़्ते बाद) को दीजिए — "बताओ, khel() में return क्यों है?" — फिर टिप्पणी वाली दीजिए। कौन-सी जल्दी समझ आई? हुक्म-बही के प्रोजेक्ट-पन्ने पर: "ईंट-7 (सफ़ाई): # = Python नहीं पढ़ता · "क्यों" लिखो, "क्या" नहीं · हर पुर्ज़े पर किसलिए · # से जाँच-पंक्ति बंद · सफ़ाई-सूची 7 बातें · टिप्पणी नमक जैसी"।

आगे क्या सीखेंगे

आख़िरी सफ़ाई हो गई — # से टिप्पणी (पूरी पंक्ति और पंक्ति के अंत में), "क्यों" बनाम "क्या", # से जाँच-पंक्ति बंद करना, सात-बात सफ़ाई-सूची, और यह सच कि टिप्पणी नमक जैसी है। आपका खेल अब चलता भी है, जँचा भी है, दोस्तों ने खेला भी है, और छह महीने बाद पढ़ा भी जा सकता है — एक पूरा प्रोग्राम।

और कल — भाग-स का आख़िरी पाठ, और इस कोर्स का एक बड़ा पड़ाव: शाबाशी-पाठ। पीछे मुड़कर देखेंगे कि पाठ-129 के पहले print से आज के पूरे खेल तक आपने क्या-क्या बनाया; अपने लिए एक छोटा शाबाशी-प्रोग्राम; और एक ईमानदार जानकारी — इस कोर्स के प्रमाणपत्र का द्वार कैसा है, ACS और FFGPMTrust की व्यवस्था में वह कैसे मिलता है, और उसकी हद क्या है (प्रमाणपत्र एक दिशा है, वादा नहीं)। उसके बाद आख़िरी अध्याय — 12 कंप्यूटर-भाषाओं का परिवार और कमाई के द्वार। पाठ-203: शाबाशी-पाठ — तुम प्रोग्रामर (Programmer) बन गए — प्रमाणपत्र-द्वार की जानकारी।
