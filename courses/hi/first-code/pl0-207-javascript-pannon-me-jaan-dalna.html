पाठ परिचय

गाँव के मेले में दो तरह की तस्वीरें बिकती हैं — एक दीवार पर टाँगने वाली, जो हमेशा वैसी ही रहती है; और एक "जादुई" — उसे हिलाओ, तो उसमें चिड़िया उड़ती दिखे। पहली सुंदर है, पर स्थिर; दूसरी जवाब देती है। भाग-ब में आपने जो पन्ने बनाए (पाठ 62-128) — अपना परिचय-पन्ना, मेले का पोस्टर, अपना रिज़्यूमे — वे पहली तरह के थे: सुंदर, पर बटन दबाओ तो कुछ नहीं होता।

पन्नों को जवाब देना सिखाने वाली भाषा का नाम है JavaScript (जावास्क्रिप्ट)। बटन दबाओ — संदेश बदल जाए; फ़ॉर्म में ग़लत नंबर लिखो — तुरंत लाल चेतावनी; खेल का बटन — पासा घूमे। आज जितनी भी वेबसाइटें "हरकत" करती हैं, उनमें लगभग हर जगह JavaScript है। और इसके साथ एक ख़ास सुविधा: वह आपके फ़ोन के ब्राउज़र में पहले से मौजूद है — कोई ऐप लगाना नहीं, कुछ ख़रीदना नहीं।

आज एक छोटा नमूना देखेंगे, और उसे Python के अपने जुड़वाँ से मिलाएँगे — कल वाले "बोली नई, बात वही" की पहली असली परीक्षा। ध्यान रहे: यह JavaScript सिखाने का पाठ नहीं (उसका अलग कोर्स ACS के रजिस्टर में आगे की योजना में है) — यह पहचान का पाठ है। (इस पाठ के JavaScript-नमूने इस किताब का robot नहीं चलाता — वह Python, HTML और CSS ही जाँचता है; इसलिए वे धारीदार "नमूना"-डिब्बों में हैं।) चलिए — तस्वीर में जान डालते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बता पाएँगे कि JavaScript क्या करती है — HTML ढाँचा, CSS रंग-रूप, JavaScript हरकत — और वह कहाँ चलती है।

2. एक छोटा बटन-नमूना पढ़ पाएँगे — function, onclick, id से तत्व पकड़ना।

3. JavaScript और Python की बोली का फ़र्क़ पहचान पाएँगे — धनु-कोष्ठक, अर्धविराम — और सोच की एकता भी।

तस्वीर में जान

तीन परतें — एक पन्ना (कॉपी में): HTML = ढाँचा (क्या है — शीर्षक, बटन, पैरा — पाठ 62-98); CSS = रंग-रूप (कैसा दिखे — पाठ 99-118); JavaScript = हरकत (क्या करे — दबाओ तो बदले)। एक घर की तरह: दीवारें (HTML), रंग-पुताई (CSS), बिजली की फ़िटिंग — बटन दबाओ, बत्ती जले (JavaScript)।

पहला नमूना — बटन जो संदेश बदले: नीचे एक छोटा HTML-पन्ना है, जिसके भीतर script (स्क्रिप्ट) नाम की जोड़ी में JavaScript लिखी है (धारीदार डिब्बा = नमूना, robot नहीं चलाता) —

<button onclick="badlo()">Dabao</button>
<p id="sandesh">Namaste!</p>

<script>
function badlo() {
  document.getElementById("sandesh").textContent = "Aapne button dabaya!";
}
</script>

पढ़ो (पाठ-64 की चीर-फाड़ वाला ढंग): पहली दो पंक्तियाँ आपका पुराना HTML — एक बटन, और एक पैरा जिसकी अपनी पहचान-जेब है: id="sandesh" (पाठ-87 की attribute-जेबें!)। बटन में एक नई जेब: onclick="badlo()" — "दबाया जाए, तो badlo नाम का पुर्ज़ा बुलाओ"। फिर script-जोड़ी के भीतर — function badlo() — Python के def जैसा: एक पुर्ज़ा बनाया (और बुलाया तभी जाएगा जब बटन दबे — पाठ-186 का "बनाना ≠ चलाना", ठीक यहीं!)। भीतर की पंक्ति: "पन्ने में sandesh वाला तत्व ढूँढो, और उसका पाठ बदल दो"। परदे पर: पहले "Namaste!"; बटन दबाते ही — "Aapne button dabaya!"।

Python-जुड़वाँ — 🔮 अंदाज़ा: वही दोनों विचार (गिनती का लूप, और एक पुर्ज़ा) Python में — यह डिब्बा robot चलाता है —

for i in range(1, 6):
    print(i, end=" ")
print()

def badlo():
    print("Aapne button dabaya!")

badlo()

नतीजा: 1 2 3 4 5 और Aapne button dabaya!। और वही गिनती वाला लूप JavaScript में (नमूना) —

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

बोली का फ़र्क़ (कॉपी में तालिका — कल के खेल-2 वाली): Python — def badlo(): · JavaScript — function badlo() { ... }। Python — हाशिया बताता है कि शरीर कहाँ तक (पाठ-161 की लक्ष्मण-रेखा); JavaScript — धनु-कोष्ठक { } बताते हैं (हाशिया वहाँ सिर्फ़ आँख के आराम के लिए — पर अच्छे प्रोग्रामर फिर भी लगाते हैं!)। पंक्तियों के अंत में JavaScript अक्सर अर्धविराम ; लगाती है। लूप: Python — range(1, 6) (अंत से पहले रुको); JavaScript — शुरू, शर्त (i <= 5), और हर चक्कर में बढ़ाओ (i++ = i = i + 1) — तीनों एक पंक्ति में। छपाई: print बनाम console.log (जो ब्राउज़र के भीतरी "जाँच-परदे" पर छापता है)। सोच: बिल्कुल एक — पुर्ज़ा, लूप, गिनती।

फ़ोन पर आज़माना: भाग-ब वाले ढंग से (पाठ 49-52) अपने फ़ोन के text-editor में ऊपर का बटन-नमूना एक .html फ़ाइल में सहेजिए, और फ़ोन के ब्राउज़र में खोलिए — बटन दबाइए! (कुछ editor-ऐपों का भीतरी "preview" script नहीं चलाता — तब फ़ाइल को सीधे ब्राउज़र में खोलिए।) सीखने का सबसे बड़ा मुफ़्त घाट: MDN Web Docs — HTML, CSS और JavaScript की दुनिया भर में सबसे ज़्यादा भरोसे वाली मुफ़्त पढ़ाई-पुस्तक (अंग्रेज़ी; कुछ हिस्से और भाषाओं में) (बाहरी site — जानकारी ख़ुद verify करें)।

जानकारी-जाँची: अक्टूबर 2026

रेखा-चित्र: तस्वीर में जान

नीचे पन्ने की तीन परतें, बटन-नमूने का सफ़र, और Python-JavaScript की बोली की तुलना —

नीचे के दो डिब्बे एक ही बात दो बोलियों में कहते हैं — बाएँ हाशिया शरीर की सीमा बताता है, दाएँ धनु-कोष्ठक; पुर्ज़ा और लूप दोनों में वही।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "JavaScript और Java एक ही चीज़ हैं — नाम में ही दोनों 'Java' है! एक सीख ली, तो दूसरी भी आ गई।"

सच: यह दुनिया भर की सबसे मशहूर नाम-उलझनों में है — और नहीं, वे अलग भाषाएँ हैं, अलग लोगों ने अलग कामों के लिए बनाईं। JavaScript ज़्यादातर ब्राउज़र में पन्नों को जान देने के लिए जानी जाती है (आज का पाठ); Java बड़े सिस्टमों, बैंकों और पुराने Android ऐपों की भाषा है (पाठ-212)। नाम की मिलावट इतिहास की एक संयोग-सी बात है — जिस समय JavaScript बनी, उस समय Java बहुत चर्चा में थी, और नाम मिलता-जुलता रखा गया। लोग अक्सर एक मज़ाक़ कहते हैं: "Java और JavaScript का उतना ही रिश्ता है जितना 'कार' और 'कारपेट' का"! (पाठ-143 का सबक़ याद आता है — नाम मिलता-जुलता हो, तो उलझन तय।)

पर कल वाली बात यहाँ भी सच है — दोनों में (और Python में भी) सोच एक है: पुर्ज़े, लूप, फ़ैसले, सूचियाँ। एक भाषा ठीक से आती हो, तो दूसरी जल्दी समझ आती है — नाम की वजह से नहीं, सोच की वजह से। तो सही बात यह है: JavaScript सीखने से Java अपने-आप नहीं आती; पर Python सीखने से दोनों जल्दी आती हैं। और एक और ग़लतफ़हमी जो इसी से जुड़ी है: "JavaScript सिर्फ़ ब्राउज़र की खिलौना-भाषा है" — आज वह सर्वरों पर भी चलती है (उसका एक मशहूर रूप Node.js कहलाता है — नाम सिर्फ़ उदाहरण), और फ़ोन-ऐप बनाने में भी काम आती है। नाम मिलता है, भाषा नहीं — रिश्ता नाम का नहीं, सोच का होता है।

अभ्यास-खेल: जान-मश्क़

खेल 1 — अपने पन्ने में जान (फ़ोन पर): पाठ-128 का अपना रिज़्यूमे-पन्ना (या पाठ-118 का पोस्टर) खोलिए। उसमें ऊपर वाला बटन-नमूना जोड़िए — बटन: "Mera sapna dikhao"; दबाने पर एक पैरा का पाठ बदले: आपका सपना। ब्राउज़र में खोलकर दबाइए। (ध्यान: script की जोड़ी पूरी हो — पाठ-68 का खुली-जोड़ी जाल यहाँ भी!)

खेल 2 — बोली की तालिका भरो: कल की तालिका की JavaScript-पंक्ति: क्रम (ऊपर से नीचे — वही) · दोहराव (for (...) { }) · फ़ैसला (अनुमान लगाइए! — if (शर्त) { } — Python के if जैसा, बस कोष्ठक और धनु-कोष्ठक) · पुर्ज़ा (function नाम() { }) · छपाई (console.log)। फिर एक छोटी पहेली: यह JavaScript-पंक्ति Python में कैसी होगी — if (ank >= 33) { console.log("Paas"); } ?

खेल 3 — Java या JavaScript? + हुक्म-बही: पाँच वाक्य — सही (✓) या ग़लत (✗): (क) JavaScript ब्राउज़र में पहले से होती है (ख) Java और JavaScript एक ही भाषा हैं (ग) JavaScript में शरीर की सीमा धनु-कोष्ठक बताते हैं (घ) Python का def और JavaScript का function एक ही सोच हैं (ङ) JavaScript सीखने के लिए फ़ोन पर कुछ ख़रीदना पड़ता है। हुक्म-बही के भाग-द पन्ने पर: "JavaScript = पन्ने में हरकत · HTML ढाँचा, CSS रूप, JS जान · function, onclick, id · धनु-कोष्ठक + अर्धविराम · ब्राउज़र में मुफ़्त · Java ≠ JavaScript"।

आगे क्या सीखेंगे

तस्वीर में जान आ गई — पन्ने की तीन परतें (HTML ढाँचा, CSS रूप, JavaScript हरकत), बटन-नमूना (onclick, function, id), Python-जुड़वाँ से तुलना (हाशिया बनाम धनु-कोष्ठक, अर्धविराम), फ़ोन पर आज़माने का मुफ़्त ढंग, MDN का घाट, और Java ≠ JavaScript।

कल परिवार की सबसे रंगीन सदस्य — Scratch (स्क्रैच)। उसमें code लिखा नहीं जाता, ईंटों की तरह जोड़ा जाता है — "10 बार दोहराओ" एक पीली ईंट, "अगर-तो" एक और — ताकि सात-आठ साल का बच्चा भी दोहराव और फ़ैसले की सोच खेल-खेल में पकड़ ले। कल का पाठ आपके लिए नहीं, आपके छोटे भाई-बहनों के लिए है: आप उन्हें Scratch से वही सोच सिखाएँगे जो आपने भाग-अ में सीखी — और सिखाते हुए ख़ुद पक्की करेंगे। साथ में ईमानदार जानकारी: Scratch किस फ़ोन-tablet-कंप्यूटर पर कैसे चलता है, छोटे बच्चों का ScratchJr, और बच्चों की ऑनलाइन सुरक्षा। पाठ-208: स्क्रैच (Scratch) — छोटे भाई-बहन को सिखाओ।
