पाठ परिचय

आपके फ़ोन पर दर्जनों ऐप हैं — बात करने का, पैसे भेजने का, पढ़ाई का, मौसम का, खेती की सलाह का। हर ऐप किसी ने बनाया, किसी भाषा में। आपने भाग-ब में पन्ने बनाए (ब्राउज़र में खुलने वाले) — पर फ़ोन पर अलग से लगने वाला, आइकॉन वाला ऐप कैसे बनता है?

भारत में सबसे ज़्यादा फ़ोन Android वाले हैं, और Android के ऐप बनाने की दो मुख्य भाषाएँ हैं — दो बहनें: Kotlin (कोटलिन) और Java (जावा)। Java बड़ी है — बरसों तक Android ऐपों की मुख्य भाषा रही, और आज भी बैंकों और बड़ी कंपनियों के कई विशाल सिस्टम उसमें चलते हैं। Kotlin छोटी और नई है — 2017 में Google ने उसे Android की आधिकारिक भाषा माना, और 2019 से Android-विकास को "Kotlin-first" (पहले Kotlin) घोषित किया: नए ऐप के लिए वही सुझाई जाती है, और Android का आधुनिक परदा-बनाने वाला औज़ार (Compose) सिर्फ़ Kotlin में ही है।

आज दोनों बहनों की बोली की झलक, Python से मिलान, और एक ईमानदार सवाल का सीधा जवाब: ऐप बनाने के लिए फ़ोन काफ़ी है या कंप्यूटर चाहिए? (Kotlin-Java के नमूने धारीदार डिब्बों में — robot उन्हें नहीं चलाता; Python-जुड़वाँ वह चलाता है।) चलिए — ऐप की रसोई देखते हैं।

सीखने का उद्देश्य

इस पाठ के बाद आप —

1. बता पाएँगे कि Android ऐप किन भाषाओं में बनते हैं — Kotlin (आज मुख्य) और Java (बड़ी बहन) — और दोनों कहाँ काम आती हैं।

2. एक छोटा Kotlin-नमूना पढ़ पाएँगे (fun, val, if, println, $naam) — और Java का लंबा ढाँचा पहचान पाएँगे।

3. ऐप-निर्माण की ईमानदार ज़रूरतें बता पाएँगे — कंप्यूटर, और Kotlin आज़माने का ब्राउज़र-रास्ता — और आधिकारिक मुफ़्त सीख।

ऐप की रसोई

Kotlin का नमूना (धारीदार = नमूना): वही पास-फ़ेल वाला फ़ैसला, Kotlin में —

fun main() {
    val naam = "Sita"
    val ank = 40
    if (ank >= 33) {
        println("$naam - Paas")
    } else {
        println("$naam - Mehnat")
    }
}

Python-जुड़वाँ — 🔮 अंदाज़ा (robot चलाता है) —

naam = "Sita"
ank = 40
if ank >= 33:
    print(naam, "- Paas")
else:
    print(naam, "- Mehnat")

नतीजा: Sita - Paas। Kotlin-नमूने का परदा भी यही होगा।

Kotlin पढ़ो (कॉपी में, पाठ-205 वाली तालिका की Kotlin-पंक्ति): fun main() { ... } — "fun" = function = पुर्ज़ा (Python का def; C का main वाला ढंग — पाठ-211!); val naam = "Sita" — डिब्बा बनाया; val = "ऐसा डिब्बा जिसका माल बाद में नहीं बदलेगा" (बदलने वाले डिब्बे के लिए var); ग़ौर कीजिए, C की तरह क़िस्म लिखनी ज़रूरी नहीं — Kotlin ख़ुद पहचान लेती है (Python जैसी!), पर पहचानकर पक्की कर देती है (C जैसी!) — दोनों का मेल; if (...) { } else { } — JavaScript-C वाला ढंग; println = print ("ln" = line — नई पंक्ति, पाठ-211 के \n वाली बात अपने-आप); "$naam - Paas" — शब्द के भीतर $ लगाकर डिब्बे का माल सीधे बिठाना (पाठ-141 के साँचे जैसा — कॉमा-जोड़ की ज़रूरत नहीं)। अर्धविराम? — Kotlin में ज़रूरी नहीं! (Python जैसी सादगी।)

Java का ढाँचा — बड़ी बहन, ज़्यादा औपचारिक (नमूना): सिर्फ़ "Namaste!" छापने के लिए —

public class Pehla {
    public static void main(String[] args) {
        System.out.println("Namaste!");
    }
}

पाँच पंक्तियाँ — जहाँ Python में एक: print("Namaste!") (पाठ-131!)। हर शब्द का अपना मतलब है (class = एक बड़ा डिब्बा जिसमें पुर्ज़े रहते हैं, public = सबके लिए खुला, String = शब्द-क़िस्म...) — बड़े सिस्टमों में यह औपचारिकता व्यवस्था देती है, पर शुरुआत में भारी लगती है। Kotlin को कुछ हद तक इसी भारीपन को हल्का करने के लिए बनाया गया था — इसलिए दोनों एक ही ऐप में साथ-साथ भी चल सकती हैं।

ईमानदार ज़रूरत — फ़ोन या कंप्यूटर? (1) Kotlin की बोली आज़माना — फ़ोन के ब्राउज़र से भी: Kotlin के आधिकारिक घर kotlinlang.org पर ब्राउज़र में छोटे Kotlin-प्रोग्राम चलाकर देखने की सुविधा ("playground") रहती आई है; (2) असली Android ऐप बनाना — इसके लिए आम तौर पर एक कंप्यूटर चाहिए, जिस पर Google का मुफ़्त औज़ार Android Studio चले (और वह ठीक-ठाक ताक़त वाला कंप्यूटर माँगता है — ACS केंद्र, कॉलेज-लैब)। (3) सीखने का आधिकारिक मुफ़्त रास्ता — developer.android.com पर Google के शुरुआती कोर्स (जैसे "Android Basics with Compose"), और Java के लिए dev.java (सब अंग्रेज़ी में) (बाहरी sites — जानकारी ख़ुद verify करें)।

जानकारी-जाँची: अक्टूबर 2026

रेखा-चित्र: ऐप की रसोई

नीचे दोनों बहनें, Python से मिलान, और ऐप बनने का रास्ता —

बीच की काली तालिका एक ही बात तीन बोलियों में कहती है — पढ़िए, तो Java की पंक्तियाँ सबसे लंबी, Python की सबसे छोटी, और Kotlin बीच में; पर हर स्तंभ में वही पुर्ज़ा, वही डिब्बा, वही छपाई।

ग़लतफ़हमी तोड़ो

ग़लतफ़हमी: "ऐप बनाना तो बड़ी कंपनियों का काम है — करोड़ों का बजट, सैकड़ों लोग! गाँव का कोई अकेला लड़का-लड़की ऐप कैसे बनाएगा?"

सच: बड़े ऐप (जिनके करोड़ों उपयोगकर्ता हों) सचमुच बड़ी टोलियाँ बनाती हैं। पर दुनिया के बहुत-से उपयोगी ऐप छोटे होते हैं — एक काम, साफ़-सुथरा: किसी कोचिंग-केंद्र की हाज़िरी, किसी दुकान का स्टॉक, किसी गाँव के मंडी-भाव, किसी स्कूल का गृह-कार्य। ऐसे ऐप एक अकेला सीखने वाला भी बना सकता है — औज़ार मुफ़्त हैं (Android Studio, Kotlin), सीखने के आधिकारिक कोर्स मुफ़्त हैं, और ज़रूरत है कंप्यूटर तक पहुँच की (केंद्र, कॉलेज, साइबर कैफ़े) और धैर्य की। और ध्यान दीजिए — एक ऐप का दिमाग़ क्या होता है? पाठ-184 का पर्ची-ऐप: मेन्यू, सूची, जोड़ो-हटाओ-गिनो। फ़ोन-ऐप में बस उसका चेहरा बदलता है (काले परदे की जगह बटन) — दिमाग़ की सोच आपके पास पहले से है।

हाँ, ईमानदारी से — यह रास्ता लंबा है। एक अच्छा Android ऐप बनाने लायक़ होने में महीनों का लगातार अभ्यास लगता है; पहले-पहले ऐप टूटेंगे, धीमे चलेंगे, अजीब दिखेंगे (तेरह दवाख़ाने याद हैं?)। और ऐप को दूसरों तक पहुँचाने (ऐप-दुकान पर डालने) के अपने नियम और कभी-कभी शुल्क भी होते हैं — ये बदलते रहते हैं, ख़ुद जाँचिए। पर रास्ता बंद नहीं है — और भारत में ऐसे बहुत-से लोग हैं जिन्होंने छोटे शहरों-गाँवों से शुरुआत की। सीढ़ी यही: Python की सोच (आपके पास) → Kotlin की बोली (ब्राउज़र में आज़माइए) → कंप्यूटर पर पहला छोटा ऐप → दोस्त से जाँच → सुधार। ऐप बड़ी कंपनियों की जागीर नहीं — छोटे ऐप अकेले हाथ भी बनते हैं; बस रास्ता लंबा है, और पहला क़दम आपकी सोच पहले ही उठा चुकी है।

अभ्यास-खेल: रसोई-मश्क़

खेल 1 — बोली पहचानो: पाँच टुकड़े — हर एक किस भाषा का (Python, Kotlin, Java, JavaScript, C)? कारण लिखिए: (क) val ginti = 5 (ख) System.out.println("Hi"); (ग) print("Hi") (घ) console.log("Hi"); (ङ) printf("Hi\n"); — फिर हर एक को Python में लिखिए। (सुराग़: val → Kotlin; System.out → Java; console.log → JavaScript; printf → C।)

खेल 2 — Kotlin आज़माओ (अगर इंटरनेट हो): ऊपर की कड़ी (kotlinlang.org) पर ब्राउज़र वाला playground खोजिए, और आज का Kotlin-नमूना चलाइए — फिर naam और ank बदलिए। val वाले डिब्बे का माल दोबारा बदलने की कोशिश कीजिए (val ank = 40 के बाद ank = 50) — क्या हुआ? (रोक! — val बदला नहीं जाता; var से चलेगा।) कॉपी में: Python का कौन-सा डिब्बा "val" जैसा व्यवहार करता है? (कोई नहीं — Python सब बदलने देता है; पाठ-140!)

खेल 3 — अपने ऐप का नक़्शा + हुक्म-बही: अपने गाँव-घर के लिए एक छोटे ऐप का काग़ज़ी नक़्शा (पाठ-194 का ढंग): क्या करेगा, कितने परदे (बटन कौन-से), भीतर कौन-सी सूचियाँ, कौन-से पुर्ज़े। पाठ-184 के पर्ची-ऐप से मिलाइए — दिमाग़ कितना एक-सा? पाठ-205 की तालिका में Kotlin और Java की पंक्तियाँ भरिए। हुक्म-बही के भाग-द पन्ने पर: "Android ऐप = Kotlin (आज मुख्य) + Java (बड़ी बहन) · fun, val, println, $naam · Java औपचारिक · आज़माना ब्राउज़र में, बनाना कंप्यूटर पर · रास्ता लंबा, बंद नहीं"।

आगे क्या सीखेंगे

ऐप की रसोई देख ली — Android की दो बहनें (Kotlin — आज मुख्य, 2019 से Kotlin-first; Java — बड़ी बहन, बड़े सिस्टम), Kotlin-नमूना और Python-जुड़वाँ, Java का औपचारिक ढाँचा, ऐप बनाने की ईमानदार ज़रूरतें (आज़माना ब्राउज़र में, बनाना कंप्यूटर पर), आधिकारिक मुफ़्त सीख, और यह सच कि छोटे ऐप अकेले हाथ भी बनते हैं।

बारह भाषाओं का परिवार पूरा हुआ। पर एक "भाषा" और है जो इन बारहों में नहीं, फिर भी आज के समय में सबसे तेज़ी से काम की बन रही है — AI-सहायकों से बात करने की भाषा: अपनी ही हिंदी या अंग्रेज़ी, पर इस ढंग से लिखी कि AI ठीक-ठीक समझे कि क्या चाहिए। इसे प्रॉम्प्ट (prompt) लिखना कहते हैं — और यह भाषा नहीं, हुनर है: पाठ-12 का "अधूरा निर्देश, गड़बड़ नतीजा", पाठ-39 के टुकड़े, और तेरह दवाख़ानों वाली जाँच — सब इसमें लगते हैं। कल एक अच्छे प्रॉम्प्ट के हिस्से, एक प्रॉम्प्ट-पुर्ज़ा, और AI से काम लेने की सुरक्षा-रेखाएँ। पाठ-213: ए॰आई॰ से काम लेना — प्रॉम्प्ट (Prompt) लिखने का हुनर।
