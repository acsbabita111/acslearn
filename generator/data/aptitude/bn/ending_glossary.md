# बांग्ला अंत-शब्दावली (अभिरुचि-प्रश्न) : v1.0, 12-Nov-2026

यह सूची बताती है कि हिंदी प्रश्नों के बार-बार आने वाले अंत बांग्ला में कैसे लिखे जाते हैं।
एक हिंदी अंत का एक ही बांग्ला रूप रखा जाता है, ताकि पूरे भंडार में भाषा एक-सी रहे।
संबोधन हर जगह "তুমি" है (live बांग्ला करियर-पन्ने जैसा)।

| हिंदी अंत | English पुल | बांग्ला |
|---|---|---|
| कैसा लगता है? | how does that feel? | কেমন লাগে? |
| सोचकर कैसा लगता है? | how does it feel to think about it? | ভাবতে কেমন লাগে? |
| कैसा लगेगा? | how would that feel? | কেমন লাগবে? |
| कैसा रहेगा? | how would that be? | কেমন হবে? |
| भाएगा? | would you enjoy it? | উপভোগ করবে? |
| रुचेगा? | would you like it? | পছন্দ হবে? |
| जमेगा? | would it suit you? | তোমার সঙ্গে মানাবে? |
| जँचेगा? | does it appeal to you? | মনে ধরবে? |
| मज़ा आएगा? | would it be fun? | মজা লাগবে? |
| अच्छा लगेगा? | would that feel good? | ভালো লাগবে? |
| मन करेगा? | would you want to? | করতে ইচ্ছে করবে? |
| मन लगेगा? | would you enjoy doing it? | কাজে মন বসবে? |
| कर पाओगे? | could you do it? | পারবে? |
| करोगे? | would you do it? | করবে? |
| सोचोगे? | would you think about it? | ভেবে দেখবে? |
| हिम्मत है? | do you have the courage? | সাহস আছে? |
| धीरज रहेगा? | would you have the patience? | ধৈর্য থাকবে? |
| यह हुनर सीखोगे? | would you learn this skill? | এই দক্ষতা শিখবে? |
| सोच जमती है? / सोच भाती है? | does the idea appeal to you? | ভাবনাটা মনে ধরে? |
| करने का मन है? | do you want to do it? | করতে মন চায়? |

बार-बार आने वाले प्रश्न-ढाँचे:

| हिंदी | बांग्ला |
|---|---|
| इनमें से कौन-सा काम तुम सबसे पहले करना चाहोगे? और कौन-सा सबसे कम? | এগুলোর মধ্যে কোন কাজটা তুমি সবার আগে করতে চাইবে? আর কোনটা সবচেয়ে কম? |
| इनमें से कौन-सा धंधा तुम सबसे पहले चुनोगे? और कौन-सा सबसे कम? | এগুলোর মধ্যে কোন ব্যবসাটা তুমি সবার আগে বেছে নেবে? আর কোনটা সবচেয়ে কম? |
| दोनों सही हैं — तुम्हें कौन-सा ज़्यादा भाता है? | দুটোই ঠিক। তোমার কোনটা বেশি ভালো লাগে? |
| ज़्यादा अच्छा क्या — …, या …? | কোনটা বেশি ভালো লাগে: …, নাকি …? |
| ज़्यादा मज़ा किसमें — …, या …? | কোনটায় বেশি মজা: …, নাকি …? |
| तुम क्या करोगे? | তুমি কী করবে? |
| तुम क्या सँभालोगे? | তুমি কী সামলাবে? |

शब्द-चुनाव: पानी = জল (भारत की बांग्ला) · धंधा = ব্যবসা · हुनर = দক্ষতা · हाट = হাট · मंडी = পাইকারি বাজার · टोली = দল।
