# पाठ 2.01 — Word खोलना, नया document बनाना और सहेजना

## इस पाठ में क्या सीखोगे (लक्ष्य)

1. कंप्यूटर पर MS Word 2019 (एम-एस वर्ड) खोलना।
2. नया ख़ाली document (डॉक्यूमेंट — काग़ज़ जैसा पन्ना) बनाना।
3. उस पन्ने को सही नाम देकर सही जगह सहेजना (save करना)।
4. फ़ोन पर यही काम Google Docs (गूगल डॉक्स) से मुफ़्त में करना।
5. "Save" और "Save As" का फ़र्क़ समझना।

**पहले क्या आना चाहिए:** पाठ 1.05 (कंप्यूटर/फ़ोन चालू-बंद करना, icon पहचानना)।

## डिजिटल मित्र के काम में यह क्यों ज़रूरी है

दुकान पर काका आए — "बेटा, पंचायत को अर्ज़ी लिखनी है।" डिजिटल मित्र का पहला हुनर यही: पन्ना खोलना, लिखना, और ऐसा सहेजना कि कल दस सेकंड में मिल जाए। बिना सहेजा document बिजली जाते ही उड़ जाता है — ग्राहक का भरोसा भी। यही पाठ पूरे कोर्स की नींव है।

## Word है क्या?

MS Word एक software (सॉफ़्टवेयर — कंप्यूटर का औज़ार) है, जिसमें चिट्ठी, अर्ज़ी, सूचना, resume (रिज़्यूमे) — सब लिखा जाता है। काग़ज़-कलम जैसा ही, पर यहाँ ग़लती मिटाना, अक्षर बड़ा-छोटा करना और सौ प्रतियाँ छापना — सेकंडों का काम।

## कदम-दर-कदम: कंप्यूटर पर (Word 2019)

**कदम 1 — Word खोलो।** Screen के बाएँ-नीचे Start (स्टार्ट) बटन दबाओ → type करो `word` → "Word 2019" दिखे → Enter (एंटर) दबाओ। *(संस्करण-दर-संस्करण बटन की जगह बदल सकती है — काम वही।)*

**कदम 2 — नया पन्ना लो।** Word खुलते ही "Blank document" (ब्लैंक डॉक्यूमेंट — ख़ाली पन्ना) का सफ़ेद खाना दिखेगा। उस पर click करो। कोरा पन्ना हाज़िर — उस पर cursor (कर्सर — टिमटिमाती लकीर) चमकता है।

**कदम 3 — दो पंक्तियाँ लिखो।** अभ्यास के लिए type करो: `नमस्ते, मेरा नाम सीता कुमारी है।` (काल्पनिक नाम — अभ्यास में असली ब्योरा कभी नहीं।)

**कदम 4 — सहेजो (Save):** तीन रास्ते, तीनों एक ही काम करते हैं —
- Ribbon में **File → Save** दबाओ, या
- keyboard पर **Ctrl + S** (कंट्रोल और S एक साथ), या
- ऊपर बाएँ कोने का छोटा disk-निशान 💾।

पहली बार सहेजने पर Word पूछेगा — *कहाँ रखूँ, क्या नाम दूँ?*

**कदम 5 — जगह और नाम।** "Browse" से **Documents** folder चुनो। File name में लिखो: `seeta-arji-2026`। फिर **Save** बटन दबाओ। Title Bar में यही नाम दिखेगा; **पक्का सबूत** = बंद करके दोबारा खोलना।

**नाम रखने के तीन नियम (ज़िंदगी-भर काम आएँगे):**
1. नाम से काम पता चले — `arji` लिखो, `document1` नहीं।
2. साल/तारीख़ जोड़ो — बाद में खोजना आसान।
3. आड़ी लकीर `-` चलेगी, पर `/ \ ? *` जैसे चिह्न फ़ाइल-नाम में कभी नहीं।

## Save बनाम Save As — एक-पंक्ति का फ़र्क़

**Save** = उसी फ़ाइल में ताज़ा बदलाव जोड़ना। **Save As** (File → Save As) = उसी काम की **नई प्रति**, नए नाम या नई जगह पर — पुरानी फ़ाइल जस-की-तस बची रहती है। काका की अर्ज़ी में कल बदलाव करना हो तो Save; वैसी ही अर्ज़ी दूसरे ग्राहक के लिए बनानी हो तो Save As।

## फ़ोन पर यही काम — Google Docs (मुफ़्त)

कंप्यूटर न हो तो Play Store से **Google Docs** app (ऐप) लो — मुफ़्त।
1. Docs खोलो → नीचे-दाएँ रंगीन **+** दबाओ → "New document"।
2. वही दो पंक्तियाँ type करो।
3. Save-बटन नहीं मिलेगा — **Docs हर अक्षर अपने-आप Google Drive (ड्राइव) के cloud में सहेजता है**; ऊपर "Saved" दिखे, बस। यह फ़ोन के Documents folder की .docx फ़ाइल **नहीं** होती।
4. **.docx चाहिए तो अलग कदम:** ⋮ (तीन बिंदु) → Share & export (शेयर एंड एक्सपोर्ट) → Save as → Word (.docx)।
5. नाम बदलने के लिए ऊपर फ़ाइल-नाम पर उँगली रखो → `seeta-arji-2026` लिखो।

**ध्यान:** auto-save की आदत Word 2019 (कंप्यूटर) पर मत ले जाना — वहाँ Ctrl+S तुम्हारी अपनी ज़िम्मेदारी है। पक्का नियम: **हर 5 मिनट में एक बार Ctrl+S।**

## हल किया हुआ उदाहरण (worked example — काल्पनिक)

**स्थिति:** चौथम बाज़ार की दुकान पर रामू काका आए — बिजली-विभाग को शिकायत-पत्र चाहिए।
**डिजिटल मित्र के कदम:** (1) Word → Blank document। (2) पत्र type (असली काम में असली ब्योरा; *अभ्यास* में सदा काल्पनिक)। (3) Ctrl+S → Documents में `bijli-shikayat` folder → नाम `ramu-bijli-shikayat-07nov2026`। (4) बंद कर दोबारा खोला — पक्का। (5) अगले हफ़्ते तारीख़ बदली → Save। दस सेकंड — यही भरोसा कमाता है।

## अपनी जाँच — 5 प्रश्न

**प्र-1.** Word में फ़ाइल सहेजने का keyboard-रास्ता कौन-सा है?
(क) Ctrl + C (ख) Ctrl + P (ग) Ctrl + S (घ) Alt + F4
**उत्तर: (ग)।** कारण: Ctrl+S = Save। भटकाने वाले विकल्प क्यों ग़लत: (ख) Ctrl+P छापता है, (क) Ctrl+C नक़ल करता है, (घ) Alt+F4 खिड़की बंद करता है — बिना सहेजे दबाया तो काम खो सकता है।

**प्र-2.** पहली बार Save दबाने पर Word क्या पूछता है?
(क) फ़ाइल खोलने का password (ख) फ़ाइल का नाम और जगह (ग) जुड़े printer का नाम (घ) कुछ नहीं
**उत्तर: (ख)।** कारण: पहली बार फ़ाइल का घर-नाम तय होता है। बाक़ी क्यों ग़लत: (घ) पहली बार Word हमेशा पूछता है; (क) password सुरक्षा-सुविधा है, Save का अंग नहीं; (ग) printer छापते समय पूछा जाता है।

**प्र-3.** रधिया को एक जैसी अर्ज़ी दो ग्राहकों के लिए बनानी है — पहली सहेजी जा चुकी है। दूसरी के लिए सही रास्ता?
(क) पहली फ़ाइल delete (ख) File → Save As से नई प्रति (ग) पहली फ़ाइल में ही नाम बदलकर Save (घ) नया कंप्यूटर
**उत्तर: (ख)।** कारण: Save As पुरानी बचाकर नई प्रति बनाता है। बाक़ी क्यों ग़लत: (ग) पहले ग्राहक की अर्ज़ी मिट जाएगी; (क) delete से पुराना record खोओगे; (घ) बेतुका ख़र्च — वही software दोनों काम करता है।

**प्र-4.** फ़ाइल का सबसे अच्छा नाम कौन-सा?
(क) important-doc-final-2026 (ख) asdfg-2026 (ग) ramu-bijli-shikayat-2026 (घ) RAMU/SHIKAYAT/2026
**उत्तर: (ग)।** कारण: काम + व्यक्ति + साल — खोजना आसान। बाक़ी क्यों ग़लत: (क) "important/final" से काम-व्यक्ति नहीं झलकता; (ख) बेमतलब अक्षर, कल पहचान नहीं; (घ) में `/` है — फ़ाइल-नाम में मना।

**प्र-5.** Google Docs (फ़ोन) में Save-बटन क्यों नहीं दिखता?
(क) पहले पैसा देना पड़ता है (ख) Docs हर बदलाव अपने-आप सहेजता है (ग) फ़ोन में सहेजना नहीं होता (घ) app ख़राब है
**उत्तर: (ख)।** कारण: auto-save (cloud में)। बाक़ी क्यों ग़लत: (घ) app ठीक है — यही बनावट है; (ग) सहेजना होता है, पर Drive में; (क) Docs पूरी तरह मुफ़्त है।
