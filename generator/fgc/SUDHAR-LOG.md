# fgc सुधार-बही (हर सुधार यहीं दर्ज हो)

नियम:
1. विद्यार्थी, शिक्षक या भाषा-जानकार कोई ग़लती बताए, तो पहले यहाँ एक पंक्ति लिखिए।
2. फिर `texts/` की पंक्ति बदलिए और `node generator/fgc/build.js` चलाइए।
3. पूरा कोर्स दोबारा नहीं लिखना है। सिर्फ़ वही पंक्तियाँ बदलनी हैं जिनका सबूत हो।
4. सबूत के बिना बदलाव नहीं। सबूत = स्रोत का वाक्य, या मूल-वक्ता का नाम और तारीख़।

## खुली शिकायतें (अभी सुधार बाक़ी)

|---|---|---|---|---|---|
| | | | | | |
